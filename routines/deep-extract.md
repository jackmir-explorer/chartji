# Routine: Deep Extract (PR-based Knowledge Ingest)

## 실행 방식
**매일 정오 12:00 자동 실행**
Scout가 6시에 생성한 보고서를 미르가 오전 중 핸드폰으로 확인·체크할 수 있도록
6시간 간격을 두고 실행한다.

**데스크탑에서 수동 실행도 가능:** "deep extract 실행해줘"

## 목적
Scout ⭐ 항목 중 미르가 선택한 논문을 
`skills/paper-extract/SKILL.md` 로 정식 knowledge 형식으로 추출하고
**PR을 생성**해 미르의 최종 승인을 받는다.

---

## 실행 절차

### Step 1 — 대상 수집
`inbox/scout/` 에서 `[o]` 체크된 항목 수집
(미르가 Scout 파일에서 `[ ]` → `[o]` 로 변경한 항목)

대상이 없으면: 조용히 종료. (로그 없음 — 정상 동작)
→ 놓쳐도 Scout 파일은 inbox/scout/에 누적되어 있으므로 나중에 체크 후 재실행 가능.

### Step 2 — 논문별 Deep Extract
각 대상 논문에 대해 `skills/paper-extract/SKILL.md` 실행:
1. PubMed/저널 사이트에서 초록 + 결론 수집
2. 임상 핵심 추출
3. knowledge/ 형식 draft 작성
4. 저장 위치 결정 (기존 파일 추가 or 신규 생성)

### Step 3 — 브랜치 생성 및 커밋

```
브랜치명: claude/deep-extract-YYYY-MM-DD
```

작업 내용:
- 추출된 knowledge draft를 해당 파일에 반영
- 신규 파일이면 Write, 기존 파일이면 해당 섹션에 추가
- `knowledge/log.md` 업데이트 (신규 항목 추가)
- 처리된 Scout 항목을 `[o]` → `[✓]` 로 변경

Scout 파일 업데이트:
- 처리된 항목 `[o]` → `[⏳]` 로 변경 (PR 번호 기록)
- 예: `[⏳ PR#14]`

커밋 메시지:
```
feat: Deep Extract — {논문 제목 축약} 외 {N}건

{각 논문 한 줄 요약 목록}

Auto-generated by Deep Extract Routine
```

### Step 4 — PR 생성

```bash
gh pr create \
  --title "📚 Deep Extract: {날짜} — {주요 논문 제목 축약}" \
  --body "..."
  --base main \
  --head claude/deep-extract-YYYY-MM-DD
```

PR 본문 형식:
```markdown
## 이번 Deep Extract 요약

| 논문 | 저장 위치 | 태그 | PMID |
|------|----------|------|------|
| {제목 축약} | knowledge/{경로} | [CLINICAL] | {번호} |

## 추출 내용 미리보기

{각 논문별 핵심 내용 2-3줄}

---
✅ Merge하면 knowledge/ 에 자동 반영됩니다.
❌ Close하면 브랜치가 삭제됩니다. (재실행 가능)
```

### Step 5 — Merge 감지 후 마커 업데이트
PR이 Merge되면 (main 브랜치에 반영 감지 시):
- Scout 파일의 `[⏳ PR#N]` → `[✓]` 로 업데이트
- 별도 커밋으로 반영

### Step 6 — 완료 보고
"PR 생성 완료. GitHub에서 확인 후 Merge해주세요: {PR URL}"

---

## PR 검토 → 승인 방법 (핸드폰)

1. GitHub 앱 또는 github.com 접속
2. Pull Requests 탭 → 해당 PR 클릭
3. "Files changed" 탭에서 변경 내용 확인
4. 이상 없으면 초록색 **Merge pull request** 클릭
5. 마음에 안 들면 **Close pull request** 클릭

---

## 주의사항
- CLINICAL 항목은 반드시 출처(PMID) 표기
- 기존 파일 내용 삭제 금지 — 추가만 허용
- PR 1개당 최대 논문 5건 (과부하 방지)
- `gh` CLI 미설치 환경: Step 4 건너뜀, draft 파일만 `inbox/drafts/`에 저장 후 미르에게 알림
