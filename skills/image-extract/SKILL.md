# skills/image-extract/SKILL.md — Image / PDF Extract

## 역할
미르가 업로드한 이미지(사진·슬라이드·메모) 또는 PDF에서 임상 내용을 추출하여
knowledge-ingest용 Draft를 구조화 출력한다.
Liby가 이미지·PDF 입력을 감지했을 때 자동 호출된다.

---

## 입력
- 이미지 1장 이상 (Claude 멀티모달 직접 읽기)
- PDF 파일 (Claude 네이티브 읽기 — 페이지 범위 지정 필요)
- 선택: 미르가 붙인 컨텍스트 메모 (없어도 무방)
- 이미지·PDF + 텍스트 동시 제공 시: 텍스트를 Draft에 병기하여 미르가 검토 중 보완 가능하도록 함께 출력

### PDF 특이사항
- 미르가 페이지 범위를 지정하지 않으면 반드시 먼저 질문:
  "몇 페이지를 읽을까요? (예: 3-7페이지)"
- 미르가 명시적으로 전체 읽기를 지시한 경우: PII 스캔 선행 후 허용. 단, 토큰 비용 사전 고지.
- PDF 출처(논문명·가이드라인명·교재명)가 있으면 Attribution 후보로 바로 활용

---

## 절차

### Step A. PII 스캔
이미지·PDF 내 다음 항목이 보이면 즉시 중단 후 미르에게 보고:
- 환자 이름·주민번호·나이·진료일·기관명·처방전 번호
- ⚠ 의심만 돼도 플래그. 확인 전 ingest 진행 절대 금지.
- PDF는 PII 위험 특히 높음 (EMR 출력물·처방전 가능성)

### Step B. 내용 추출
Claude 멀티모달/PDF 읽기로 텍스트화.
- OCR 불확실 부분: `[판독불가]` 마킹
- 손글씨·저해상도: 가장 유력한 해석 + `[추정]` 마킹
- PDF 텍스트 레이어 있으면 그대로 추출 (더 정확)

### Step C. 2단계 신선도 필터

#### 1단계 — 기존 bundle 중복 체크
`src/knowledge-bundle.js` 키워드와 대조.
이미 저장된 내용과 완전 중복되는 항목 → Draft에서 제외.

#### 2단계 — 신선도 평가

| 등급 | 기준 | 처리 |
|---|---|---|
| ⭐ 신선 | 특정 수치·한국 약품명·임상 경험·교수 팁·가이드라인에 없는 뉘앙스·새 연구 프로토콜 | Draft 포함 |
| △ 보통 | 알려져 있지만 맥락 강화에 유용 | Draft 포함, 낮은 우선순위 |
| ✕ 제외 | LLM이 이미 잘 아는 교과서 기본 지식 | 자동 제외 |

**✕ 제외 기준 예시:**
- 약물 기본 작용 기전 (아스피린 COX 억제 등)
- 흔한 질환 진단 기준 (HTN 140/90, DM HbA1c 6.5 등)
- 교과서 1차 치료 원칙 (당뇨 1차 metformin 등)
- 일반적 병태생리·역학 설명

**⭐ 신선 기준 예시:**
- 특정 taper 프로토콜 (소론도 4T#2 ×5일 → 2T#2 ×2일)
- 한국 외래 실전 처방 순서·조합
- 한국 보험 급여 조건·심평원 기준
- 교수님 외래 임상 팁
- 새 RCT·가이드라인 업데이트 내용

### Step D. 구조화 Draft 생성

```
━━━━━━━━━━━━━━━━━━━━━━━━━
📋 IMAGE/PDF EXTRACT DRAFT
━━━━━━━━━━━━━━━━━━━━━━━━━

[추정 질환/약물명]
- {질환명 또는 약물명} (확신도: 높음|보통|낮음)

[신선도 필터 결과]
- 제외된 항목 수: {N}개 (교과서급 기본 지식)
- bundle 중복 제외: {N}개

[섹션 분류]  ⭐/△ 항목만 표시 (각 항목 앞에 등급 마킹)
- 문진/검사:   ⭐ {내용} / △ {내용} / "해당 없음"
- 처방/치료:   ⭐ {내용} / △ {내용} / "해당 없음"
- 감별진단:    ⭐ {내용} / △ {내용} / "해당 없음"
- 가이드라인:  ⭐ {내용} / △ {내용} / "해당 없음"
- 기타:        ⭐ {내용} / △ {내용} / "해당 없음"

[태그 후보]
- {[CLINICAL] / [REGULATORY] / [TIPS] / [INSIGHTS]}
- 불명확 시 "미르 판단 필요" 명시

[Attribution 후보]
- 추출 가능: "{출처명}" → `by {출처명}` 제안
- 확인 불가: "⚠ 출처 확인 필요 — TIPS/INSIGHTS 저장 전 필수"

[⚠ 미르 확인 필요]
- {수치·용량·기간 포함 항목 나열}
- 없으면 "없음"

[PII 플래그]
- {의심 항목} 또는 "없음"
━━━━━━━━━━━━━━━━━━━━━━━━━
```

### Step E. 미르에게 제시
Draft 출력 후:
> "위 Draft를 검토·수정 후 승인해 주시면 knowledge-ingest Step 1부터 진행합니다.
> ⚠ 확인 필요 항목은 수정 후 승인 바랍니다."

### Step F. 미르 승인 대기
- 승인 → Liby가 knowledge-ingest SKILL.md Step 1부터 정상 실행
- 거부·보류 → Draft 폐기, 추가 지시 대기
- 승인 없이 자동 ingest 절대 금지

---

## ⚠ 절대 금지
- PII 플래그 없이 ingest 진행 금지
- 수치·용량 항목 ⚠ 표시 생략 금지
- Attribution 미확인 상태에서 TIPS/INSIGHTS 저장 진행 금지
- OCR 불확실 내용을 확실한 것처럼 출력 금지
- PDF 페이지 범위 미지정 상태에서 전체 읽기 금지
- ✕ 제외 항목을 미르에게 추천 금지
