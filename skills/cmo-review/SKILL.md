# skills/cmo-review/SKILL.md — 임상 안전 리뷰

CMO가 전략 리뷰 시 실행하는 임상 안전 체크.

## 체크리스트
```
[ ] 이 변경이 RedFlag 감지를 약화시키지 않는가?
[ ] Live panel이 의사의 임상 판단을 오도할 가능성이 없는가?
[ ] Working Draft 출력이 transcript 근거 없는 소견을 포함하지 않는가?
[ ] 환자 안전에 부정적 영향을 줄 수 있는 구조 변경이 없는가?
[ ] 의사의 판단을 흐리게 만드는 정보 과잉이 없는가?
```

## 판정
모두 통과 → 안전 확인
하나라도 우려 → 우려 사항 + 권고 명시
