# skills/clo-review/SKILL.md — 법적 리스크 리뷰

CLO가 전략 리뷰 시 실행하는 법적 리스크 체크.

## 체크리스트
```
[ ] 시스템이 의사의 진단을 대신하는 구조처럼 보이지 않는가?
[ ] 법적으로 문제가 될 표현이 UI/출력에 없는가?
[ ] Working Draft가 medico-legal document로 오용될 위험이 없는가?
[ ] 오진 시 책임 구조가 의사에게 불리하게 작용하지 않는가?
[ ] 환자 데이터 처리가 브라우저 로컬에서만 이루어지는가?
```

## 판정
모두 통과 → 법적 리스크 없음
하나라도 우려 → 우려 사항 + 권고 명시
