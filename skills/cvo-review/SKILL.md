# skills/cvo-review/SKILL.md — 제품 가치 리뷰

CVO가 전략 리뷰 시 실행하는 제품 가치 체크.

## 체크리스트
```
[ ] 이 변경이 Chartji의 핵심가치(진료 보조, 누락 방지)를 강화하는가?
[ ] 의사의 인지부하를 감소시키는 방향인가?
[ ] 외래 workflow를 더 잘 반영하는가?
[ ] 단순히 기능만 늘어난 것은 아닌가?
[ ] 제품을 더 단순하게 만드는가, 더 복잡하게 만드는가?
```

## 판정
모두 부합 → 가치 정렬 확인
이탈 항목 있음 → 이탈 사항 + 본질 회귀 권고 명시
