# skills/cfo-review/SKILL.md — 비용/효율 리뷰

CFO가 전략 리뷰 시 실행하는 비용·효율 체크.

## 체크리스트
```
[ ] 프롬프트 길이가 과도하게 증가하지 않았는가?
[ ] 같은 정보를 여러 패널에서 중복 생성하지 않는가?
[ ] 불필요한 API 호출이 추가되지 않았는가?
[ ] Agent/Skill 수가 과도하게 증가하지 않았는가?
[ ] 워크플로우가 불필요하게 길어지지 않았는가?
[ ] 유지보수 난이도가 과도하게 증가하지 않았는가?
```

## 판정
모두 통과 → 효율 적정
하나라도 우려 → 우려 사항 + 비용 영향 + 권고 명시
