# 일본뇌염 백신 [CLINICAL]

keywords: 일본뇌염, Japanese encephalitis

## 종류 비교

| 구분 | 사백신 (불활성화, IXIARO 등) | 생백신 (약독화, Imojev 등) |
|-----|--------------------------|--------------------------|
| 접종 횟수 | 2회 (0일·28일) | 성인 1회 |
| 추가접종 | 필요 시 1~2년 후 1회 | — |
| 특징 | 부작용 적음, 해외 많이 사용 | 편의성 우수 |
| 금기 | 없음 | 임신부·면역저하자 금기 |

## 실전 선택

- **여행 직전 (시간 없을 때)**: 생백신 1회 (금기 없을 때)
- **시간 여유 있을 때**: 불활성화 2회 완료
- 소아기 접종 기록 불확실해도 성인 추가접종 안전
