# 폐렴구균 백신 [CLINICAL]

keywords: 폐렴구균, pneumococcal, 폐렴백신, PCV13, PPSV23

## 적응증

| 대상 | 백신 |
|-----|------|
| 65세 이상 | PPSV23 (23가) |
| 65세 미만 만성질환자 | PCV13 |
| 면역저하자 | PCV13 우선 |
| 해당 없지만 접종 원하는 경우 | PCV13 가능 |

## 만성질환자 해당 범위

알코올중독 / 만성 심혈관질환 (심부전·심근병증 포함) / 만성 간질환 / 만성 폐질환 (COPD·폐기종·천식 포함) / 흡연 / 당뇨병

## 면역저하자 해당 범위

선천·후천성 무비증 / 낫적혈구병·혈색소병증 / 만성 신질환 / 전신성 암 / HIV 감염 / 호지킨병 / 면역억제제 투여 / 백혈병 / 림프종 / 다발성 골수종 / 신증후군 / 고형장기이식
