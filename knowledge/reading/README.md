# knowledge/reading/ — 관심 아티클 (Reading Lane)

tags: [META]

## 목적
진료 알고리즘에 직접 쓰지는 않지만 미르가 정리할 가치가 있는 **관심 주제 아티클**을 모으는 lane.
`일차의료 학습 스코프`의 확장 — 임상 inject가 아니라 **지적 큐레이션·Obsidian 그래프**용.

## 격리 원칙 (필수 — myth-log·study-notes와 동일 강도)
- **bundle 밖**: `src/knowledge-bundle.js` 컴파일 대상 **아님**. Liby ingest의 bundle backlog 점검에서 **제외**.
- **inject 전면 차단**: Triage·Working Draft·RedFlag·Liby hint·Guide tab 어디에도 **안 뜸**.
- 소비 경로 = **Obsidian 직접 읽기 / 그래프뷰 / 검색**뿐. 앱 runtime과 분리된 공간.

## 형식 (임상 엔트리와 동일 rigor 유지)
- md frontmatter(tags·keywords·sources) · 3-tier 출처 · `[[wikilink]]` 규약 그대로.
- 파일 태그: `[READING]` (근거 성격 보조 태그 병기 가능 — 예: `[READING — INSIGHTS]`).
- 검증 못 한 원 출처는 `[원 논문 미확인 — Researcher 검증 대기]` 마커로 투명 표기.
- wikilink는 reading → 임상 엔트리 **아웃링크 허용**(Obsidian 탐색용). 단 reading 키가 inject **target**이 되는 일은 없음(bundle 밖이라 구조적으로 차단).
- `knowledge/log.md`에 1줄 기록(추적용). `src/knowledge-bundle.js`·앱 `index.md` 목록에는 **넣지 않음**.
