## 정의 (definition)

노인(≥65세)은 현재 뇌전증 환자 중 가장 빠르게 성장하는 집단. 다약제·다이환·신기능 저하·낙상 취약으로 항경련제(ASM) 선택이 복잡. 발작 조절 효능은 약물 간 유사 → **내약성과 삶의 질이 치료 선택의 핵심**.

## 신약 vs 구약 내약성 비교 [CLINICAL]

> [출처: McCarthy LM et al. Drugs Aging 2026;43(3):251-265. PMID:41706289]
> 서술적 고찰 — RCT + 임상 경험 통합

### 신세대 ASM (내약성 우수)

| 약물 | 특이사항 | 노인 권고 |
|---|---|---|
| **Lamotrigine** (라모트리진) | 인지·낙상 부작용 적음; 약물 상호작용 낮음 | 1차 선택 고려 |
| **Levetiracetam** (레베티라세탐) | 신장 배설 → eGFR에 따라 용량 조절; 신경정신 부작용(과민·우울) 주의 | 널리 사용 |
| **Lacosamide** | 심장 전도 주의 (PR 연장) | 심방세동 노인 주의 |
| **Brivaracetam** | 레베티라세탐 대비 신경정신 부작용 적음 | 레베티라세탐 불내 시 대안 |
| **Eslicarbazepine acetate** | 카바마제핀보다 저나트륨혈증 적음 | 카바마제핀 대안 |
| **Oxcarbazepine** (옥시카바마제핀) | 저나트륨혈증 주의 | 카바마제핀보다 내약성 양호 |

### 구세대 ASM — 노인에서 회피 권장

| 약물 | 문제점 |
|---|---|
| **Phenytoin** (페니토인) | 다약물 상호작용 광범위; 뼈 대사·전정 영향; 좁은 치료역 |
| **Carbamazepine** (카바마제핀) | 저나트륨혈증; 효소 유도 → 다약제 상호작용; 인지 영향 |
| **Valproate** (발프로에이트) | 떨림·체중 증가·간독성·골다공증 위험 |
| **Phenobarbital** | 진정·낙상·인지저하 — 노인 금기에 준함 |

## 처방 원칙 (protocol)

**저용량 시작, 천천히 증량:**
- 신기능 저하·체수분 감소 → 일반 성인 용량의 50%에서 시작
- 증량 간격 4~8주 (성인보다 느리게)
- 발작 조절보다 **내약성 우선** — 부작용으로 중단하면 무의미

**효소 유도 ASM 회피:**
- 카바마제핀·페니토인·페노바르비탈 → 스타틴·DOAC·항생제 등 수십 가지 상호작용
- 가능하면 비효소 유도 신약으로 대체

---

## 동반 상황별 고려 (precaution)

| 동반 상황 | 선택 고려 |
|---|---|
| 신기능 저하 | 레베티라세탐 → eGFR에 따라 용량 조절 |
| 간기능 저하 | 라모트리진·발프로에이트 감량 |
| 골다공증 | 효소 유도 ASM → 비타민 D 대사 방해 → 회피 |
| 항응고제 사용 | 효소 유도 ASM → 와파린·DOAC 농도 변화 → 신약 선호 |
| 치매 동반 | 신경정신 부작용 적은 라모트리진 선호 |
| 뇌졸중 후 뇌전증 | 라모트리진, 레베티라세탐 일반적 선택 |
| 뇌종양 관련 | 비효소 유도 ASM 필수 (항암제 상호작용 차단) |

## 문진/검사 (exam)

- 낙상 위험 평가 (STEADI 또는 TUG ≥12초)
- 인지기능 기저치 (MMSE·MoCA)
- 현재 복용 약물 → 효소 유도 상호작용 스크리닝
- eGFR, LFT 기저치 → 용량 결정
- 혈중 약물 농도 필요 시 (페니토인 특히 중요 — 치료역 좁음)

---

## 의뢰 기준 (referral)

- 신규 뇌전증 진단 → 신경과 의뢰 (원인 규명·치료 계획 수립)
- 2종 이상 ASM 실패 → 신경과 협진 (난치성 뇌전증 평가)
- ASM 전환·감량 결정 → 신경과 협의 후 진행
- 발작 1~2년 소실 후 감약 → 신경과 필수
