## 정의 (definition)

**CKM(Cardiovascular-Kidney-Metabolic) 증후군** — AHA 2023이 제안한 신패러다임:

- **정의**: ≥2개 심혈관·신장·대사 위험인자의 상호작용으로 전반적 심혈관 건강 저하가 나타나는 전신 장애
- **핵심 개념**: 당뇨·CKD·심혈관질환을 각개격파하는 대신 **하나의 스펙트럼**으로 통합 관리
- **한국 외래 맥락**: DM+고혈압+CKD 동반 환자가 급증 — CKM 프레임이 다약제 환자 처방 간소화에 직결

## CKM 증후군 4단계 분류 (indication)

> [출처: Fordan S et al. Postgrad Med. 2026;138(6):643-653. PMID:42415318]
> [초록 기반 — 전문 미확인: 단계별 치료 상세는 원문 Table 참조 권장]

| 단계 | 특징 | 주요 개입 |
|---|---|---|
| **0기** | 위험인자 없음 | 건강 유지·예방 |
| **1기** | 대사 위험인자 (비만·당뇨전단계·고혈압·이상지질혈증) | 생활습관 교정 우선 |
| **2기** | CKD 동반 (단백뇨·eGFR 감소) | 신보호 약제 추가 (SGLT-2i·RAS 차단제) |
| **3~4기** | CVD 동반 (심부전·관상동맥질환·뇌졸중) | 다장기 이익 약제 통합 처방 |

## CKM 증후군의 핵심 개념 — 일차의료 의사용 (notes)

### 왜 CKM 프레임이 필요한가?

기존 접근: DM 담당과 + CKD 담당과 + 심장과 각각 처방 → 다약제 누적

CKM 접근: **하나의 원인 스펙트럼**으로 보고 단일 약제로 여러 구성요소를 동시 개선

### 병태생리 간략 요약

```
비만·대사증후군
    ↓ (인슐린저항성·염증)
신장 손상 (단백뇨·eGFR 저하)
    ↓ (볼륨 과부하·신장-심장 교차)
심혈관 손상 (심부전·관상동맥질환)
```

이 세 영역이 **악순환 고리**를 형성 — 하나를 치료하면 다른 영역도 개선됨.

## 다장기 이익 약제 선택 원칙 (protocol)

[초록 기반 — 전문 미확인]

### SGLT-2 inhibitor — 심장·신장·혈당 동시 개선

| 이익 영역 | 근거 |
|---|---|
| 심부전 입원 감소 | EMPEROR-Reduced·DAPA-HF (HFrEF), EMPEROR-Preserved (HFpEF) |
| 신장 보호 (단백뇨 감소·eGFR 유지) | CREDENCE·DAPA-CKD — eGFR ≥20까지 시작 가능 |
| 혈당 조절 | 2~3제 병용에 적합 |
| 적용 단계 | CKM **2기 이상** (CKD 동반 시 우선 고려) |

관련 처방 기준: [[diabetes]] → SGLT-2i eGFR cutoff 참조

### GLP-1 RA / 이중작용제 — 체중·심혈관·신장 동시 개선

| 이익 영역 | 근거 |
|---|---|
| 체중 감소 | 위약 대비 10~22% (semaglutide·tirzepatide) |
| 심혈관 사건 감소 | LEADER·SUSTAIN-6·SELECT |
| 신장 보호 | FLOW (semaglutide) |
| 적용 단계 | CKM **1기 이상** (비만·DM 동반 시 우선) |

### PCSK9i — LDL 목표 미달 시

- CKM 3~4기 + 고LDL 유지 → PCSK9i 추가
- 스타틴 불내성 환자의 대안

### RAS 차단제 (ACEi / ARB)

- 단백뇨 + CKD: CKM 2기 이상 표준 처방
- 심부전 + CKM: RAAS 차단 기본 포함

## 처방 간소화 전략 (protocol)

**"단일 약제 → 여러 CKM 구성요소 동시 개선"** 원칙:

| 환자 프로필 | 우선 약제 | 커버하는 CKM 요소 |
|---|---|---|
| DM + CKD + 비만 | SGLT-2i + GLP-1RA | 혈당 + 신장 + 체중 + 심장 |
| DM + HF | SGLT-2i 우선 | 심부전 입원 감소 + 혈당 |
| DM + 고LDL + CVD | 스타틴 + PCSK9i (필요시) | LDL + 심혈관 2차 예방 |
| CKD 단독 | SGLT-2i + ACEi/ARB | 신보호 |

---

## 한국 외래 변환 시 확인 (precaution)

- SGLT-2i·GLP-1RA 급여 기준: 당뇨 병용 조건·HbA1c 기준 [출처 미확인 — researcher 검증 권장]
- CKM 증후군 자체는 아직 한국 급여 진단명 아님 [출처 미확인]
- 다과 분산 처방 환자 통합 시 — 각 전문과와 처방 조율 필요

---

## 의뢰 기준 (referral)

- CKM 4기 (활동성 CVD + CKD 4~5기 + 조절 불량 DM) → 심장내과·신장내과 통합 협진
- eGFR <20 → 신장내과 (투석 준비)
- HFrEF + 조절 불량 → 심장내과 (GDMT 최적화)
