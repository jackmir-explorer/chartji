## 진단 (exam)

### 스파이로메트리 진단 기준
- **기도 폐쇄**: 기관지 확장제 투여 후 **FEV1/FVC < 0.70** (GOLD 고정 기준)
- 증상: 호흡곤란(dyspnea), 만성 기침, 객담
- 위험인자: 흡연(주요), 대기오염, 직업적 노출, α1-antitrypsin 결핍

### 중증도 (FEV1 기준 — GOLD 등급)
| GOLD 등급 | FEV1 (% predicted) |
|---------|-------------------|
| 1 (경증) | ≥80% |
| 2 (중등도) | 50–79% |
| 3 (중증) | 30–49% |
| 4 (최중증) | <30% |

## 분류 (classification)

### GOLD 2025 ABE 분류 [REGULATORY]

> 출처: Basoshvili N. Cureus 2026;18(1):e102479. PMID:41769574. DOI:10.7759/cureus.102479

| 그룹 | 기준 | 처방 방향 |
|------|------|---------|
| **A** | 증상 없거나 경미 (mMRC 0-1 / CAT <10) **AND** 악화 위험 없음 (지난 1년 ≤1회 비입원 악화) | LABA 또는 LAMA 단독 |
| **B** | 증상 있음 (mMRC ≥2 / CAT ≥10) **OR** 악화 위험 ≥1회 | LABA + LAMA 병용 |
| **E** | 악화 ≥2회/년 **OR** 악화로 인한 입원 ≥1회/년 | LABA + LAMA (±ICS); 호산구 ≥300 → ICS 추가 강력 고려 |

**GOLD 2025 핵심 변경:** B·D 그룹 → **B·E 그룹**으로 단순화 (이전 C 그룹 소멸)

## 처방/치료 (protocol)

### 흡입기 기반 치료 단계

```
초기 단계
A군 → LABA 또는 LAMA 단독
B/E군 → LABA + LAMA 병용 (이중 기관지확장제)

증상/악화 지속 시
E군 + 호산구 ≥300 → LABA + LAMA + ICS (삼중치료)
E군 + 호산구 <100 → ICS 회피 (효과↓ + 폐렴 위험↑)
```

### 혈중 호산구 기반 ICS 결정 [CLINICAL]

> 출처: Basoshvili N. Cureus 2026;18(1):e102479. PMID:41769574. DOI:10.7759/cureus.102479

| 호산구 수치 | ICS 권고 |
|-----------|---------|
| **≥300 cells/μL** | ICS 추가 — 강력 고려 |
| 100–299 cells/μL | ICS 효과 불확실 — 개별 판단 |
| **<100 cells/μL** | ICS **회피** (폐렴 위험↑, 효과↓) |

**임상 포인트:** GOLD 2025 이전에는 혈중 호산구 기준 없었음. 2025년부터 ICS 사용·제거 의사결정에 호산구를 공식 바이오마커로 통합.

### 비약물 치료
- **금연** — 가장 중요한 예후 개선 중재
- 폐재활(pulmonary rehabilitation): 운동능력·삶의질 개선
- 예방접종: 독감(매년), 폐렴구균, COVID-19, Tdap

## 모니터링 (monitoring)

- mMRC 호흡곤란 척도 / CAT(COPD Assessment Test) 점수 — 매 외래
- 스파이로메트리: 1–2년마다 (진행 추적)
- 혈중 호산구: ICS 결정·유지 시 주기적 재평가
- 폐렴·악화 에피소드 기록 (E군 분류 근거)
- 흡입기 사용 기술 확인 (외래 방문마다)

---

## 주의사항 (precaution)

- ICS 장기 사용 → **폐렴 위험 증가** (특히 호산구 <100일 때)
- Beta-blocker: COPD와 심혈관질환 동반 시 **선택적 β1 차단제(비소프롤롤·메토프롤롤)** 는 일반적으로 안전 — 금기 아님
- 산소치료: PaO₂ <55mmHg 또는 SpO₂ ≤88% → 장기 산소치료 적응

---

## 1차의료 적용 (referral)

- 외래에서 ABE 분류 → 흡입기 처방 결정 가능
- 호산구 수치로 ICS 추가·제거 결정 — 직접 적용 가능
- 의뢰: 진단 불확실·FEV1 <30%·잦은 입원 악화·수술 고려·α1-AT 결핍 의심
