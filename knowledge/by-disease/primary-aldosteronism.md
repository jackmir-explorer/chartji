## 2025 패러다임 전환 — 고혈압 전원 선별

### 기존(구) 선별 기준 → 2025 가이드라인 변화

| 항목 | 기존 접근 | 2025 Endocrine Society CPG |
|---|---|---|
| 선별 대상 | 저항성 고혈압, 저칼륨혈증, 부신종괴 등 **고위험군 한정** | **고혈압 환자 전원** |
| 선별 검사 | 위험 요소 있을 때만 | 알도스테론 + 레닌 → ARR 측정 |
| 근거 | PA 유병률 과소평가 | 고혈압 외래의 최대 14%가 PA (현저히 저진단) |

> **핵심 메시지:** PA는 같은 혈압에서도 본태성 고혈압보다 **심혈관 합병증 위험↑** → 조기 발견이 임상적 의미 있음

## 진단 알고리즘 (exam / differential)

```
고혈압 초진 또는 혈압 조절 불량
    ↓
Step 1: ARR 선별 (알도스테론 + 레닌 동시 측정)
    │  ARR = 혈장 알도스테론(ng/dL) / 레닌(ng/mL/hr)
    ├─ ARR 저위험 → PA 낮음, 본태성 고혈압 관리
    ├─ ARR 중간 → 알도스테론 억제 검사 + 수술 원하는지 확인
    └─ ARR 고위험 (PA 강하게 시사) → 알도스테론 억제 검사 생략 가능
           ↓
Step 2: 알도스테론 억제 검사 (필요 시)
           ↓
확진 시 Step 3: CT 스캔 + 부신정맥 샘플링 (AVS)
           ├─ 편측성 과잉 → 부신절제술 (수술 원할 때)
           └─ 양측성 → MRA 약물 치료
```

> 1mg 야간 덱사메타손 억제 검사: 부신 선종이 있는 모든 PA 환자에게 권고 (동반 쿠싱 배제)

## 처방/치료 (protocol)

### MRA (Mineralocorticoid Receptor Antagonist) — 수술 불가 또는 원치 않을 때

| 약물 | 특성 | 권고 순위 |
|---|---|---|
| **스피로노락톤 (Spironolactone)** | 비특이적 MRA, 저비용, 광범위 가용 | **1차 선택** |
| 에플레레논 (Eplerenone) | MRA 특이적, 항안드로겐 부작용↓ | 여성형유방 부작용 시 대체 |
| 피네레논 (Finerenone) | 고특이적 MRA, T2DM+CKD에도 허가 | PA 적응증 미명시 [출처 미확인] |

> 동등 역가로 titration 시 모든 MRA 효능 유사 — 비용·부작용 프로파일로 선택

### MRA 모니터링

- **레닌 추적 측정** — 레닌이 억제된 상태에서 고혈압 지속 → MRA 용량 증량
- 저칼륨혈증 교정 후에도 혈압 조절 안 되면 용량 조정
- 스피로노락톤: 여성형유방(남성 최대 40%), 성욕↓, 월경 불순 — 부작용 시 에플레레논으로 교체

## 환자 설득 포인트 (고혈압 초진 ARR 검사)

미르 반응: *"고혈압초진에서 ARR 내려면 환자 설득이 필요할거같다"*

**ARR 검사 설명 예시 (외래 2분):**
> "고혈압 원인 중 부신에서 호르몬이 너무 많이 나오는 경우가 전체 고혈압의 10-15%에 이르는데, 이건 약으로 핀포인트 치료가 가능합니다. 피 한 번으로 확인할 수 있어서 오늘 같이 측정해 두겠습니다."

**ARR 검사 전 주의사항 (위양성 방지):**
- β차단제, α2 작용제(클로니딘), NSAIDs → 레닌 억제 → ARR 위음성 가능
- 칼륨 보충 먼저 (저칼륨혈증 교정 후 측정)
- CCB·α차단제(암로디핀·독사조신)는 ARR에 최소 영향 → ARR 측정 중 이 약으로 혈압 조절

---

## 주의사항 (precaution)

- ARR cutoff 수치는 측정 기관·assay마다 다름 — 기관 기준 확인 필요
- 편측성 PA 수술 시 혈압 완전 정상화율은 ~40-60% — 수술 후에도 항고혈압제 필요한 경우 많음
- PA + T2DM 동반 시 스피로노락톤의 성기능 부작용 유의

---

## 의뢰 기준 (referral)

- ARR 양성 → 내분비내과 협진 (확진 + AVS 계획)
- 부신 CT에서 종괴 발견 → 내분비내과 협진
- MRA 최고 용량에서도 혈압 조절 불량 → 내분비내과
