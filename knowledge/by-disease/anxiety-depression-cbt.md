## 정의

인지행동치료(CBT)는 대부분의 정신질환에서 **1차 치료(first-line)**로 권고되는 구조화된 심리치료.

---

## 핵심 수치 — 효과 크기 (Hedges g, CBT vs 대조군)

> 메타분석 근거: 375 RCT, 423 비교군, 32,968명 (Cuijpers P et al., JAMA Psychiatry 2025)
> [DOI](https://doi.org/10.1001/jamapsychiatry.2025.0482)

| 질환 | 효과 크기 (g) | 근거 강도 |
|------|-------------|---------|
| **PTSD** | **1.27** (최대) | 강력 |
| **특정 공포증** | >1.0 | 강력 |
| 사회불안장애 | 0.5~1.0 | 강력 |
| 공황장애 | 0.5~1.0 | 강력 |
| 범불안장애 (GAD) | 0.5~1.0 | 강력 |
| 폭식증 (Bulimia nervosa) | 0.5~1.0 | 강력 |
| 대식장애 (BED) | 0.5~1.0 | 강력 |
| **주요우울증 (MDD)** | 0.5~1.0 | 강력 |
| 강박장애 (OCD) | 0.5~1.0 | 강력 |
| 양극성장애 | <0.5 | 보조적 |
| 정신증 | <0.5 | 보조적 |

> - Waitlist 대조군: 효과 크기 더 큼 (g >0.94)
> - 일상치료(TAU) 대조군: 보수적 (0.22~1.13)
> - 중도 탈락률: 특정 공포증 8% ~ PTSD 24%

## 처방/치료 — 1차의료 적용

### CBT 의뢰 적응증

| 질환 | 권고 강도 |
|------|---------|
| PTSD | **1차 치료** — 강력 권고 |
| 특정 공포증 | **1차 치료** |
| 불안장애 (공황·사회불안·GAD) | 약물 + CBT 병합 권고 |
| 주요우울증 | 약물 단독 대비 장기 재발 예방 우수 |
| OCD | ERP (노출반응방지) — CBT 특수 기법 |

### 외래 실용 지침

- **불안·우울 초진**: 약물 처방 + CBT 동시 의뢰 → 최적 결과
- CBT 제공 경로: 임상심리사·정신건강복지사·정신건강의학과 협진
- 디지털 CBT (iCBT): 전통 CBT 대비 유사 효과 → 접근성 낮은 환자 보조 수단
- 통상 치료 기간: 8~20회기 (주 1회)

---

## 한계·주의사항

- **중증 정신증·양극성장애**: CBT 단독 불충분 — 약물 우선, CBT 보조적 역할
- **자살 위험**: CBT 의뢰 전 안전 계획 수립 필요
- 효과 크기는 대조군 종류에 따라 크게 달라짐 (waitlist vs TAU)
- 한국 의료 환경: CBT 보험 급여 제한 → 접근성 제약 현실적 고려 필요
- 대부분 RCT가 서양 인구 대상 → 문화적 적응 효과 차이 가능

## 약물 처방 plan — 동반증상별 1차 약제 선택

> 근거: APA MDD 2010, AAFP 2023 Pharmacologic Treatment of Depression, NICE NG222, FDA labeling

### 우울증 1차 SSRI

| 약물 | 시작 | 유지 | 특징 |
|---|---|---|---|
| **Escitalopram** | 5mg qd | 10~20mg qd | **가장 안전, 약물 상호작용 적음** |
| Sertraline | 25mg qd | 50~200mg qd | 불안·강박 동반 시, 위장 부작용·약물 상호작용 적음 |
| Fluoxetine | 10mg qd | 20~60mg qd | 폭식증·다이어트 원할 시, 활력 증가 (오전 복용) |

### Follow-up 표준
- **1주 f/u**, 1주 용량 증가 가능
- **4주 후 평가** (PHQ-9, GAD-7) — 효과는 4주 후부터
- 체중·BP·간/신기능 확인
- **유지 6~12개월**, 증상 심할 시 2년+, 중단 시 점진적 감량
- **1~2주 불안 악화 가능** (BDZ 단기 병용 가능)
- 위장장애·성기능장애·**고령 hyponatremia (SIADH)**

> NICE NG222: less severe MDD에서 항우울제는 routine 1차 권고 X (스텝드 케어 우선) — 한국 1차의료 맥락에선 약물 1차가 흔하나 옵션 인지.

### 동반증상별 선택

| 동반증상 | 우선 약물 |
|---|---|
| 활력·각성 증가 필요 | **Fluoxetine, Bupropion** (오전 복용) |
| 성기능 문제 | **Bupropion, Mirtazapine** |
| 다약제·약물 상호작용 우려 | Escitalopram, Sertraline |
| **우울 + 만성통증·섬유근육통** | **Duloxetine 30mg → 60mg** (FDA 섬유근통 승인). Venlafaxine 37.5 → 75~225mg (HTN 주의) |
| **우울 + 수면장애·체중감소** | **Mirtazapine 15mg HS → 15~45mg** (진정·식욕 증가) |
| 우울 + 무기력·집중력 저하·금연보조 | **Bupropion 150mg SR → 150~300mg qd~bid** (활력 증가, 과하면 불안) |

> ⚠ Duloxetine 60mg 이상은 추가 효과 근거 부족·부작용↑ — 100~120mg는 신중.

## 불안 처방

> 근거: NICE CG113 GAD/Panic, APA Panic, FDA labeling

| 적응 | 약물 |
|---|---|
| GAD·공황장애 | Escitalopram, Sertraline (1차 SSRI) |
| 강박장애 (OCD) | **Fluvoxamine 50mg → 100~300mg qd** |
| **무대 불안증** | Propranolol 10~40mg qd-bid (공연 1~2시간 전, 필요 시 40~120mg/day) |
| **급성 불안·SSRI 시작 초기 단기 보조 (2~4주, PRN)** | Alprazolam 0.25~0.5mg PRN (총 ~0.75~4mg/day), Lorazepam 0.5~1mg PRN (총 2~4mg/day) |

> ⚠ **BZD는 NICE GAD에서 routine 사용 비권고** — 급성 위기·단기(2~4주) PRN/최단기간으로 한정. 정기 bid-tid 처방은 의존·반동불안 위험. **고령에서 회피 (Beers 2023 강한 권고)**.

## 불면 처방

> 근거: AASM 2017 Chronic Insomnia CPG, AGS Beers Criteria 2023, FDA labeling

### 수면 개시장애
| 약물 | 용량 | 비고 |
|---|---|---|
| Ramelteon | 8mg 취침 1h 전 | 의존·금단 거의 없음 |
| 멜라토닌 | 취침 1h 전 | ⚠ AASM 2017 1차 권고 X (근거 약함) |
| **Zolpidem** | 취침 직전 5~10mg (고령 5mg) | 반감기 2~3h, 4주 이상 X. ⚠ **고령 회피 (Beers)** |
| Triazolam | 취침 30분 전 0.125~0.25mg | 반감기 1.5~5.5h. 금단·반동 주의. ⚠ **고령 회피 (Beers)** |

### 수면 유지장애
| 약물 | 용량 | 비고 |
|---|---|---|
| **Doxepin** | 취침 전 3~6mg | **의존성 적음 — AASM 권고** |
| Mirtazapine | 15mg HS | 진정·식욕 증가 |
| Trazodone | 취침 전 25~100mg | ⚠ **AASM 2017 불면 1차 사용 말 것 (weak against)** — 어지럼증·진정 주의 |

### 수면 개시 + 유지
