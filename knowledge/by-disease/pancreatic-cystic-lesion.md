## 1차 평가 패널

복부 sono/CT에서 췌장 낭성 병변 발견 시 일차의료에서:

| 검사·항목 | 목적 |
|---|---|
| **CA 19-9** | Tumor marker (cutoff 37 U/mL); 단독 진단 X, **trend·surveillance에 유용**; 황달·간담도 폐쇄 시 false positive |
| **HbA1c·공복혈당** | **New-onset DM (NOD) = paraneoplastic sign** — 50세+ 새 DM 진단 시 췌장암 위험 6-8배 |
| **LFT 패널** (AST/ALT/GGT/T-bil) | 담관 폐쇄·간 전이 평가 |
| **Amylase·Lipase** | 췌장염 동반 평가 |
| **증상·가족력** | 복통(특히 새로 시작·등 방사)·체중감소·황달·췌장암 가족력 |
| **소화기내과 의뢰** | **MRCP/MRI 시행** — cyst 형태 평가 (worrisome features) |

---

## Worrisome Features (Kyoto 2024) — 일차의료 인지

다음 시 즉시 소화기내과:

- Cyst size **≥30 mm**
- 주췌관(MPD) **5-9 mm**
- CA 19-9 상승
- New-onset DM (50세+)
- 췌장암 가족력
- 빠른 cyst 성장 (> 5 mm/year)

## High-Risk Stigmata (수술 적응증)

- Enhancing mural nodule ≥5 mm
- MPD **≥10 mm**
- 폐쇄성 황달 + 췌두부 cyst

---

## 일반 surveillance 원칙 (참고)

| Cyst size | Imaging 간격 (Kyoto 2024) |
|---|---|
| <10 mm | 6mo후 1회 → 안정 시 q2y |
| 10-20 mm | q1y |
| 20-30 mm | q6-12mo |
| ≥30 mm 또는 worrisome | **즉시 의뢰 / EUS·FNA 결정** |

> 일차의료는 의뢰 결정만 — 상세 surveillance는 소화기내과.

---

## New-Onset DM + 50세+ — 췌장암 screening 알람

> Olmsted County 코호트 데이터: 50세+ 새 DM 환자의 3년 내 PDAC 위험 평균 인구 대비 **6-8배**.

- 50세+ 무위험·무가족력 신규 DM에서 췌장 sono/CA 19-9는 routine 권고는 아니나 **체중감소·식욕부진·복통·황달** 동반 시 적극 평가
- 가족력 1촌 췌장암 또는 BRCA1/2·PALB2·CDKN2A·Lynch syndrome → 50세 이전부터 surveillance

---

## 의뢰 기준

- Cyst ≥30 mm → 소화기내과
- MPD ≥5 mm 또는 mural nodule → 소화기내과 (HRS는 응급)
- CA 19-9 ↑ + new-onset DM + 50세+ → 소화기내과
- 췌장암 가족력 + 임의 cyst → 소화기내과
- 황달 + 췌두부 cyst → 응급 의뢰
