## 핵심 근거 — 나이-보정 D-이합체 DVT 배제 (JAMA 2026)

### 나이-보정 D-이합체 공식

```
표준 기준치: 500 µg/L (연령 무관)

나이-보정 기준치: 나이(세) × 10 µg/L  — 50세 이상에 적용
  예: 65세 → 650 µg/L
  예: 80세 → 800 µg/L
```

> 이미 PE(폐색전증)에서 검증된 동일 공식 → 이번에 DVT에서 최초 전향적 검증

### 순차적 진단 전략 (Wells + 나이-보정 D-이합체)

```
하지 통증·부종·DVT 의심
    ↓
Wells DVT score 계산
    ├─ 고위험(≥3점) → 압박 초음파 즉시
    └─ 저/중위험(<3점) → D-이합체 측정
           ├─ D-이합체 < 500 µg/L → DVT 배제
           ├─ D-이합체 500–나이×10 (50세 이상) → DVT 배제 (나이-보정 기준 적용)
           └─ D-이합체 ≥ 나이×10 → 압박 초음파
```

### 핵심 수치

| 지표 | 결과 |
|---|---|
| 표준 기준치(500 µg/L)로 음성 비율 | 24.5% |
| 나이-보정 추가 음성 비율 | +7.4%포인트 (161명 추가 배제) |
| **나이-보정 기준 이하 환자 VTE 사건** | **0% (95% CI 0–2.3%)** |
| 75세 이상 음성 비율: 표준 → 나이-보정 | **8.7% → 26.1%** |

> ✅ 3개월 추적 VTE 0건 — 안전성 확인

## 처방/치료 (protocol)

### Wells DVT 점수 (계산 항목)

| 항목 | 점수 |
|---|---|
| 활동성 암 | +1 |
| 하지 마비·석고붕대 | +1 |
| 최근 3일 이상 침상안정 또는 최근 12주 이내 전신마취/수술 | +1 |
| 종아리 연조직 압통 | +1 |
| 하지 전체 부종 | +1 |
| 증상 있는 다리의 종아리 3cm 이상 부종 (비골두에서 10cm) | +1 |
| 압박 스타킹 착용 부위 함요부종 | +1 |
| 표재정맥 측부 순환 (정맥류 제외) | +1 |
| 이전 DVT 확진 병력 | +1 |
| **DVT 이외의 진단이 더 가능성 높음** | **–2** |

- ≤0점: 저위험 / 1-2점: 중위험 / ≥3점: 고위험

---

## 적응 환자군 (indication)

- Wells 점수 저/중위험 + DVT 의심 외래·응급실 환자
- **특히 50세 이상 고령 환자**: 나이-보정 기준치 적용으로 불필요한 초음파 크게 줄임
- 75세 이상: 표준 기준으로 음성 나오는 환자가 8.7%뿐 → 나이-보정으로 26.1%로 확장

---

## 주의사항 (precaution)

- **고위험(Wells ≥3)에서는 D-이합체 의미 없음** — 직접 압박 초음파
- D-이합체는 예민도(민감도) 높고 특이도 낮은 검사 — 배제 검사로만 사용, 확진 불가
- 임신·활동성 암·CRP 상승 등에서 D-이합체 위양성 흔함
- 나이-보정 공식은 아직 한국 보험 기준에 공식 명시 없음 [출처 미확인 — researcher 검증 권장]

---

## 한국 외래 적용 포인트

- **DVT 의심 하지 통증·부종** 환자: Wells 점수 + D-이합체(고감도) 순차 적용
- 65세 이상 환자: 나이-보정 기준(나이×10 µg/L) 적용 → 불필요 초음파 의뢰 줄이기
- 초음파 결과 대기 중 Wells 점수 중위험 이상이면 LMWH 시작 고려
- 외래 추적 어려운 환자(홀몸 고령 등): 임계치 경계일 경우 보수적 접근(초음파 우선)
