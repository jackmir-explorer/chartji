## 정의

형질세포(plasma cell)의 혈액 악성 종양 — 단클론 단백(M-protein) 과다 생성.
- 미국: 연간 약 36,000건 신규 진단
- 중앙 진단 연령: 69세
- **전구 단계**: MGUS → 무증상 다발성골수종(Smoldering) → 증상성 다발성골수종

## 문진/검사

### 의심 증상 조합 (CRAB + 기타)

| 증상 | 기전 |
|------|------|
| **C — 고칼슘혈증** (Hypercalcemia) | 파골세포 활성화 |
| **R — 신부전** (Renal failure) | M-protein, 고칼슘혈증, 탈수 |
| **A — 빈혈** (Anemia) | 골수 침범 |
| **B — 뼈 통증·병적골절** (Bone pain/fractures) | 용해 병변 |
| 피로·체중감소 | 전신 악성 질환 |
| 반복 감염 | 정상 면역글로불린 억제 |

> 고령 환자에서 빈혈 + 신부전 + 고칼슘혈증 조합 → 다발성골수종 적극 배제

### 초기 평가 검사 (1차의료 시행 가능)

| 검사 | 목적 |
|------|------|
| CBC + 감별계산 | 빈혈, 혈소판, 백혈구 |
| CMP (종합대사검사) | 칼슘·신기능·간기능 |
| **SPEP** (혈청 단백전기영동) | M-protein spike 확인 |
| **UPEP** (소변 단백전기영동) | Bence-Jones 단백 확인 |
| 소변검사 (UA) | 단백뇨 |
| TSH | 갑상선 이상 배제 |
| X-ray (증상 부위) | 용해 병변·골절 |

### 확진 검사 (전문의 영역)

- 혈청 면역고정전기영동 (serum immunofixation)
- 혈청 유리경쇄검사 (serum free light chain assay)
- CT 또는 PET-CT (전신 용해 병변)
- 골수 생검 (형질세포 비율 ≥10%)

## 처방/치료

> 치료 결정·실행은 **혈액종양내과 영역**. 1차의료 역할은 의심·의뢰·추적·지지.

### 표준 치료 흐름

```
유도 치료 (3~4제 병합요법)
→ 자가 줄기세포이식 (ASCT — 이식 적격 시)
→ 유지 치료 (lenalidomide 등)
```

**보조 치료:**
- 비스포스포네이트 (zoledronic acid) 또는 Denosumab → 골 보호, 골절 예방
- VTE 예방 (aspirin 또는 항응고제 — 면역조절제 사용 시)

## 1차의료 역할

- **최초 발견**: 고령 + 빈혈 + 신부전 + 고칼슘혈증 + 뼈 통증 → 초기 검사 시행
- **의뢰**: SPEP/UPEP M-protein 확인 시 → 혈액종양내과 **즉시 의뢰**
- **협력 관리** (의뢰 후 지속):
  - 합병증 모니터링 (감염·빈혈·신기능·고칼슘혈증)
  - 심리사회적 지지 및 완화 의료 연계
  - 동반 질환 관리 유지 (당뇨·고혈압·골다공증)
  - 재발·재발 신호 감시 (지속 피로·뼈 통증 재발·감염 반복)

---

## 의뢰 기준

- 초기 평가에서 다발성골수종 의심 → **혈액종양내과 즉시 의뢰**
- 신부전 + 고칼슘혈증 + 빈혈 조합 → **긴급 의뢰**
- 척추 압박골절 + M-protein → 정형외과·신경외과 동시 의뢰 고려
