# 황반변성 환자 스테로이드 주의 (Macular Degeneration — Systemic Steroid Caution)

keywords: 황반변성, AMD, age-related macular degeneration, 스테로이드 금기, systemic steroid contraindication, solondo, methylprednisolone, 안과 협진

## 정의 / 범위 (definition)

황반변성(특히 wet AMD·CSC 병력) 환자에서 **전신 코르티코스테로이드 사용 시 황반부종·삼출 가속·중심성 장액성 망막병증(CSC) 유발·악화 위험**. 따라서 단기 burst라도 처방 전 안과 상태 확인·대안 약제 우선 고려가 원칙. 일차의료 cross-link hub 역할.

- [[cervical-lymphadenitis]] Solondo 단기 (김근전 외래 routine)

- [[asthma]] OCS burst — 안과 협진
- [[urticaria]] short course steroid — 안과 협진

### 김근전 교수님 강의 원칙 [TIPS — by 김근전 교수님]

> "황반변성 병력이 있는 사람에게는 스테로이드를 주의하고 금기이다."

- **전신 경구·정맥 스테로이드** — 황반변성 환자에서 일반적으로 금기 또는 신중 사용
- **국소·흡입·INCS** — 전신 흡수 낮으면 비교적 허용 (안과 의견 참고)
- **외래 routine 처방 전 안과력·시력 변동 단서 확인 필수**

## 문진 — 처방 전 5초 체크 [TIPS — by 김근전 교수님]

- 황반변성·CSC·중심성 장액성 망막병증·당뇨망막병증 진단력
- 시력 변동·중심 시야 왜곡·암점·메타모르프시아(직선 휘어짐)
- 안과 추적 중인지·최근 주사치료 (anti-VEGF) 이력
- 스테로이드 noted 시기·반응
- 동반 녹내장 (안압 상승 위험 별도)

> 환자에게 "녹내장 / 백내장 / 황반변성 / 망막 주사 맞으신 적 있나요?" 단순 단어 질문이 가장 효과적

## 대안 (alternative)

### 경구 스테로이드 회피·감량 옵션

- **돌발성 난청·메니에르 급성기** → **Intratympanic Steroid (ITS)** 우선 (전신 노출 ↓) — ENT 협진
- **Ramsay Hunt** → 항바이러스 단독 + 안과 협진 (스테로이드 보류 시 회복률 영향 — 사전 안과 평가)
- **임파선염** → NSAID + 항생제 단독 (스테로이드 생략 가능) — 김근전 외래 routine에서 solondo 부분만 제거
- **부비동염·두드러기** → INS / 항히스타민 / leukotriene 차단 / anti-IgE — 전신 스테로이드 회피

---

## 의뢰 기준 (referral)

- 황반변성 진단력 있는 환자에서 **불가피한 전신 스테로이드 적응증** (예: 심한 천식 발작·자가면역 질환) → **안과 사전 의뢰** + 최단기 최저용량 + 안과 모니터링
- 시력 변화·중심 시야 왜곡 호소 → 안과 즉시
- 스테로이드 시작 후 시력 변화 → 약 중단·안과 즉시

---

## 비고 (notes)

- AMD 자체에 스테로이드가 직접 진행을 가속한다는 high-quality 근거는 제한적이지만, CSC·황반부종은 코르티코스테로이드 유발·악화가 명확. AMD 환자에서 동반 CSC·황반부종 위험 평가 가능성 때문에 **신중 사용·안과 협진** 원칙이 임상 표준.
- INCS·국소 스테로이드는 전신 흡수가 낮아 안과 단서 없으면 사용 가능 — 단, 안압·각막 부작용 별도 평가.
- 김근전 강의의 "금기" 표현은 안전 우선 임상 원칙 — 절대 금기가 아닌 신중 사용/대안 우선.
