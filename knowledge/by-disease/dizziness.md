## 문진/검사

### 어지럼증 기본 문진 [TIPS — 교수님 외래 참관]
1. 언제부터 어지러웠는지
2. 갑자기 발생했는지
3. 과거 비슷한 episode 있었는지
4. 한번 어지러울 때 얼마나 지속되는지
5. 괜찮을 땐 완전히 괜찮은지 (삽화성 vs 지속성)
6. 심한 정도 — 구역/구토 동반 여부, 휘청거림
7. 귀먹먹함(이충만감) 동반 여부
8. 이명 동반 여부
9. 만성이라면 한달 발생 빈도
10. 어떤 상황에서 특히 어지러운지 (자세변화, 기립, 스트레스 등)
11. 가장 최근 episode는 언제

### 편두통성 어지럼증 추가 문진
- 편두통 과거력 확인
- 두통 동반 여부, 빛·소리 과민, 구역/구토, 전조증상, 두통 양상(박동성/지속시간), 가족력, 발작 빈도

### 환자가 "어지럽다"고 할 때 [TIPS — by ENT 교수]

- "어지럽냐"고 물으면 다 어지럽다고 함 → **구체화 질문** 필수:
  - **"걸을 때 비틀거리거나 중심을 못 잡은 적 있는지"**
  - 이 질문이 진짜 vertigo·ataxia 감별의 시작점

### 어지럼증 초진 검사 표준 [TIPS — by ENT 교수]

| 항목 | 확인 |
|---|---|
| 구토 여부 | 동반 여부·빈도 |
| 일상생활 지장 정도 | 침상안정·휘청거림 정도 |
| **Head Impulse Test (HIT)** | 말초 vs 중추 감별 (catch-up saccade 유무) |
| **Tandem gait** | 소뇌·후순환 의심 시 |
| 난청·이명·귀 먹먹함 | 메니에르·내이수종 감별 |
| **고막 시진** | 외이염·중이염·천공 |

> HIT abnormal + skew deviation 없음·nystagmus 단방향 = **HINTS 양성 → 말초성**
> HIT normal + skew deviation 있음·nystagmus 변화 = **HINTS 음성 → 중추성 의심 (소뇌 경색)**

### 귀에 물약 → 일시적 어지럼 [TIPS — by ENT 교수]

- 귀에 물약을 넣었을 때 어지러울 수 있음
- 원인: **물약이 차가움 → 외이도 내 온도 자극 → caloric stimulation**
- 환자 교육: **물약을 손에 잠시 쥐어 체온 정도로 데워서** 점안

## 감별진단

### Horses — 흔한 원인 (빈도순)

1. **[[BPPV]]** — 자세 변화 시 수초~1분 내 소실. 가장 흔함(말초성 현훈의 절반 이상)
2. **전정신경염** — 바이러스 후 급성 지속성 현훈. 청력저하 없음. 오심·보행장애 동반
3. **편두통성 어지럼증 (Vestibular migraine)** — 편두통 과거력 + 반복성 어지럼. 두통 없이 어지럼만 올 수 있음
4. **기립성 저혈압** — 기립 시 어지럼. 노인·탈수·강압제 복용자
5. **메니에르병** — 반복성 현훈 + 이명 + 편측 청력저하 + 이충만감 동반

### Zebra — 드물지만 절대 놓치면 안 됨

- **⚠ 소뇌경색 / TIA** — 갑작스러운 발병. 보행장애, 두통, 복시·안면마비·구음장애 동반 시 즉시 의심. RedFlag 영역.

[출처: AAFP Am Fam Physician 2017, NCBI StatPearls]

## 의뢰 기준

### 척추동맥 도플러 — 90%는 불필요 [CLINICAL — 조건부]

> 출처: Kurşun O, Karataş H. Vertebral Artery Doppler Necessity in Vertigo Patients. Noro Psikiyatr Ars 2025;62(3):256-258. PMID:40950820, DOI:10.29399/npa.28793
> 어지럼증 환자 1,021명 후향 분석 (단일 신경과 클리닉).

**핵심 수치:**
- 약 **90%** — 유의한 척추동맥 죽상경화 없음
- **5.1%** — 혈역학적으로 유의한 척추동맥 병변
- 유의 병변은 **≥60세 + 심혈관 위험인자 보유 남성**에 집중

**검사 의뢰 기준 (실전 적용):**

| 환자 | 도플러 권고 |
|---|---|
| <60세 + 심혈관 위험인자 없음 | **생략 가능** — 불필요한 검사·비용 절감 |
| ≥60세 + 심혈관 위험인자 있음 (HTN·DM·이상지질·흡연) | **고려** — 5.1%에서 의미 있는 병변 발견 |
| Red flag 동반 (보행장애·복시·구음장애·편측 위약) | 도플러가 아닌 **즉시 뇌영상·응급 의뢰** |

**주의:**
- 도플러는 red flag (소뇌·뇌간 경색 의심) 환자의 **적합한 first-line이 아님** — 정상 결과가 후순환 뇌졸중을 배제하지 못함.
- 외래 어지럼증에서 **선택적 의뢰 기준**으로서의 의미. 일반 루틴 screening 금지.
