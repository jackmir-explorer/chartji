# BPPV (양성돌발성체위성현훈)

keywords: BPPV, 이석증, 양성돌발성체위성현훈, 체위성현훈

## 문진/검사
- 자세변화 시 갑작스러운 어지럼증 → BPPV 의심
- 1단계: Supine Head Roll Test — Horizontal canal 안진 확인
- 2단계: 안진 없으면 Dix-Hallpike Test — Posterior canal 안진 확인

## 처방/치료

### 약물치료 [TIPS — by ENT교수]
- 약물은 이석정복술에 비해 효과 제한적
- 증상이 매우 심할 때 PRN으로 보나링(meclizine) po 처방 가능
- 반드시 안내: "너무 심할 때만 복용, 졸릴 수 있음"

### 이석정복술
Horizontal canal 안진 시:
- 바닥으로 beating (Geotropic): 병변 = 안진이 강하게 발생하는 쪽
- 천장으로 beating (Apogeotropic): 병변 = 안진이 약하게 발생하는 쪽
- 치료: Barbeque Roll (병변 반대방향으로 360도 회전)

Posterior canal 안진 시:
- 병변 = beating 반대방향
- 치료: Modified Epley Maneuver (병변 방향에서 시작)
