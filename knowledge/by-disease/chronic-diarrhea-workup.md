## 정의 / 범위 (definition)

**4주 이상** 지속되는 묽은 변 (Bristol 6-7) 또는 빈도 증가 (>3회/일). 흔한 원인: **IBS · IBD · celiac disease · microscopic colitis · bile acid diarrhea · 약물 · post-infectious**. **빈혈 동반 시 IBS 가정 금지**, organic etiology 적극 감별.

---

## 초기 평가 — "IBS 가정 금지" 적응 [CLINICAL]

> ⚠ 다음 red flag 중 하나라도 있으면 IBS로 진단·증상약 처방 금지 → organic workup 우선:

| Red flag | 의심 진단 |
|---|---|
| **빈혈** (특히 IDA) | celiac · IBD · colon cancer |
| **체중감소** | IBD · 악성 · celiac (malabsorption) |
| **혈변 / FOBT+** | IBD · colon cancer · diverticular |
| **야간 설사** | organic (IBS는 야간 드묾) |
| **50세 이상 신규 발생** | colon cancer 우선 평가 |
| **발열 / CRP↑** | IBD · 감염 |
| **가족력 IBD·celiac·colon cancer** | screening 문턱 ↓ |
| **B symptoms** | 악성 |

> Burgers K *AFP* 2020 (PMID:[32293842](https://pubmed.ncbi.nlm.nih.gov/32293842/))

## 최소 1차 검사 [CLINICAL]

> AGA 2019 + AAFP 2020

| 검사 | 목적 |
|---|---|
| **CBC** | 빈혈 (IDA = celiac/IBD/colon cancer 신호) |
| **CRP / ESR** | 염증 (IBD) |
| **Anti-tissue transglutaminase IgA + total IgA** | **celiac screening** (총 IgA 결핍 환자 false-negative 회피) |
| **TSH** | hyperthyroid |
| **BMP (electrolyte, BUN, Cr)** | 탈수·신기능 |
| **LFT, albumin** | malabsorption |
| **Fecal calprotectin (또는 lactoferrin)** | **IBD 감별 — 정상이면 IBD 가능성 ↓** |
| **FOBT 또는 FIT** | 혈변 / colon cancer screening |
| **Stool culture, C. difficile toxin** | 감염 후 지속 시 |

> ⚠ **Ova & parasite는 routine 비권고** (저수율, AGA 2019). 여행력·면역저하 시만.

## "만성 설사 + 빈혈" 적극 감별 cluster [CLINICAL]

### 1. Celiac disease
- Anti-tTG IgA + total IgA → 양성 또는 high suspicion → 십이지장 생검 (EGD)
- IDA가 GI 증상보다 먼저 또는 단독 발현 가능
- HLA-DQ2/DQ8 음성이면 사실상 배제

### 2. IBD (Crohn·UC)
- Fecal calprotectin >150-250 μg/g → 내시경
- ESR·CRP·anemia·hypoalbuminemia
- Colonoscopy + ileoscopy + 생검

### 3. Colorectal cancer
- 50세 이상 (한국 국가검진 45세부터) 신규 발생 → 우선 colonoscopy
- FIT/FOBT 양성 → colonoscopy
- 가족력 → 문턱 ↓
- [[colorectal-cancer-screening]] 상태 점검

### 4. Microscopic colitis
- 50세+ 여성, watery diarrhea, 정상 colonoscopy 육안
- 진단: random biopsy (좌·우 결장)
- 약물 유발 (NSAID·PPI·SSRI·statin) 확인 → 중단 시도

### 5. Bile acid diarrhea
- 회장 절제·Crohn·cholecystectomy 후
- SeHCAT scan 또는 empirical cholestyramine 반응으로 진단

## ⚠ IBS 가정 전 처방 금기 [CLINICAL]

> 미르 [INSIGHTS — 임상 경험]: "IBS 진단 전에 Dicetel·Norzyme·Fotagel 등 증상약 처방하면 organic etiology 진단 지연·놓치는 사례 반복"

- Red flag 1개 이상 → **증상약 중지**, 위 workup 진행
- 정상 workup + Rome IV 기준 충족 → IBS 진단, [[ibs]] 관리

---

## 의뢰 기준 (referral)

- Red flag (위 표) → 소화기내과
- Anti-tTG 양성 → 소화기내과 (EGD + duodenal biopsy)
- Fecal calprotectin 상승 → 소화기내과 (colonoscopy)
- 50세+ 신규 / 가족력 / FOBT 양성 → colonoscopy
- IDA + 만성 설사 → 동시 위·대장 내시경 ([[anemia]] workup + GI source)

---

## 비고 (notes)

- 만성 설사 환자의 ~10-15%가 IBD·celiac·colon cancer 등 organic 원인 (Burgers AFP 2020)
- IBS는 진단명이 아닌 *증후군* — Rome IV 기준 + organic 배제 후 진단
- **빈혈 동반은 IBS와 양립 어려움** — 항상 organic 우선

## 환자 교육 (patient communication)
