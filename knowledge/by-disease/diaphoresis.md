## 정의 / 범위 (definition)

**야간발한 (night sweats)** = 잠옷·시트가 젖을 정도의 수면 중 발한, 주변 온도와 무관. **일반 발한 (diaphoresis)** = 다른 trigger (열·운동) 없이 일어나는 과도 발한. 둘 다 비특이 증상이지만 야간발한은 결핵·림프종·HIV 등 systemic disease의 cardinal symptom이다.

## 9축 감별 [CLINICAL]

> Bryce C *AFP* 2020 — 1차 의료에서 만성 야간발한 환자 대부분 양성, 단 9 카테고리 systematic 평가 필요.

| 축 | 진단 예 | 단서 / 검사 |
|---|---|---|
| **감염** | TB·HIV·EBV·CMV·endocarditis·brucellosis·osteomyelitis | TB workup (IGRA·흉부 X-ray), HIV, serology |
| **악성** | 림프종·백혈병·고형암 (renal·hepatic) | CBC + diff, LDH, 흉부 X-ray, LAP·HSM 평가 |
| **갑상선** | hyperthyroidism | TSH, free T4 |
| **당뇨** | 야간 저혈당 (특히 인슐린·sulfonylurea) | 야간 혈당 측정, HbA1c |
| **심혈관** | unstable angina·MI (발한 prodrome) | ECG, troponin (suspicious 시) |
| **자율신경** | autonomic neuropathy (당뇨·파킨슨·다계통 위축증) | 기립성 BP, 신경학 |
| **약물** | SSRI·SNRI·opioids·항우울제·tamoxifen·acetaminophen·corticosteroid taper | 약물 reconciliation |
| **호르몬** | 폐경·perimenopause·androgen deficiency·pheochromocytoma | FSH·estradiol (여), testosterone (남), metanephrine if suspicious |
| **심리/수면** | anxiety·panic·PTSD·OSA·악몽 | PHQ-9·GAD-7, 수면평가 ([[sleep-apnea]]) |

## 야간발한 vs 일반 발한 [CLINICAL]

| 항목 | 야간발한 (significant) | 일반 발한 |
|---|---|---|
| **정의** | 잠옷·시트 흠뻑 젖음 → 옷 갈아입어야 | 흘리는 정도, 환경 무관 |
| **첫 평가 우선순위** | TB·림프종·HIV·갑상선 | 약물·자율신경·다한증 |
| **B symptoms 동반?** | weight loss·발열 → 즉시 systemic workup | 단독이면 양성 가능성 ↑ |
| **AAFP minimum workup** | CBC·LDH·TSH·HIV·CRP·흉부 X-ray·IGRA | 약물력·trigger 평가 우선 |

## 1차 외래 minimum workup [CLINICAL]

> Bryce C *AFP* 2020 권고

- CBC with diff
- LDH (림프종·용혈)
- TSH
- HIV
- CRP / ESR
- TB testing (IGRA 또는 PPD)
- 흉부 X-ray
- (남성) testosterone, (여성) FSH·estradiol — 임상 단서 시
- (선택) 야간 혈당, 24h urine metanephrine — 단서 시

---

## Red flags → 즉시 systemic workup [CLINICAL]

- 체중 감소 (>5% 6개월)
- 발열 (>38℃)
- LAP (특히 supraclavicular)
- 비대한 림프절·HSM
- 야간 통증 (림프종·악성)
- 항히스타민·진통제 무반응

> [[lymphadenopathy]] + [[ldh-interpretation]] 동시 평가

## 비고 (notes)

- 외래 환자 대부분 양성 (폐경·기분장애·GERD·갑상선·비만) — Bryce 2020
- 그러나 결핵·림프종은 *야간발한이 dominant symptom* → minimum workup으로 cover 필수
- 단발성 발한은 약물·trigger 점검 우선

## 의뢰 기준 (referral)

- B symptoms + 야간발한 → 혈액종양·감염내과
- TB·HIV 양성 → 감염내과·보건소
- pheochromocytoma 단서 (paroxysmal 고혈압·두통·심계항진 + 발한) → 내분비
