## 정의 / 범위 (definition)

EBV(Epstein-Barr virus) 원발 감염에 의한 바이러스 증후군. **발열·인두염·후경부 림프절병증** 3주징. 15~24세에 가장 흔하고, 타액을 통해 전파.

---

## 진단·평가 (indication / exam)

### 임상 3주징

- 발열
- 인두염 (pharyngitis)
- **후경부 림프절병증** (posterior cervical lymphadenopathy)

> 이 3가지가 모두 있으면 mono 감별을 우선 고려.

### 검사 순서 [CLINICAL]

1. **CBC with differential**
   - >40% 림프구
   - >10% 비정형 림프구 (atypical lymphocytes)
2. **Rapid heterophile antibody test (Monospot)**
   - Sensitivity 87%, Specificity 91%
   - **False-negative**: 5세 미만 소아, 발병 첫 주 (1주 내 검사 시 위음성 가능)
3. 이종친화성항체 음성 + 임상 강력 의심 시 → **EBV VCA-IgM 검사** (더 민감·특이적, 비용↑ 처리 지연)
4. **간효소 상승** → heterophile 음성이라도 EBV 의심 강화 단서

## 처방/치료 (protocol)

### 치료 원칙 — 보존치료(supportive care) [CLINICAL]

- **항바이러스제 routine 사용 비권고** (acyclovir·valacyclovir 등)
- **Corticosteroid routine 사용 비권고**
  - 일부 합병증(기도 폐쇄, 혈소판감소성 자반, 용혈성 빈혈 등)에는 고려 가능하나 routine 사용 금지
  - 림프종 감별 전 steroid는 조직학적 진단 mask 위험 ([[lymphadenopathy]] 참조)
- 수분 충분히, 해열·통증 완화 (NSAID·acetaminophen)
- 편도·인두 중증 시 기도 확보 주의

### 운동 복귀 — 비장파열 예방 [CLINICAL]

- **발병 후 3주간 접촉 스포츠 및 격렬한 운동 금지**
  - 비장비대 합병증 시 비장파열 위험
- 복귀 시기: **shared decision-making** (환자·보호자와 함께 결정)
- 초음파로 비장 크기 확인 후 복귀 고려 가능

## 주의사항 (precaution)

### Ampicillin / Amoxicillin 처방 금지 [CLINICAL]

- EBV 감염 중 ampicillin·amoxicillin 투여 시 **전신 발진(마쿨로파풀러 발진)** 높은 빈도 발생
- 인두염에 편의상 항생제 처방 시 EBV를 먼저 배제할 것

### 면역저하 환자 — 중증 위험 ⚠ [CLINICAL]

- 면역저하 환자에서 EBV 감염은 중증 경과 및 유의한 이환율 위험
- 이식환자·HIV·화학요법 중 환자에서 EBV 재활성화 또는 원발 감염 주의

## EBV와 암·자가면역 연관 [INSIGHTS]

> Sylvester JE et al. AFP 2023 (PMID:36689975)

EBV 감염은 **9가지 암** 발생과 연관:
- Hodgkin 림프종
- Non-Hodgkin 림프종
- 비인두암 (nasopharyngeal carcinoma)
- 기타 (위암·버킷림프종·등)

일부 자가면역 질환과도 연관 보고.

→ EBV 감염 기왕력은 추후 림프절병증 재발·LAP+발열 재평가 시 악성 감별에서 고려.

## 감별진단 [CLINICAL]

| 질환 | 구분 포인트 |
|---|---|
| **CMV 단핵구증** | heterophile 음성 → CMV IgM 검사 |
| **Streptococcal pharyngitis** | 전경부 LAP, tonsillar exudate; mono-spot 음성 + rapid strep 양성 |
| **HIV 급성 감염** | 위험인자 + 비침습적 LAP ± 피부 발진 → HIV 선별 |
| **림프종** | 무통·단단·고정 LAP; B symptoms; LDH 상승 → steroid 전 workup 필수 |
| **약물 유발 LAP** | phenytoin·allopurinol 복용력 |

---

## 의뢰 기준 (referral)

- 기도 위협 (심한 편도 부종) → 즉시 응급
- 비장파열 의심 (갑작스런 좌측 복통·쇼크) → 즉시 응급
- 합병증: 혈소판감소·용혈성 빈혈·신경학적 증상 → 전문과 의뢰
- 면역저하 환자 → 감염내과
