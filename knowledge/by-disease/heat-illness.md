## 스펙트럼 분류 (differential)

> [출처: Gauer RL et al. Am Fam Physician. 2026;113(4):369-381. PMID:42101601]
> [초록 기반 — 전문 미확인]

| 중증도 | 질환 | 핵심 특징 |
|---|---|---|
| **경미** | 열부종 (Heat edema) | 사지 부종 |
| 경미 | 열발진 (Heat rash) | 땀샘 폐색 피부 발진 |
| 경미 | 열경련 (Heat cramps) | 심한 운동 후 근경련, 저나트륨 관련 |
| **중등도** | 운동 관련 허탈 (Exercise-associated collapse) | 활동 직후 쓰러짐, 의식 명료 |
| 중등도 | 열탈진 (Heat exhaustion) | 허약·피로·두통·오심·구토, 체온 <40°C, CNS 정상 |
| 중등도 | 운동 횡문근융해 (Exertional rhabdomyolysis) | 근육통·갈색뇨·CK↑ |
| **응급** | 열사병 (Heat stroke) | 핵심 체온 **>40°C + CNS 변화** — 즉각 냉각 필수 |
| 응급 | 중증 운동 관련 저나트륨혈증 | 혼돈·경련, 열사병과 감별 필수 (치료 다름) |
| 응급 | 낫모양 적혈구 특성 관련 허탈 | 운동 중 갑작스러운 허탈, 높은 사망률 |

### 열탈진 vs 열사병 감별 (핵심)

| 항목 | 열탈진 | 열사병 |
|---|---|---|
| 체온 | <40°C | **>40°C** |
| CNS 변화 | **없음** (의식 명료) | **있음** (혼돈·의식저하·경련) |
| 긴급도 | 중등도 — 안정·냉각 | **응급 — 30분 내 즉각 냉각** |

## 고위험군 (precaution)

> 열관련 질환 위험 증가 약물·상태 — 처방 재검토 근거

| 위험인자 | 기전 |
|---|---|
| **이뇨제** 복용 | 수분·전해질 고갈 |
| **항콜린제** 복용 (항히스타민·방광약·항정신병약 등) | 발한 억제 → 체온 조절 장애 |
| **항정신병약** 복용 | 발한 억제 + 체온조절 중추 영향 |
| 고령·소아 | 체온조절 능력 저하 |
| 순화(acclimatization) 미완성 | 더위 적응 전 고강도 활동 |
| 최근 질병·탈수 | 생리적 예비능 감소 |
| 과도한 의복·장비 | 열 발산 방해 |
| 비만·심폐 기저질환 | 열 발산 효율 저하 |

**처방 연결:** 이뇨제·항콜린제 복용 환자 → 고온 노출 전 복약 재검토 및 수분 섭취 강조

## 처방/치료 (protocol)

### 경미한 열관련 질환
- 활동 중단, 시원한 환경으로 이동
- 경구 수분 보충 (전해질 포함)
- 경미 열경련: 스트레칭 + 생리식염수 경구 보충

### 열탈진
- 안정 + 수분 보충 + 기본 냉각 (선풍기·그늘·분무)
- IV 수액 필요 시 (경구 섭취 불가)
- 30분 관찰 후 증상 지속 또는 악화 → 열사병 가능성 재평가

### 열사병 — 즉각 응급 처치 [CLINICAL]

> ⚠ 열사병은 **30분 이내 핵심 체온 하강**이 생사 결정

1. **얼음물 침수 냉각** (Cold water immersion) — 냉각 속도 최우선 방법
   - 샤워·선풍기보다 냉각 속도 현저히 우월
   - 병원 이송 대기 중에도 현장에서 즉시 시작
2. 목표 체온: 핵심 체온 <39°C까지 냉각
3. 기도·호흡·순환 유지 + 즉시 응급실 이송
4. IV 수액 (생리식염수)
5. 모니터링: 간기능·신기능·혈액응고·CK (다장기부전 감별)

### 중증 운동 관련 저나트륨혈증 — 열사병과 치료 방향 다름
- 저나트륨혈증이 원인 → 과도한 저장성 수액 금지
- 혈중 Na+ 확인 후 고장성 생리식염수 고려

## 예방 상담 (protocol)

### 순화 (Acclimatization)
- **10~14일에 걸쳐 점진적 더위 노출** → 심폐 적응·발한 증가
- 새 환경·새 계절 시작 시 강도 즉시 올리지 않도록 교육

### 고위험군 외래 상담 핵심
1. 이뇨제·항콜린제·항정신병약 복용자 → 폭염 시 주의 사항 교육
2. 충분한 수분 섭취 (갈증 전 음수 습관)
3. 폭염 경보 시: 야외 활동 자제 + 시원한 환경 유지
4. 가족·보호자: 고령 환자 이상 행동(혼돈·의식 변화) → 즉시 응급 연락

## 환자 교육 (notes)

> "열탈진과 열사병은 다릅니다. 더위에 지쳐서 쓰러졌는데 정신이 멀쩡하면 열탈진, 의식이 흐릿하거나 헛소리를 하면 열사병입니다. 열사병은 즉시 찬물에 담가 식히고 119를 불러야 합니다. 혈압약이나 이뇨제를 드시는 분은 폭염 때 특히 조심하세요."
