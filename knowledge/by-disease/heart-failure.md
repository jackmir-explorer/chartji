## 정의 (definition)

심부전은 심장이 구조적·기능적 이상으로 전신에 필요한 혈액을 충분히 박출하지 못하거나, 충분히 받아들이지 못해 증상·징후(호흡곤란·부종·피로)가 발생하는 임상 증후군이다. 단일 질환이 아니라 다양한 심혈관·대사 원인이 수렴하는 최종 표현형이다.

## 분류 (classification)

### LVEF 기반 (2021 Universal Definition)

| 구분 | LVEF | 특징 |
|---|---|---|
| HFrEF (Heart Failure with reduced EF) | ≤ 40% | 수축기능 저하. GDMT 4 pillars 대상 |
| HFmrEF (mildly reduced EF) | 41 – 49% | 중간 범주. HFrEF 치료 일부 준용 |
| HFpEF (preserved EF) | ≥ 50% | 이완기능 장애 중심 |

HFmrEF·HFpEF는 BNP↑ 또는 구조이상/충만압 상승 근거 추가 필요.

### ACC/AHA Stage A/B/C/D (2022)

> 근거: 2022 AHA/ACC/HFSA HF Guideline (Circulation)

| Stage | 정의 | 약물 |
|---|---|---|
| **A** "At Risk" | 고위험군 (HTN·DM·비만·대사증후군·가족력·심독성 항암제) | 위험인자 조절 (ACEi/ARB·statin) |
| **B** "Pre-HF" | 구조적 이상 (MI·심비대·EF↓·판막) **또는 BNP/NT-proBNP 지속 상승** + **무증상** | ACEi/ARB 우선, BB 추가, 시술/수술 |
| **C** | 구조적 이상 + **유증상** | **GDMT 4 pillars (HFrEF)** ↓ + 이뇨제 (울혈), Digoxin (보조) |
| **D** | **불응성·반복 입원** (advanced HF) | LVAD·심장이식·완화치료 |

> ⚠ Stage B 정의에 **BNP/NT-proBNP 지속 상승**도 포함됨 (2022 ACC/AHA 갱신).

### Stage 유발 약물 — 회피 또는 주의

- **NSAIDs** — 모든 stage 회피
- **Verapamil / Diltiazem (non-DHP CCB)** — HFrEF 회피
- **BB** — 안정 HFrEF의 핵심 치료, **급성 비대상성에선 주의** (잘못된 시점 X)

> 출처: 2022 AHA/ACC/HFSA HF Guideline / 2021 Universal Definition (Bozkurt B, JCF 2021) / 대한심부전학회 2022

## 문진/검사 (exam)

### 증상·징후
- 호흡곤란 (운동 시 → 안정 시 → 좌위 호흡 순으로 진행)
- 하지 부종, 체중 증가
- 피로·운동능력 저하
- 야간 기침, 발작성 야간 호흡곤란(PND)
- 경정맥 팽대, 폐 수포음, S3 gallop

### 초기 평가 (일차진료 가능 범위)
- 병력·신체진찰
- 심전도 (좌각차단 등 비정상 시 주의)
- 흉부 X선 (심비대·폐울혈)
- **NT-proBNP 또는 BNP** — cutoff 환경별 차이 (ESC 2021):
  - **외래 (비급성) rule-out**: BNP <35 / NT-proBNP <125 (초과 시 ECHO)
  - **응급실 (급성) rule-out**: NT-proBNP <300 (age-adjusted rule-in: <50세 450, 50~75세 900, >75세 1800)
- 혈액검사: CBC, 전해질, BUN/Cr, LFT, TSH, 철 대사(ferritin, TSAT), HbA1c
- 심초음파 (LVEF 확인 — 상급기관 필요 시 의뢰)

> 출처: 대한심부전학회 심부전 진료지침 2022

### Volume Overload 진단 정확도 — BNP + POCUS B-lines [CLINICAL]

호흡곤란 환자에서 심인성 부하과다(volume overload) 감별. JAMA 2026 Rational Clinical Examination — 40개 연구, 11,490명, 유병률 35–69%.

**Rule-in (가장 유용한 순)**

| 검사 | LR | 특이도 |
|---|---|---|
| BNP ≥100 ng/mL | **6.9** | 87% |
| CXR 혈관 충혈 | 5.9 | 91% |
| JVD (흉골각 위 >3 cm 수직) | 4.1 | 92% |
| POCUS bilateral B-lines | 4.0 | 77% |
| IVC collapsibility <50% | 3.9 | 79% |
| POCUS JVP >8 cm | 2.8 | 71% |
| 폐 수포음 (crackles) | 2.7 | 81% |
| 하지 부종 | 2.2 | 80% |

**Rule-out (가장 유용한 순)**

| 검사 | LR | 민감도 |
|---|---|---|
| POCUS B-lines 없음 | **0.09** | 93% |
| BNP <100 ng/mL | 0.14 | 87% |
| IVC collapsibility ≥50% | 0.22 | 82% |
| POCUS JVP ≤8 cm | 0.26 | 81% |

임상 포인트: BNP ≥100이면 단독 최강 rule-in, B-lines 없으면 단독 최강 rule-out. 두 검사 조합이 JVD·crackles보다 진단 정확도 우월하며 외래·응급 의사결정을 직접 지원한다.

> 출처: Drum B et al. JAMA 2026;335(13):1159-1168. PMID:41729549. DOI:10.1001/jama.2026.0446

## 단계별 치료 (protocol)

### 1차 표준치료 — GDMT 4 Pillars (HFrEF)
동시 또는 빠른 순차 titration이 원칙. **용량 titration은 전문의 영역**.

1. **ARNI / ACEi / ARB** — 안지오텐신 수용체-네프릴리신 억제제(ARNI) / 안지오텐신전환효소억제제(ACEi) / 안지오텐신 수용체 차단제(ARB)
2. **Beta-blocker** — 베타차단제
3. **MRA** — 염류코르티코이드 수용체 길항제 (Spironolactone, Eplerenone)
4. **SGLT2 inhibitor** — SGLT2 억제제

> GDMT 약물별 시작·목표 용량표 → [[heart-failure-gdmt-dosing]]

### 2차 추가치료
- 동율동·안정 시 분당 심박수 70회 이상 → **이바브라딘**
- 표준치료에도 심부전 악화로 입원 필요 → **베리시구앗**
- 심박수 조절 필요한 심방세동 → **디곡신**

### 비약물
- 좌심실보조장치(LVAD), 심장이식, 완화치료 (중증·말기)
- ICD/CRT-D (부정맥 예방)

> 출처: 대한심부전학회 심부전 진료지침 2022

## 금기 (contraindication)

- ACEi → ARNI 전환 시: **최소 36시간 wash-out** 필요 (혈관부종 위험)
- 양쪽 콩팥동맥 협착
- 임신 (ACEi/ARB/ARNI/SGLT2 모두 금기)
- 기타 약물별 절대금기는 개별 제품 허가사항 참조

## 의뢰 기준 (referral)

> 상급병원 의뢰 절차·I NEED HELP 약어·전원 최적시기 4단계 곡선 상세 → [[heart-failure-referral]]

### 진료지침에 따른 심부전 전문가 의뢰 6시점

1. **좌심실 박출률(LVEF)과 상관없이 새롭게 발생한 심부전**
2. **만성 심부전에서 위험요인이 새롭게 발생하거나 지속적으로 보일 때**
   - 수축기 혈압 < 90 mmHg 이하이거나 증상이 동반된 저혈압
   - (지속적인 또는 반복적인) 주사용 강심제가 필요할 때
   - 폐울혈에 의해 NYHA class III–IV 증상이나 심각한 피로가 지속될 때
3. **3개월 이상 지침기반 약물치료(GDMT)에도 지속적인 LVEF ≤ 35%**
4. **심부전의 원인으로 2차적인 소견이 요구될 때**
   - 심근염 의심 시, 심장판막질환·판막교정이 도움될 가능성, 관상동맥질환에 대한 재관류 치료가 도움될 가능성
5. **매년 환자의 전반적인 검토를 통한 예후 및 근본적인 치료 계획 수립**
6. **임상연구 등록 가능성 평가**

### Stage D 중증 심부전 의심 약어 — I NEED HELP
중증 심부전(Stage D HF)의 대표적 예시: Persistent or progressive severe LV failure / Repeated worsening (ER visits or hospitalization) / Persistent severe symptoms (NYHA Fc III–IV).

| 약어 | 의미 |
|---|---|
| **I** | **I**notropes need (강심제 필요) |
| **N** | **N**YHA Fc IV |
| **E** | **E**nd-organ dysfunction |
| **E** | **E**F < 20% |
| **D** | **D**efibrillator shock for VAs |
| **H** | Recurrent **HF** hospitalization |
| **E** | **E**scalating diuretics dose |
| **L** | **L**ow BP |
| **P** | **P**rogressive GDMT intolerance |

### HFrEF vs HFpEF 약물 차이 (comparison)

| 구분 | HFrEF | HFpEF |
|---|---|---|
| 기본 약물 | GDMT 4 pillars (ARNI/ACE/ARB + BB + MRA + SGLT2) | SGLT2 억제제 + RAS 차단제 + 이뇨제 |
| 이바브라딘 | 동율동·HR ≥ 70 조건부 추가 | 일반 권고 아님 |
| 베리시구앗 | 표준치료에도 악화 시 | 일반 권고 아님 |

### 동반 고혈압 관리 (핵심 권고사항)
- LVEF 무관, BP **≥ 140/90 mmHg**일 때 약물치료 권고.
- HFrEF: ACEi/ARB·BB·이뇨제·알도스테론길항제 우선. 미달 시 DHP-CCB 추가.
- HFpEF: HFrEF와 유사 기준·목표.
- 좌심실비대 동반: RAS 차단제 + CCB + 이뇨제 조합, SBP **120–130 mmHg** 목표.

### 동반 당뇨병 관리 (핵심 권고사항)
- CV 위험 높은 T2DM (현재 심부전 없어도) → **SGLT2 억제제** 표준.
- 심부전 + T2DM → **SGLT2 억제제 ([[sglt2-inhibitors|empagliflozin]] / [[sglt2-inhibitors|dapagliflozin]])** 표준.

## Spironolactone vs Furosemide — 역할 다름 [CLINICAL]

> 근거: Pitt B et al. RALES (Randomized Aldactone Evaluation Study). N Engl J Med 1999;341(10):709-717. PMID:10471456; Heidenreich PA et al. 2022 AHA/ACC/HFSA Guideline for the Management of Heart Failure. PMID:35379503

"Spironolactone이 Lasix보다 부드러우니 안전" 인식은 **오해** — 두 약 역할이 자체로 다르다. 이 환자에선 오히려 반대일 수 있음.

| | **Furosemide (loop diuretic)** | **Spironolactone (MRA)** |
|---|---|---|
| 주 역할 | **울혈 제거 (감량 이뇨)** | HF **예후 개선 약** (이뇨 효과 약함) |
| 효과 발현 | 빠름, 강력 | 느림, 약함 |
| K | 낮춤 | **높임** |
| 신기능 의존 | eGFR 낮아도 증량하면 작동 | **eGFR <30에서 위험·효과 제한** |
| HFrEF 사망률 | 미입증 (증상 완화 목적) | **30% 감소** (RALES NEJM 1999) |

### 임상 결정
- **급성 울혈 (호흡곤란·부종·NT-proBNP ↑↑)** → Furosemide (loop) — 강력·빠른 감량 이뇨
- **만성 HFrEF GDMT 4-pillar** → MRA (spironolactone·eplerenone) — 예후 개선 약물
- **두 약 병용** — HFrEF 표준 (loop은 증상 조절, MRA는 mortality 감소)
- K 모니터 — MRA + ACEi/ARNI 병용 시 hyperkalemia 위험 (특히 eGFR <30)

울혈성 prerenal AKI 외래 결정은 [[cardiorenal-aki-diuretic-management]] 참조.
