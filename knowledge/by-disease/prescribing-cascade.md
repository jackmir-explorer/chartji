## 정의 (definition)

처방 연쇄(Prescribing Cascade, PC): **기존 약물의 부작용(ADR)을 새 질환 증상으로 오인하여 추가 약물을 처방하는 패턴**. 84가지 ADR이 추가 처방을 유발하는 것으로 확인(우산 고찰, 190개 연구 분석). 고령 다약제 환자에서 부적절 폴리파머시의 핵심 기전.

> [출처: Carollo M et al. Drugs Aging 2026. PMID:41949780]

## 노인 외래 — 새 증상 발생 시 약물력 우선 점검 [TIPS — by 미르 경험]

### 노인 부종 → NSAIDs 문진 필수

> 노인에서 이유 없이 붓는 경우 **NSAIDs를 꼭 문진해야 한다**.

- NSAID-induced edema: PGE2 차단 → renal sodium retention
- 동반 약물: 칼슘 차단제(amlodipine), TZD, gabapentin
- 새 부종 → '왜 이 약을 시작했는지'·'기존 약 변경됐는지' 동시 점검
- Cascade 회피: 이뇨제 추가 전 NSAIDs 중단·교체 우선 시도

### 노인 스테로이드 처방 전 사전 확인 [TIPS — by ENT 교수]

스테로이드 처방을 결정하기 전 **반드시 4가지 확인**:

| 확인 | 이유 |
|---|---|
| **당뇨** | 혈당 상승 — DM 환자도 처방 가능하지만 혈당 모니터링·환자 교육 필수 |
| **황반변성** | 스테로이드는 황반변성 악화 가능 — **다른 옵션 우선 고려** |
| **녹내장** | 안압 상승 |
| **위궤양·BPSD** | 소화기 출혈·정신 증상 악화 |

> **DM이 있다고 절대 금지가 아님** — "혈당 상승에 유의하시라"는 환자 교육 필수.
> 황반변성은 다른 선택지(NSAID·국소 치료 등) 우선.

### Cascade 방지 핵심 질문

새 증상 호소 노인 환자에서 **첫 질문은 "기존 약 부작용?"** —
- 부종 → NSAIDs·CCB·TZD?
- 변비 → CCB·항콜린제·opioid?
- 기침 → ACEi?
- 어지럼 → 항고혈압제·BZD·항히스타민?
- 인지 저하 → 항콜린제 burden·BZD?

→ STOPP/START·Beers criteria 활용 우선, 추가 처방은 마지막 수단.

## 주요 원인 약물과 cascade 패턴 (notes)

### 가장 흔한 원인 약물군

| 약물군 | 대표 ADR | 추가 처방 cascade 예시 |
|---|---|---|
| **항우울제** | 구역·불면·성기능 장애 | 항구토제·수면제·PDE5 억제제 추가 |
| **항치매약 (AChEI)** | 구역·서맥·요실금 악화 | 항구토제·항부정맥제·항무스카린제 추가 |
| **항정신병약** | 파킨슨 유사증상 | 항파킨슨제 추가 |
| **항고혈압제** | 어지럼증·기립성 저혈압·부종 | 항구토제·이뇨제 추가 |
| **지질강하제 (스타틴)** | 근육통 | 진통제·근이완제 추가 |
| **벤조다이아제핀/수면제** | 낙상·혼동 | 항불안제·항정신병약 추가 |

### 대표적 처방 연쇄 사례

**예시 1**: CCB (칼슘차단제) → 발목 부종 → 이뇨제 추가 → 전해질 이상 → 보충제 추가

**예시 2**: 도네페질(AChEI) → 오심 → 항구토제(메토클로프라미드) → 지연성 운동 이상증 → 항파킨슨제

**예시 3**: 프로프라놀롤·베타차단제 → 우울증 증상 → 항우울제 추가

**예시 4**: NSAID → 위장 증상 → PPI 추가 → 마그네슘 저하 → 보충제 추가

## 감별 포인트 (differential)

### 새 증상 발생 시 반드시 물어야 할 것

**"최근 처방 변경(새 약 추가·용량 변경)이 있었나요?"**

| 새 증상 | 의심 cascade 유발 약물 | 확인 방법 |
|---|---|---|
| 어지럼증·기립 어려움 | 항고혈압제·이뇨제·항우울제 | 기립성 혈압 측정; 약물 시작 시점 대조 |
| 파킨슨 유사 증상 | 항정신병약·메토클로프라미드 | 약물 중단 후 경과 관찰 |
| 오심·구역 | AChEI·오피오이드·메트포르민 | 용량·투여 시간 조정 시도 |
| 근육통 | 스타틴·피브레이트 | CK 측정; 약물 중단 후 반응 |
| 변비 | 오피오이드·항콜린제·칼슘 보충제 | 원인 약물 조정; 하제 우선 |
| 요실금 악화 | AChEI·이뇨제 | 투약 시간 조정; 항무스카린제 cascade 주의 |

## 처방/치료 (protocol)

### 처방 연쇄 감별·중단 알고리즘

1. **타임라인 확인** — 새 증상과 처방 변경 시점 비교 (PSSA 방법론)
2. **의심 약물 일시 중단** — 부작용 vs 질환 감별
3. **중단 후 증상 소실** → 처방 연쇄 확인 → 원인 약물 중단·대체
4. **중단 후 증상 지속** → 다른 원인 탐색 (진단 재고)

### Deprescribing 도구 활용
- **Beers Criteria** — 고령 부적절 약물 목록
- **STOPP/START 기준** — 고령 처방 검토 도구
- **MedStopper 앱** — 중단 순서 제안 온라인 도구

---

## 모니터링 (monitoring)

- 고령 다약제(≥5종) 환자 재진: 매 3~6개월 약물 목록 전체 재검토
- 새 약 추가 후 2~4주: 새로운 증상·변화 적극 확인
- 처방 연쇄 의심 시 → 의심 약물 중단 후 2~4주 추적

---

## 기타 특이사항 (notes)

처방 연쇄는 **인지되지 않은 채 지속**되는 것이 가장 큰 문제. "새 약이 필요한 증상인가 vs 기존 약 부작용인가"를 매번 자문하는 습관이 핵심 예방법. 고령 외래에서 다약제 처방 전 반드시 cascade 가능성 점검.
