## 정의

심장·신장·빈혈이 **서로를 악화시키는 악순환 삼각**. "Cardiorenal syndrome"에 빈혈이 끼면서 굴러가는 바퀴를 강조한 개념. 한 축만 건드려선 잘 안 풀리고, 하나 호전되면 나머지 둘도 호전 — 반대로 한 축 급격 악화 시 연쇄 무너짐.

## 임상 단서 — 통합 인식

| 신호 | 의미 |
|---|---|
| **NT-proBNP ↑ + Cardiomegaly + pulmonary congestion + 부종** | HF 울혈 |
| **BUN/Cr >20** | Prerenal 색채 (cardiorenal) |
| **eGFR <60 (특히 <45)** | EPO 부족 기여 (KDIGO 2012) |
| **Hgb <11 + 부적절하게 낮은 reticulocyte (ARC <100K)** | 저생산성 빈혈 |
| **TIBC ↓ + ferritin 정상~상승** | ACD-like (hepcidin 매개) |
| **넓은 맥압 + flow murmur + 빈맥** | 빈혈의 심장 보상 |

## 평가 패널

- CBC w/diff + RBC indices + **Reticulocyte·ARC·IRF·RET-He**
- Ferritin·Iron·TIBC·TSAT·**hepcidin** (가능 시)
- BUN/Cr·eGFR·UA·ACR
- **NT-proBNP** (or BNP)
- TTE (LVEF·structural assessment)
- TSH (저하증 동반 평가)
- B12·Folate

## 치료 원칙 — 3 축 동시 개입

### 1. HF 안정화 ([[heart-failure]] GDMT)
- 4-pillar (ACEi/ARNI·BB·MRA·SGLT2i) — 단 K·신기능 모니터
- 울혈 시 loop diuretic — **용적 상태 기반** ([[cardiorenal-aki-diuretic-management]])

### 2. CKD anemia 교정
- EPO·ESA (erythropoiesis-stimulating agent) — eGFR <30·Hgb <10 (KDIGO 2012)
- **IV iron** (ferric carboxymaltose 등) — ferritin <100 또는 TSAT <20%
- Target Hgb 10-11.5 (over-correction 회피 — CV event ↑)

### 3. 빈혈 교정 → HF·신장 호전 기대
- 적절한 빈혈 교정으로 cardiac output 보상 부담 ↓ → HF·신장 stabilize 가능
- 단 over-correction (Hgb >12) → 혈전·사망 ↑ (TREAT·CHOIR trial)

---

## 의뢰 기준

- eGFR <30 또는 Hgb <10 → 신장내과 (ESA·IV iron 결정)
- LVEF <40% + 빈혈 → 심장내과 + 신장내과 협진
- 급성 악화 (Hgb 급락·BUN/Cr 급등·울혈 악화) → 응급 / 입원
- Hgb <8 또는 증상 동반 (DOE·syncope) → 수혈 검토
