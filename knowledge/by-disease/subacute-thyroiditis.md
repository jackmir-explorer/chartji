## Clinical Features

- **호발**: 30-50대 여성
- **선행 URI history** — **2-8주 전, 약 50-70%**
- **갑상선 부위 통증 + 압통** (가장 특징적)
- 통증: 한쪽에서 시작 → 반대쪽 확산 가능 / 턱·귀로 방사
- 갑상선 swelling·firm
- 발열·피로 동반 가능

### 갑상선 기능 phase 변화

```
1-3개월: Hyperthyroid (destruction 방출) ─→
       : Euthyroid (transient) ─→
       : Hypothyroid (transient) ─→
       : Recovery (대부분 1년 내)
```

> 5-15% 영구 hypothyroid (long-term LT4 필요)

---

## 진단 기준

| Major | 내용 |
|---|---|
| 1 | Anterior neck pain·압통 (갑상선) |
| 2 | **ESR >50 mm/hr 또는 CRP elevated** |
| 3 | Thyroid sono: **hypoechoic area + reduced vascularity** |
| 4 | RAIU <5% (한국 routine X) |
| 5 | TFT 변화 (early hyperthyroid) |

**진단 강도**:
- 1+2 = strong clinical suspicion
- 1+2+3 = clinical diagnosis
- 1+2+3+4 = definitive

> 외래에서는 1+2+3 + 임상 경과로 진단·치료 시작 가능 (RAIU 없이).

## 관리

### Mild (통증·증상 경한 경우)
- **NSAIDs**: ibuprofen 400-600mg q6-8h **또는** naproxen 500mg BID
- **1-2주 trial**
- 통증·압통 control이 목표
- 갑상선 기능 자연 회복 — methimazole 부적절

### Moderate-Severe (심한 통증·증상)
- **경구 Prednisolone 40mg/day** 시작
- 1-2주 후 평가, 점진 감량 (**4-8주 tapering**)
- 통증 빠른 호전 — 호전 후 감량 시작

### Hyperthyroid phase 증상 동반
- **β-blocker** (propranolol·atenolol·bisoprolol) — 일시적·증상 완화 목적
- ⚠ **Antithyroid drug (methimazole) 부적절** — destruction이 원인 (production 아님)

### Hypothyroid phase (3-6개월 후)
- 일시적 hypothyroid 가능
- 증상 동반 시 **단기 LT4**
- 대부분 자연 회복

## 추적

| 시점 | 검사 |
|---|---|
| 초진 + 2-4주 | TFT·ESR·CRP·sono |
| 6개월 | TFT 회복 확인 |
| 12개월 | TFT 영구 hypothyroid 배제 |

> 대부분 1년 내 완전 회복. 5-15% 영구 hypothyroid — long-term LT4 필요 ([[thyroid-disorder]] subclinical hypothyroid 참조).

## 감별진단

| 진단 | 단서 |
|---|---|
| **De Quervain (subacute)** | 통증·압통 + 선행 URI + ESR 매우 ↑ |
| Painless thyroiditis (postpartum) | 통증 없음·산후·전신 sx 적음 |
| Suppurative thyroiditis (acute) | 농양·심한 발열·세균 |
| Hashimoto 급성 악화 | anti-TPO 강양성·만성 경과 |
| Graves' disease (silent) | 통증 없음·RAIU ↑·TRAb 양성 |

---

## 의뢰 기준

- Severe + Prednisolone 반응 부족 → 내분비
- 영구 hypothyroid 확정 (12개월 TSH ↑) → 내분비 또는 [[thyroid-disorder]] 외래 본체로 이행
- Suppurative thyroiditis 의심 (농양·심한 발열·중독 양상) → 응급/내분비
