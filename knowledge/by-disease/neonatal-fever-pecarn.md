## PECARN 저위험 기준 (exam) [CLINICAL]

> [출처: Burstein B et al. JAMA 2026;335(5):425-433. PMID:41359314]
> 4개 전향 코호트 풀드 분석, n=1,537명(생후 ≤28일), 6개국.

**저위험 3기준 (모두 충족 시 저위험):**

| 검사 | 저위험 컷오프 |
|---|---|
| 소변검사/딥스틱 | **음성** |
| 혈청 프로칼시토닌 | **≤0.5 ng/mL** |
| 혈액 절대 호중구 수 (ANC) | **≤4,000/mm³** |

---

## 진단 정확도 (exam)

| 지표 | 수치 (95% CI) |
|---|---|
| **민감도** | **94.2%** (85.6–97.8%) |
| **특이도** | 41.6% (36.7–46.7%) |
| **양성예측도** | 6.9% (4.8–9.9%) |
| **음성예측도** | **99.4%** (98.1–99.8%) |

- 저위험 판정 환자 비율: 41.1% (n=632/1,537)
- **세균성 수막염은 저위험 판정 환자에서 단 1건도 없음**
- 전체 침습세균감염(bacteremia+뇌수막염) 유병률: 4.5% (n=69)

## 외래 결정 분기 (differential) [CLINICAL]

```
발열 신생아 (≤28일, ≥38.0°C, 정상 출현, 만삭)
      ↓
PECARN 3기준 평가
 (소변검사 / PCT / ANC)
      ↓
┌─────────┬──────────────────────────────────────┐
│ 저위험   │ 3기준 모두 충족                       │
│         │ → LP 선별적 적용 고려 (공유의사결정)  │
│         │ → 입원·주의 관찰 지속 필요            │
└─────────┴──────────────────────────────────────┘
      ↓
┌─────────┬──────────────────────────────────────┐
│ 고위험   │ 1개 이상 비충족                       │
│         │ → 루틴 LP + 균혈증 패혈증 workup      │
│         │ → 입원·경험적 항생제                  │
└─────────┴──────────────────────────────────────┘
```

**일차의료·응급실 적용:**
- 저위험 분류 시 LP를 **모든 환자에 루틴 시행 대신 선별 적용** 가능한 근거 — 공유의사결정 기반
- 저위험에서도 **세균성 수막염 미검출 가능성 5.8%** (민감도 94.2%) — 완전 배제 아님
- 이상 출현(ill-appearing), 미숙아, 기저질환 → 적용 제외

---

## 주의사항 (precaution)

- 이 연구 대상: 건강했던(previously healthy)·정상 출현·만삭 신생아 — ill-appearing·미숙아 제외
- PCT 검사 가용성 확인 필요 (국내 응급 검사 가능 여부 [출처 미확인 — researcher 검증 권장])
- LP 선별 적용 시 보호자와 **공유의사결정** 필수 (잠재 위험 설명 포함)
- 저위험 판정 후에도 **증상 악화 시 재내원 지침** 필수
