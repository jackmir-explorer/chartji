## 분류 기준

| 유형 | 진단 기준 | 자연 경과 |
|------|-----------|----------|
| **급성 HBV** | HBsAg(+) + IgM anti-HBc(+) + 증상(황달·AST/ALT↑) | 성인 >95% 자연 회복 |
| **만성 HBV** | HBsAg(+) **6개월 이상** 지속 | 간경변·HCC 위험 |

---

## 문진/검사

### 급성 HBV

- 증상: 구역·구토·복통·황달 (잠복기 1~4개월)
- 검사: HBsAg, IgM anti-HBc, AST/ALT, 빌리루빈, PT
- **전격성 간염 RedFlag**: PT 연장 + 황달 + 의식 변화 → 즉시 전문의 의뢰

### 만성 HBV 초기 평가

| 평가 영역 | 검사 |
|----------|------|
| HCC 가족력 | 병력 청취 |
| 간기능·섬유화 | AST/ALT, 혈소판, FibroScan (간 탄성도) |
| 바이러스 상태 | HBeAg/HBeAb, HBV DNA (IU/mL) |
| 공존 감염 | Anti-HCV, Anti-HDV, HIV |

---

## 처방/치료 — 항바이러스제

### 치료 시작 기준

```
아래 중 하나 충족 시 치료 시작:
1. ALT 상승 + HBV DNA >2,000 IU/mL
2. 간경변 + 바이러스 검출 가능 (any level)
3. 면역억제요법(항암·생물학적제제 등) 시작 전 — 예방적 투여
```

### 1차 선택 약제

| 약제 | 용량 | 특이사항 |
|------|------|---------|
| **Tenofovir disoproxil fumarate (TDF)** | 300 mg PO 1일 1회 | 신기능·골밀도 모니터링 |
| **Tenofovir alafenamide (TAF)** | 25 mg PO 1일 1회 | TDF 대비 신·골 부작용 감소 |
| **Entecavir (ETV)** | 0.5 mg PO 1일 1회 (de novo) | 임신 카테고리 C |

- **내성 장벽 높음** → 장기 복용 가능 (중단 없이 유지)
- 기능적 치료 (HBsAg 소실) — 현행 치료제로는 드묾 (<10%/년)

### 예방적 투여 (면역억제 전)

- 적응: 항암화학요법·rituximab 등 생물학적제제·장기이식 전
- 치료 기준 미달이더라도 HBsAg(+)이면 예방 투여 권고

## 모니터링

### 치료 중 추적 검사

| 항목 | 주기 |
|------|------|
| AST/ALT | 3~6개월마다 |
| HBV DNA | 6~12개월마다 |
| 신기능 (TDF 사용 시) | 6~12개월마다 |
| HBeAg/HBeAb seroconversion | HBeAg(+) 환자 |

### HCC 감시 — 고위험군에서 6개월마다 필수

**대상**: 간경변 환자 / HCC 고위험군 (50세 이상 남성, 가족력, 지속 고바이러스혈증)

```
복부 초음파 (RUQ US) + AFP (알파태아단백)
→ 6개월마다 시행
```

---

## 의뢰 기준

- 간경변 확인·의심 → 소화기내과 공동 관리
- 치료 기준 충족 (ALT↑ + HBV DNA >2,000 IU/mL) → 항바이러스제 처방 시작 또는 전문의 협진
- 전격성 간염 → 즉시 응급·간이식팀
- HCC 의심 (초음파 결절·AFP 상승) → 소화기내과·영상의학과 즉시 의뢰
