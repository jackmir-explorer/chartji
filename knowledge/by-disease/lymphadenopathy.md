## 정의 / 범위 (definition)

림프절 크기·수·경도 이상. 일차의료에서 만나는 LAP의 **악성 prevalence ~1.1%** (대부분 양성·자기제한). 단 위치·동반 증상·기간에 따라 즉시 systemic workup 필요한 high-risk cluster 존재.

---

## 기록 필수 요소 [CLINICAL]

매 LAP 평가 시 7요소 명시:

| 항목 | 평가 |
|---|---|
| **위치 (location)** | 단일 부위 vs 양측·전신 / cervical·axillary·inguinal·supraclavicular·epitrochlear·popliteal |
| **크기 (size)** | 단축 직경 (cm), >1 cm 일반적 abnormal (epitrochlear >0.5, inguinal >1.5 cm tolerable) |
| **개수** | 단일 vs 다발 vs 매트 (matted) |
| **압통** | tender (염증) vs painless (악성·림프종) |
| **가동성** | mobile vs fixed (악성 의심) |
| **경도** | soft (양성) vs firm·rubbery (림프종) vs rock-hard (전이암) |
| **기간** | <2주 (감염), 2-6주 (반응성), >6주 (만성·악성 의심) |

## High-risk 위치·양상 — 즉시 systemic workup [CLINICAL]

> Gaddey HL *AFP* 2016 (PMID:[27929264](https://pubmed.ncbi.nlm.nih.gov/27929264/))

### 위치
- **Supraclavicular** — **크기 무관 악성 의심** (Virchow node, 좌측은 복부 악성 / 우측은 흉부 악성)
- **Epitrochlear >5 mm** — 림프종·sarcoidosis·secondary syphilis·HIV
- **Popliteal, iliac** — 정상에서 촉지 안 됨, 만져지면 악성·감염

### 양상
- **양측성·전신성** — 림프종·HIV·SLE·약물·sarcoidosis (cervical 단독이라도 양측이면 림프종 가능)
- **Matted (덩어리)** — TB·림프종·전이암
- **Painless + firm + fixed** — 악성 강한 의심
- **B symptoms 동반** (발열·야간발한·체중감소 >10%/6개월) — 림프종 staging 시급

## Risk factors for malignancy [CLINICAL]

> Gaddey HL *AFP* 2016

- 나이 **>40세**
- 남성
- 백인
- Supraclavicular 위치
- B symptoms (발열·야간발한·체중감소)
- 6주 이상 지속
- fixed·painless·firm 양상

## LAP + 발열 시 진단 전 steroid 금지 [CLINICAL]

> ⚠ **steroid 처방 전 minimum workup 완료 필수.**

이유:
- 림프종 mask — 림프종 세포 일시적 위축 → 진단 지연
- 자발성 TLS 위험
- 감염 progression (TB·EBV·CMV·HIV)

### Minimum workup 선행
- **CBC with differential** (atypical lymphocyte·blast)
- **LDH** ([[ldh-interpretation]] 참조 — 단계별 해석)
- **CRP / ESR**
- **Viral serology**: EBV (mono-spot, VCA-IgM), CMV IgM, HIV
- **Peripheral blood smear** — blast·atypical
- **흉부 X-ray** — mediastinal LAP·TB

→ Workup 완료·진단 명확 후 치료. steroid는 림프종·SLE 확진 후 종양혈액내과·류마티스 영역.

## 진단 알고리즘 [CLINICAL]

```
LAP 발견
├── 위치: Supraclavicular? → 즉시 systemic workup + 영상 (CT) + 의뢰
├── 양측·전신? → CBC, LDH, HIV, EBV, ANA, 흉부 X-ray
├── 단일·국소·반응성 (<2주, 압통+, mobile)?
│     → 인접 감염원 찾기 (구강·인두·피부·치주) → 원인 치료, 2-4주 F/U
└── 단일·국소·만성 (>6주) 또는 firm·fixed?
      → US ± FNA/core biopsy → 비정상 시 excisional biopsy
```

### 영상·조직 검사
- **US**: 첫 단계 영상 — size, shape, hilum 보존 여부, vascularity
- **FNA**: 감염성 의심 시 culture 가능, 림프종 진단 한계 (architecture 안 보임)
- **Core needle biopsy**: 림프종 진단 가능성 ↑
- **Excisional biopsy**: 림프종 의심 시 gold standard (whole node + architecture)

---

## 의뢰 기준 (referral)

- **Supraclavicular LAP** → 즉시 종양혈액내과 (긴 wait 안 됨)
- **High-risk 양상 (firm·fixed·painless·>6주)** → 외과 + 종양혈액내과
- **B symptoms 동반** → 종양혈액내과 staging
- **양측·전신 + 비특이 systemic 단서** → 감염내과 (HIV·TB) 또는 류마티스 (SLE·sarcoidosis)
- 조직 진단 필요 → 외과 (excisional biopsy)

---

## 비고 (notes)

- "Cervical LAP은 흔하고 양성" 일반화 위험 — 양측·matted·painless·firm은 림프종 가능
- LAP는 단발 평가가 아닌 **동반 증상 + 시간 경과** 함께 해석
- Cervical 단발 + 인접 감염원 명확 + 압통 → 4주 F/U 정상 (대부분 호전)
