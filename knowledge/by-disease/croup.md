## 정의

성문하 구조의 바이러스성 염증으로 인한 소아 상기도 폐쇄 질환.
- **주요 원인**: Parainfluenza virus (1형 가장 흔함)
- **유행 시기**: 10~11월 (가을)
- **호발 연령**: 6개월~3세

---

## 문진/검사

### 3대 증상 (Classic triad)

- 컹컹 짖는 기침 (barking/seal-like cough)
- 쉰 목소리 (hoarseness)
- 흡기성 협착음 (inspiratory stridor)
- 발열 동반 가능

### 중증도 평가 (Westley Croup Score)

| 점수 | 중증도 | 처치 방향 |
|------|--------|-----------|
| 0~2 | 경증 | 덱사메타손 단독 + 귀가 |
| 3~5 | 중등도 | 덱사메타손 + 흡입 에피네프린 + 관찰 |
| ≥6 | 중증 | 즉시 응급 이송 |

### 영상 검사

- 대부분 **불필요**. 진단 불명확 시만 고려
- AP 경부 X-ray: **Steeple sign** (성문하 협착) — 특이도 낮아 진단 기준 아님

---

## 감별진단 (응급 감별 우선)

| 질환 | 감별 포인트 |
|------|------------|
| **세균성 기관염 (Bacterial tracheitis)** | 고열 + 독성 외관(toxic appearance) + 덱사메타손 무반응 → 즉시 응급 기도 확보 |
| **후두개염 (Epiglottitis)** | 침 흘림 + 앞으로 기댄 자세(tripod) + 목 뻣뻣함 + 눕지 않으려 함 |
| **후인두농양 (Retropharyngeal abscess)** | 경부 강직 + 경부 X-ray 전방 연조직 비대 |
| **이물질 흡인** | 갑작스런 발병, 발열 없음 |
| **혈관성 부종** | 알레르기 노출력, 두드러기 동반 가능 |

## 처방/치료

### 경증 (Westley 0~2)

**덱사메타손 1회 경구 투여:**
```
Dexamethasone 0.6 mg/kg PO 1회 (최대 12 mg)
```
- 프레드니솔론 대체 가능 (1 mg/kg/day × 3일)
- 2~3시간 관찰 후 증상 개선 확인 → 귀가

### 중등도~중증 (Westley 3 이상)

```
Dexamethasone 0.6 mg/kg PO/IM 1회
+ 네뷸라이즈드 에피네프린:
    L-epinephrine 1:1,000 — 5 mL 흡입
    (또는 Racemic epinephrine 2.25% — 0.05 mL/kg, 최대 0.5 mL)
```

- 에피네프린 투여 후 **2~4시간 관찰 필수** (rebound 효과)
- 에피네프린 반응 없음 → 기도 확보 준비 + 응급 이송

### 권고하지 않는 처치

| 처치 | 이유 |
|------|------|
| Cool mist humidifier (가습기) | 근거 없음 |
| 1세대 항히스타민제 | 비권고 |
| 항생제 | 바이러스성에 불필요 (세균성 기관염 의심 시 제외) |
| 헬리옥스 (Heliox) | 응급 환경 외 일상 사용 근거 부족 |

---

## 의뢰 기준

- Westley ≥3 (중등도 이상) → 응급 평가 및 처치
- 덱사메타손 무반응 → 세균성 기관염·후두개염 의심 → **즉시 이송**
- **반복성 크루프** (3회 이상) → 해부학적 이상·기저 질환 평가 (이비인후과·소아과 의뢰)
