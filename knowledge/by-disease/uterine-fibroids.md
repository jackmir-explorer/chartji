## 정의 (definition)

자궁근종은 여성에서 가장 흔한 양성 종양. 대부분 **무증상**, 증상 있는 경우:
- 복부 팽만·빈뇨·변비 (자궁 크기 증가에 의한 압박)
- **월경과다 (AUB)**
- 골반통 / 성교통
- 불임

---

## 진단·평가 (differential)

### 초기 평가
- 전체 부인과 병력 + 복부·경질·경관 이중수지 진찰
- **1차 영상: 경질초음파(TVUS) + 경복초음파(TAUS) 조합** → 근종 위치·크기·개수 확인
- **MRI (조영제 포함)**: TVUS에서 불충분하거나 수술 계획 전 — 병변 범위 정밀 평가

### 감별
- 자궁내막용종 / 자궁선근증 / 자궁내막암 — AUB 호소 시 반드시 고려
- 난소 종양 (골반통 동반 시)

## 처방·치료 (protocol)

### 치료 결정 인자
| 인자 | 영향 |
|---|---|
| 근종 위치·크기 | 치료 방법 선택 |
| 임신 계획 | 보존 수술(근종절제술) vs 자궁절제술 |
| 폐경 근접 여부 | 약물 또는 경과 관찰 우선 가능 |
| 증상 정도 | 월경과다→약물 1차 / 압박 증상→시술/수술 |

### 약물치료 (AUB 조절 목적)

| 약물 | 기전 / 적응 |
|---|---|
| **복합 경구피임약 (COC)** | AUB 조절 1차 — 근종 크기 감소 효과 없음 |
| **프로게스틴 단독 경구** | AUB 조절 |
| **LNG-IUD (52mg)** | AUB 조절 효과적 — 자궁강 변형 없을 때 적합 |
| **NSAIDs** | 월경통 + AUB 보조 감소 |
| **Tranexamic acid** | AUB 출혈량 감소 (수술 대기 중 사용 가능) |
| **GnRH antagonist** (레루골릭스 등) | 수술 전 근종 축소 + AUB 조절; 장기 사용 시 골밀도 저하 주의 |
| **GnRH agonist** (류프롤라이드 등) | 수술 전 단기 사용; 골밀도 저하·갱년기 증상 부작용 |

**비타민 D 결핍**: 보충이 근종 크기 감소 또는 진행 억제에 도움될 수 있음 (초기 근거)

### 수술·시술 옵션

| 시술 | 적응 | 비고 |
|---|---|---|
| **자궁절제술 (Hysterectomy)** | 가장 확실한 치료 — 임신 불원하는 증상 중증 환자 | 완치적 |
| **자궁근종절제술 (Myomectomy)** | 임신 보존 희망 | 재발 가능 |
| **자궁동맥색전술 (UAE)** | 임신 불원, 수술 고위험 | 자궁 보존; 방사선 노출 |
| **고주파 절제술 (RFA)** | 특정 위치·크기 | 최소침습 |
| **고강도 집속 초음파 (HIFU)** | 실험적·제한적 | MRI 유도 필요 |

## 의뢰 기준 (referral)

**산부인과 의뢰:**
- 약물 실패 또는 수술 계획 시
- 근종이 자궁강 변형 → LNG-IUD 삽입 전
- 임신 불임 의심
- 악성 감별이 필요한 급성 성장 또는 폐경 후 근종

**1차의료 관리 가능:**
- 무증상 근종 경과 관찰
- TVUS 추적 (증상 변화 모니터링)
- 초기 약물치료 (COC·LNG-IUD·tranexamic acid) 시작

## 환자 교육

> "자궁근종은 대부분 악성이 아니고 무증상이면 그냥 두어도 됩니다. 월경 양이 많거나 통증이 있으면 먼저 약물로 조절해 보고, 임신 계획이 없으시다면 자궁에 삽입하는 호르몬 기구(IUD)도 효과적입니다. 약물로 안 되거나 크기가 계속 커지면 수술 여부를 전문과와 함께 결정하게 됩니다."

## 한계·주의

- 근종 위치(점막하·근층내·장막하)에 따라 치료 접근 상이 — TVUS로 위치 확인 필수
- GnRH 계열 장기 사용 → 골밀도 저하, add-back 요법 고려
- UAE 후 임신 성공률 저하 가능 — 임신 계획 환자에게 비권고
