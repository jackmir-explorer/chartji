## 배경

80세 이상 DOAC 사용자에서 출혈 위험이 유의미하게 증가.
뇌졸중 예방 이익(CHA₂DS₂-VASc) vs 출혈 위험(HAS-BLED)의 **재평가가 필요한 시점**.

---

## 출혈 위험 인자

| 위험 인자 | 임상 포인트 |
|----------|------------|
| **나이 ≥80세** | 독립 위험 인자 |
| **신기능 저하** | GFR 감소 → DOAC 배설↓ → 혈중 농도↑ |
| **저체중 (≤60 kg)** | 용량 조정 기준 |
| **낙상·프레일티** | 두개내 출혈 위험 |
| **다약제 복용** | NSAID·아스피린·일부 항생제와 상호작용 |
| **과거 출혈력** | 소화기 출혈 특히 주의 |
| **조절 불량 고혈압** | 뇌졸중+출혈 위험 동시 증가 |

### HAS-BLED 출혈 위험 점수

| 항목 | 점수 |
|------|------|
| Hypertension (수축기 >160 mmHg) | 1 |
| Abnormal renal function (Cr>2.3, 투석, 이식) | 1 |
| Abnormal liver function (간경변·빌리루빈>2배) | 1 |
| Stroke history | 1 |
| Bleeding history or predisposition | 1 |
| Labile INR (warfarin 시 TTR <60%) | 1 |
| Elderly (>65세) | 1 |
| Drugs (NSAID·항혈소판) | 1 |
| Alcohol (≥8 units/주) | 1 |

> HAS-BLED ≥3: 고위험 — 교정 가능 인자(혈압·NSAID·알코올) 적극 교정

## 처방/치료 — DOAC 선택 및 용량

### 80세 이상 DOAC 선택 지침

| 약제 | 고령 특이사항 | 용량 조정 기준 |
|------|-------------|----------------|
| **Apixaban** (아픽사반) | 고령 출혈 프로파일 가장 유리 | 2.5 mg BID: ≥80세 + 체중≤60 kg + Cr≥1.5 mg/dL 중 **2가지 이상** 해당 시 |
| Rivaroxaban | 1일 1회 편의 | GFR 15~50 시 15 mg qd |
| Dabigatran | 신장 배설 80% → 신기능 저하 시 특히 주의 | GFR <30 시 금기 |
| Edoxaban | — | 체중·신기능 기반 용량 조정 |

> 80세 이상에서는 **Apixaban 우선 고려** — 임상 근거 가장 많음

### 항응고 시작 기준 (심방세동)

- CHA₂DS₂-VASc ≥2 (남) / ≥3 (여) → 항응고 시작 권고 유지
- 나이 자체가 CHA₂DS₂-VASc 점수에 포함 (65~74세=1점, ≥75세=2점)

---

## 1차의료 적용

- 처방 전: GFR·체중·다약제 상호작용 확인
- 정기 모니터링: 신기능(6~12개월), 출혈 징후 교육
- **낙상 예방**: 항응고 중단 이유보다 낙상 예방에 집중 (낙상 위험만으로 항응고 중단 비권고)
- **공유의사결정 (SDM)**: 80세 이상에서는 뇌졸중 예방 이익과 출혈 위험을 환자·가족과 함께 논의
