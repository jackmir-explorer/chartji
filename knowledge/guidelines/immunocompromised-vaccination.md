## 일반 원칙

- **생백신 금기**: MMR·varicella·MMRV·oral typhoid·yellow fever·BCG·LAIV·oral polio. 항암치료 후 **≥3개월 대기** (CD4·림프구 회복 후)
- **사백신 안전** — 단 반응↓ 가능 (rituximab·고용량 스테로이드 중)
- **동거 가족** — 인플루엔자·MMR·VZV 접종 적극 권장 (cocoon strategy)
- 백신 효과 평가 — 가능하면 anti-HBs·anti-HAV·VZV IgG titer로 확인

## 권고 백신 5종

| 백신 | 면역저하 권고 | 비고 |
|---|---|---|
| **대상포진 (RZV/Shingrix)** | ≥19세 면역저하 우선 (ACIP 2022) | **사백신 OK·생백신(ZVL) 금기**, 항암 후 **3개월 이후** 접종 가능 ([[herpes-zoster-vaccine]]) |
| **인플루엔자** | 매년, **65세+ 4배 고용량(HD-IIV) 또는 adjuvanted** | LAIV(생백신) 금기 — IIV(사백신)만 |
| **폐렴구균** | ≥19세 PCV20/21 단독 또는 PCV15 → **≥8주 후 PPSV23** (간격 단축) | ACIP 2024 — ≥50세 universal PCV ([[pneumococcal-vaccine]]) |
| **RSV** | ≥60세 (또는 만성 폐·심 질환·면역저하) | 사백신/단클론 — 면역저하에 안전 |
| **COVID-19** | mRNA 추가 접종 + 매년 갱신 | 면역저하자 booster 횟수 비면역저하보다 많음 |

### 기타
- **Tdap** 10년 주기 + 임신부 27-36주 ([[tdap]])
- **HepB** anti-HBs <10 mIU/mL 시 series 재접종 ([[hepatitis-ab-vaccine]])
- HAV — anti-HAV 음성 + 위험요인 (간질환·여행)
- HPV — ≥27세 면역저하자 3-dose 권고 가능 ([[hpv-vaccine]])

## Rituximab/Anti-CD20 사용자 — HBV reactivation screening 필수

> 근거: IDSA 2013 + AGA HBV reactivation guideline

- **처방 전 필수 검사**: HBsAg + anti-HBs + **anti-HBc total**
- HBsAg(+) 또는 anti-HBc(+) → 간내과 의뢰 + entecavir/TDF prophylaxis (rituximab 종료 후 ≥6-12개월 유지)
- anti-HBs 음성 + anti-HBc 음성 → HepB vaccine series 권고 (단 rituximab 중 반응↓ — 가능하면 치료 시작 전 접종)
- 모든 백신은 가능하면 rituximab 시작 **2주 전** 접종 (B cell depletion 전)

## 항암치료 중 / 후 접종 timing

| 상황 | 접종 가능 시점 |
|---|---|
| 화학요법 중 | 사백신은 OK (반응↓), 생백신 금기 |
| 화학요법 종료 후 | **3개월** 이후 생백신 OK |
| 조혈모세포이식 후 | 6개월 사백신 / 24개월 생백신 (별도 schedule) |
| 고형장기이식 | 평생 생백신 금기 |
| 고용량 스테로이드 (PD ≥20mg/d × ≥2주) | 1개월 후 생백신 OK |

## 의뢰 기준

- HBV reactivation 위험 (HBsAg/anti-HBc 양성 + 면역억제 예정) → 간내과
- 백신 반응 부족 (반복 series 후 anti-HBs <10) → 감염내과·이식센터
- 이식 환자 백신 schedule 결정 → 이식 코디네이터
