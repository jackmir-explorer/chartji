## 핵심 항목별 요약 (notes) [INSIGHTS]

### 호흡기 감염
- **CAP 경구항생제:** 아지스로마이신 · 아목시실린-클라불란산 · 레보플록사신이 지역사회폐렴에 효과적 (텔리스로마이신 미국 미허가)
- **COVID 항바이러스 (면역저하):** 몰누피라비르·닐마트렐비르-리토나비르 → 면역저하 COVID 환자 입원 감소
- **소아 급성 부비동염:** 아목시실린(±클라불란산) → 증상 완화에 위약 대비 유효

### 예방접종·예방
- **영아 RSV:** 니르세비맙(nirsevimab) 단회 투여 → RSV 입원 감소
- **재발성 UTI (폐경 전 여성):** 락토바실루스 포함 프로바이오틱스 → 재발률 감소

### 감염성 피부질환
- **옴 (성인·청소년):** 벤질벤조에이트 25% → 고효과 (국내 허가 확인 필요)

### 소화기
- **IBS 2차 치료:** 저용량 아미트립틸린(amitriptyline) 유효 → 기존 경련 완화제 실패 시 선택지
- **단순 담석:** 보존적 관리(watchful waiting) — 수술 대비 합리적 대안 (무증상·경증)

### 당뇨·비만 [CLINICAL]
- **T2DM:** SGLT-2 억제제 + GLP-1 RA → 구식 약물 대비 환자중심 아웃컴 우월
- **연속혈당측정(CGM):** T2DM 혈당 조절에 최소 효과, 오히려 해 가능 → T2DM 일반 처방 주의
- **체중감량 최고 효과 약물:** 펜터민-토피라메이트 + GLP-1 RA
- **비당뇨 비만 심혈관 2차예방:** 세마글루타이드 유효
- **고령 T2DM + 심부전:** SGLT-2 / GLP-1 RA → 심혈관 사망 감소

### 심혈관
- **MI 후 보존 EF (HFpEF):** 베타차단제 → 재발 사건 예방 효과 없음 (처방 재고)

### 금연
- **바레니클린·NRT 실패 후:** 고용량 반복 시도 → 금연 성공률 추가 향상
- **전자담배(베이핑):** 금연 성공률 ↑, 단 장기 베이핑 의존성 위험 동반

### 알코올 사용 장애
- **경구 날트렉손·아캄프로세이트:** 안전하고 효과적 — 일차의료에서 처방 가능

### 기타
- **Long COVID 피로:** 인지행동치료(CBT) → 개선 효과
- **알츠하이머 신규 단일클론항체:** 해롭고(부작용), 비싸고, 효과 미미 → 일상 처방 비권고
- **나쁜 소식 전달:** 대면 또는 전화 — 의사 판단·환자 선호에 따라 선택

## 일차의료 즉시 적용 포인트 (notes)

1. T2DM에서 CGM 보험 상담 시 "혈당 조절 효과 제한적" 근거 제시 가능
2. 옴 의심 시 벤질벤조에이트 옵션 검토
3. IBS 2차 치료에 아미트립틸린 저용량 추가 (25mg TID 등)
4. MI 후 정상 EF 환자에서 베타차단제 불필요 → 다약제 재검토 기회
5. 알코올 문제 환자에 날트렉손/아캄프로세이트 처방 고려 (전문의 의뢰 전 1차 시도 가능)
