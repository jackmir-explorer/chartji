### 1. [비암성 만성통증·근골격] 발뒤꿈치 통증 — 진단·치료 실전 가이드
- **저널:** Am Fam Physician 2025;112(6):648-656 | **PMID:** 41533410
- **슬롯:** 1-B #1 비암성 만성통증·근골격 (AFP fallback — Pain Medicine 저널 2025-2026 해당 주제 발행 부족)
- **한 줄:** 연간 200만 건 외래 방문 원인; 재칼카네알 점액낭염(여성 40-60세·Haglund 변형)·소아 종골 골단염(Sever병, 소아 MSK 16%)·복사뼈 삼각골·비골건 손상까지 위치별 감별 + 보존 치료 1차 원칙 정리
- **왜 유용:** 외래에서 "발뒤꿈치 아픈데요" 호소 시 감별 체계 제공. 핵심 4가지: ①재칼카네알 점액낭염 ↔ 족저근막염 구별(압통 위치·Haglund 영상 소견); ②소아 활동적 환자에서 종골 골단염(Sever병) 우선 감별; ③비골건 손상 위험인자 — 스테로이드 국소주사·퀴놀론 항생제·RA·부갑상선항진증·DM; ④통증 파국화·운동공포증 → 보존 치료 불량 예후 인자(심리사회적 스크리닝 권고). MRI 정확도 최고, POCUS 활용 확대 추세. 시험용: "소아 스포츠 발뒤꿈치 통증 → 종골 골단염(Sever병) 우선; 비골건 손상 위험인자 = 스테로이드·퀴놀론·RA"

### 2. [암성통증·완화의료] 임종기 완화의료 — 가정의의 역할과 증상 관리 실전
- **저널:** Am Fam Physician 2025;112(5):493-503 | **PMID:** 41252832
- **슬롯:** 1-B #2 암성통증·완화의료
- **한 줄:** 임종기 통증·호흡곤란에 오피오이드 1차; 오심 = 수용체별 원인 타겟; 중증 OIC → mu-오피오이드 길항제(메틸날트렉손·날록세골); 섬망 → 원인 약물 감량 + 재지남; 기분 장애 → 슬픔과 우울 감별 + 예후·효과발현 시간 고려
- **왜 유용:** 말기 환자 가정·외래 관리 시 증상별 처치 결정 직접 적용. 핵심 5가지: ①통증·호흡곤란 공통 = 오피오이드; 보조제(gabapentin·항우울제·스테로이드)가 오피오이드 필요량 감소 및 지연; ②오심 → 화학수용체 자극대(도파민 차단) vs 전정계(항콜린) vs 위배출 저하(메토클로프라미드) 수용체 맞춤; ③변비 → osmotic + 자극성 완하제 병용, 중증 OIC = 메틸날트렉손(피하) 또는 날록세골(경구); ④식욕부진 → 환자 고통 없으면 치료 불필요, 비타민·보조제 근거 없음; ⑤섬망 → 원인약물 감량·단순화·환경 재구성 우선, 항정신병약은 심한 초조·환각에 한정. 시험용: "임종기 OIC → 메틸날트렉손 또는 날록세골(mu-길항제); 섬망 = 원인 교정 먼저"

### 3. [진단추론] 급성 단관절염 감별 — 패혈성 관절염 포함 성인 진단 체계
- **저널:** Am Fam Physician 2025;111(6):497-506 | **PMID:** 40531148
- **슬롯:** 1-C Diagnostic Reasoning (3일 cycle Day 2)
- **한 줄:** 급성 단관절염에서 패혈성 관절염 우선 배제 필수; 관절강 내(능동+수동 ROM 모두 감소) vs 관절 주위(수동 ROM 유지)로 1차 구별; 활액 gram 염색·배양이 최정확, 배양 대기 중 활액 WBC+젖산+혈청 바이오마커 보완; POCUS로 삼출액 확인 및 흡인 유도
- **왜 유용:** 외래 또는 응급실에서 단관절 부종·통증 환자 처치 체계 제공. 핵심 4단계: ①관절 내 vs 주위 구별(수동 ROM 검사); ②패혈성 관절염 조기 의심 트리거 — 발열·고위험(면역억제·관절내 이물·균혈증·성매개감염); ③진단 검사 우선순위 — gram 염색·배양(최정확) + 활액 WBC ≥50,000/μL·젖산 상승 = 패혈성 높음; ④통풍·가성통풍 = DECT·POCUS·임상 스코어 활용, 단 결정형 확인이 gold standard. 주의: 많은 다관절 질환(RA·세균성 심내막염 관련 관절염 등)이 단관절로 시작 → 감별 유지. 시험용: "급성 단관절 → 수동 ROM으로 관절내 구별 → 패혈성 의심 시 즉시 관절흡인·배양"

### 4. [외래응급] 손가락 끝 손상 — 외래 관리 알고리즘
- **저널:** Am Fam Physician 2025;112(1):47-54 | **PMID:** 40736493
- **슬롯:** 1-D Tier 2 외래응급 (8일 cycle Day 6)
- **한 줄:** 손톱 밑 혈종 → 관찰 or 천공; 조상(nail bed) 열상 → 손톱 제거 + 봉합; 원위지절 탈구(배측·과신전) → 도수정복 + 부목; 원위지절 골절 → 도수정복 + 부목(개방·관절면 1/3 초과 → 수부외과); 망치 손가락 → 6-8주 지속 고정; jersey finger(FDP) → 기능 회복 위해 수술 의뢰
- **왜 유용:** 외래·응급에서 손가락 끝 손상 즉결 처치 기준 제공. 핵심 결정 분기 6가지: ①손톱 밑 혈종 ≥50% → 천공(trephination)으로 감압, 조상 손상 없으면 손톱 보존; ②조상 열상 → 손톱 제거 후 흡수성 봉합(5-0 크롬 장선 등); ③원위지절 배측 탈구 → 근위로 당겨 도수정복 + 6주 신전 부목(복합형·개방형은 수부외과); ④원위지절 골절 → 관절면 1/3 이하 = 보존(부목), 초과 = 수부외과; ⑤망치 손가락(신전건 파열) → 8주 연속 DIP 신전 부목(중단 시 재설정); ⑥jersey finger(굴곡건 파열) → 방치 시 영구 굴곡 불능, 즉시 수부외과. 시험용: "망치 손가락 = 8주 연속 신전 고정; jersey finger = 수술 의뢰"
