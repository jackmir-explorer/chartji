# Iron Deficiency Anemia (Annals In the Clinic 2026)

- **PMID**: 41525691
- **저널 / 연도**: Annals of Internal Medicine 2026 Jan;179(1):ITC1-ITC16
- **저자**: Martens KL, DeLoughery TG et al.
- **출처 Scout**: inbox/scout/2026-05-07.md

## 초록 요약

철결핍성 빈혈(IDA)은 흔하면서도 과소 인식되는 상태다. 고위험군은 소아, 월경 중이거나 임신한 여성, 사회경제적 취약계층이며, 조기 진단과 적절한 철분 보충이 예방의 핵심이다. 단순 수혈은 충분한 elemental iron을 제공하지 못하며, 심혈관 불안정·활동성 출혈·중증 빈혈 시에만 철분 치료와 병행해 고려한다.

이 ITC 리뷰는 페리틴 진단 기준 재조정, 경구 철분 투여 최적화 방법(격일 투여), 정맥 철분 적응증 확장, 원인 검색 체계화 등 현재 근거 기반 업데이트를 종합 정리한다. 대안 빈혈 원인(MCV·맙상적혈구 기반 패턴)도 감별 프레임으로 제시한다.

## 주요 결과

| 업데이트 내용 | 내용 |
|---|---|
| **Ferritin 진단 기준** | 염증 없음 <45 / 염증 있음 <100 ng/mL |
| **경구 철분 최적 투여법** | 겠일 투여 — 헵시딘 억제로 흡수 극대화 |
| **IV 철분 우선 적응증** | 심부전 동반 IDA, 흡수 불량(IBD·위절제·celiac) |
| **원인 검색** | IDA 확인 즉시 양방향 내시경 + H. pylori + celiac 검사 |

## 배경·방법

철결핍 진단의 전통적 기준(ferritin <15)은 특이도는 높으나 민감도가 낙아 잠재 결핍을 놈쳤다. 이 리뷰는 기존 기준에서 cutoff를 상향 조정해 진단 민감도를 높이는 동시에, 경구 철분 복용 방식의 혁신(겠일 투여)과 정맥 철분의 확장된 역할을 근거 기반으로 정리했다. Annals ITC 형식으로 권고 요약과 실천 지침을 제공한다.

## 일차의료 적용 포인트

### 진단·평가

- **Ferritin cutoff 업데이트**:
  - 염증 지표(CRP/ESR) 정상 → **<45 ng/mL** 적용 (민감도 85%, 특이도 92%)
  - 염증 지표 상승 (만성질환, 감염, 류마티스) → **<100 ng/mL** 적용
  - 기존 <15 기준은 매우 특이적이지만 민감도가 낙아 잠재 IDA를 놈침

- **혈액 검사 패키지**: CBC + ferritin + iron + TIBC + CRP
  - CRP 없이 ferritin만 보면 cutoff 적용 불가 → 염증 여부 확인 필수

- **원인 검색 타이밍**:
  - IDA 확인 → 즉시 양방향 내시경 (특히 >50세·남성·폐경 여성)
  - H. pylori 검사: 제균이 철 흡수 개선에 기여
  - Celiac disease: 항-tTG IgA, IgA 결핍 주의

### 약물·처방 디테일

**경구 철분 — 겠일 투여 전환:**
- 매일 복용 시 헵시딘(hepcidin) 상승 → 장내 철 흡수 억제
- **겠일 복용 시 헵시딘 낙은 상태에서 흡수** → 동일 총량으로 더 많이 흡수
- 위장 부작용도 겠일 투여에서 감소 기대

| 항목 | 기존 | 업데이트 |
|---|---|---|
| 복용법 | 매일 | **겠일** 권장 |
| 기간 | 빈혈 교정 후 3개월 | 흡수 불량 시 더 길게 |

**정맥 철분 (IV iron) — 확장된 적응증:**
- **심부전 동반 IDA**: IV 철분이 경구보다 기능·증상 개선 우월
- **흡수 불량**: IBD·위·소장 절제·celiac → 경구 효과 기대 불가
- 경구 불내성 지속 / 빠른 교정 필요 (수술 전)
- [출처 미확인 — researcher 검증 권장]: 한국 IV 철분 급여 기준 (적응증별 인정 여부)

### 외래 결정 분기

```
IDA 진단 확정 (Hb↓ + ferritin <45/100 기준 충족)
├── 경구 철분 시작: 겠일 투여
│   ├── 4주 후 Hb 반응 확인
│   └── 반응 없으면 → 흡수 불량 가능성 → IV 철분 전환 고려
├── 원인 검색: 내시경 + H. pylori + celiac
└── 심부전 동반? → IV 철분 우선
```

### 환자 교육

> "철분제를 매일 먹으면 몸이 실제로 흡수하는 양이 줄어드는 경우가 있습니다. 하루 건너 먹는 것이 더 효과적인 방법입니다. 꾸준히 먹으면서 원인도 같이 찾아봐야 합니다."

## 한계·주의

- Ferritin <100(염증 동반) 기준은 ITC 저자 권고이며, 한국 진료지침 공식 채택 여부 확인 필요
- Annals ITC 형식 — 기존 문헌 요약이므로 원저 연구 설계 상세는 개별 논문 참조
- 겠일 투여 근거는 주로 건강 여성 대상 약동학 연구; 고령·중증 IDA 환자에 대한 별도 검증 한정적
