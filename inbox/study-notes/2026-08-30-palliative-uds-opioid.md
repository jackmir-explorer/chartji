# 완화의료 암성통증 UDS — 일상 소변약물검사, 근거 없고 해악 있다 (JPSM 2026)

## 미르의 첫 반응

> 마약진통제 용량 적정시 환자의 임상증상이 더 중요하다는 말 같다.

## 미르 반응 심화 (이 노트의 핵심)

미르가 정확하게 잡았다. 이 논문의 핵심 메시지: **"UDS 결과보다 환자의 임상증상이 오피오이드 용량 결정의 더 중요한 지표"**

### 왜 UDS가 임상증상보다 열등한 정보인가?

**UDS가 탐지하는 것:** 약물 대사 산물의 소변 내 검출 여부
**UDS가 탐지 못하는 것:** 환자의 통증 조절 상태, 기능 수준, 부작용 경험

| 임상 정보 | UDS | 환자 임상증상 |
|---|---|---|
| 통증 강도 변화 | ✗ | ✓ (NRS 등) |
| 기능 상태 (ADL, 수면) | ✗ | ✓ |
| 부작용 (변비·진정·오심) | ✗ | ✓ |
| 약물 남용·전용 | 간접 탐지 (위양성 多) | 행동 패턴 관찰이 더 민감 |
| 치료 결정 변화 | 드묾 | 직접 연결 |

### 오피오이드 용량 적정의 실제 핵심 지표 (임상증상 기반)

| 지표 | 증량 신호 | 감량/유지 신호 |
|---|---|---|
| **통증 강도 (NRS)** | ≥7/10 지속 | ≤4/10, 조절 양호 |
| **돌발 통증 빈도** | 하루 ≥3-4회 | 0-1회/일 |
| **기능 상태** | ADL 제한 지속 | 수면·보행·식사 유지 |
| **진정 수준** | 적절 진통 유지 | 과진정(졸림·호흡 억제) |
| **부작용** | 경미·조절 가능 | 심한 오심·변비·섬망 → 용량 재검토 |

→ 이것이 "환자의 임상증상이 더 중요하다"는 미르의 직관의 근거

### UDS의 진짜 함정: 이상 소견 = 실제 문제가 아닐 수 있다

- **UDS 이상 소견율 15-54%**: 넓은 범위 → 연구마다 크게 다름
- **이상 소견의 실제 의미**: 절반 이상은 임상 결정에 변화를 주지 않음 (미처리되거나 이미 알고 있는 정보)
- **위양성 교차반응**: 리팜핀(항결핵제), 요오드 조영제, 퀴놀론 항생제 → opioid 또는 기타 약물로 위양성

### 완화의료에서 오피오이드 모니터링의 올바른 접근

```
오피오이드 처방 중인 암성통증 환자
├── 매 방문: 임상증상 평가
│   ├── 통증 강도·성격 변화
│   ├── 기능 상태 (수면·식사·활동)
│   ├── 부작용 (변비·진정·오심)
│   └── 돌발 통증 빈도·구제약 사용량
├── 용량 조정 결정: 임상증상 기반
└── UDS: 임상적 의심 있을 때만 (개별화)
    ├── 환자가 복용을 부인하나 의심되는 상황
    ├── 이상 행동 패턴 (약 요구량 급격 증가, 여러 처방자)
    └── 약물 전용/남용 가능성 구체 근거 있을 때
```

### 4가지 해악 — 한국 완화의료 맥락

| 해악 | 한국 맥락 |
|---|---|
| 재정 독성 | 검사비 본인 부담 |
| 낙인(stigma) | 암 환자에게 "마약 중독자 의심" 메시지 → 신뢰 손상 |
| 부당한 진료 종료 | 이상 소견 → 오피오이드 처방 중단 → 통증 조절 실패 |
| 인종적 불균등 | 한국 맥락: 의료급여·저소득층 환자에서 더 자주 시행될 수 있음 [출처 미확인] |

## 초록 요약

완화의료·암성통증 오피오이드 환자에서 루틴 UDS의 안전성 종점 개선 근거 없음. NCCN·ASCO·CDC 권고하나 근거 수준 최저. 이상 소견율 15-54%이나 임상 결정 변화 비율 미보고. UDS 진단 정보 추가는 환자가 복용 부인할 때뿐. 4가지 해악 문서화. → 임상적 의심 있을 때만 개별화 시행 권고.

## 주요 결과

- 안전성 종점 개선 RCT: 없음
- 이상 소견 탐지율: 15-54% (연구마다 차이 큼)
- UDS 진단 추가값: 환자 부인 시에만
- 4가지 해악: 재정 독성·낙인·진료 종료·인종 불균등

## 배경·방법

- SANRA(Scale for the Assessment of Narrative Review Articles) framework 적용 내러티브 리뷰 + 비판 분석
- 대상: 완화의료·암성통증 오피오이드 처방 환자

## 일차의료 적용 포인트

### 외래 결정 분기

- 암성통증 오피오이드 처방 환자 → UDS 루틴 시행 비권고
- 용량 조정: 임상증상(NRS·기능·부작용) 기반
- 개별 UDS 적응증: 복용 부인·이상 행동·다처방자 의심·구체적 전용 근거

### 환자 교육

> "통증약을 잘 조절하고 있는지 확인하는 가장 중요한 방법은 환자분의 통증이 어떤지, 활동하기 편한지, 부작용은 없는지 직접 들어보는 것입니다."
