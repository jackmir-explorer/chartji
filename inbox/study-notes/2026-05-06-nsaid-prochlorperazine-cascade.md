# Investigating Potential Prescribing Cascades Resulting in Prochlorperazine Prescription: Antihypertensives and NSAIDs

- **PMID**: 41865214
- **저널 / 연도**: Drugs & Aging 2026 Mar
- **저자**: Gilmore S et al.
- **출처 Scout**: inbox/scout/2026-05-03.md (과거 누락 복구)

## 초록 요약

처방 연쇄(prescribing cascade)는 한 약물의 부작용을 새로운 질환으로 오인해 추가 약물을 처방하는 패턴이다. 이 연구는 아일랜드 지역사회 ≥65세 노인에서 **항고혈압제 또는 NSAID 시작 후 프로클로르페라진 처방 증가**가 처방 연쇄를 나타내는지 탐색적으로 분석했다.

아일랜드 약국 청구 데이터베이스 514,056명 (2017~2020년)을 대상으로 처방 순서 대칭 분석(PSSA)을 시행했다. 항고혈압제 또는 NSAID 시작 후 프로클로르페라진을 나중에 처방받은 비율이 그 반대 순서보다 유의하게 높았다. 조정된 순서 비율(aSR)은 이뇨제 1.27부터 비뇨기 알파차단제 1.81 범위였다.

기전적 설명: 항고혈압제·NSAID 유발 어지럼증·구역을 새로운 증상으로 오인해 프로클로르페라진을 추가 처방하는 것이 처방 연쇄 가능성.

## 주요 결과

| 약물 쌍 | aSR (95% CI) |
|---|---|
| 이뇨제 → 프로클로르페라진 | 1.27 (1.16–1.40) |
| 비뇨기 알파차단제 → 프로클로르페라진 | **1.81 (1.49–2.19)** |
| 심장 알파차단제 → 프로클로르페라진 | 1.38 (범위 내) |
| 베타차단제 → 프로클로르페라진 (남성) | **1.94 (1.60–2.36)** |
| NSAID → 프로클로르페라진 | 유의한 양성 연관 |

- 관찰 기간: 365일, 180일, 60일 모두 대부분 유의
- 남성 > 여성에서 일부 연관 강도 더 높음

## 배경·방법

처방 순서 대칭 분석(PSSA): A→B 순서 vs B→A 순서 비율을 비교. A→B가 B→A보다 유의하게 많으면 처방 연쇄 신호. 처방 적응증 데이터 없이 처방 패턴만으로 탐색적 분석 — 임상 지시 여부는 미확인.

아일랜드 GMS(General Medical Services) 대상 노인 인구 — 한국 노인과 약물 사용 패턴 유사할 수 있으나 직접 동등 비교 주의.

## 일차의료 적용 포인트

### 진단·평가

**처방 연쇄 의심 트리거 — 항고혈압제·NSAID 시작 후 어지럼증·구역**:

```
노인 환자, 어지럼증·구역 호소
  → 최근 약물 변경 확인
      ├ 항고혈압제 신규 처방 or 용량 증량?
      ├ NSAID 신규 처방?
      └ 해당 약물 시작 시점 vs 증상 발현 시점 비교
  → 처방 연쇄 가능성 시
      → 프로클로르페라진 즉시 추가 X
      → 원인 약물 용량 감량·교체 시도 우선
      → 기립성 저혈압 측정 (항고혈압제 연관)
      → 증상 지속 시에만 추가 약물 고려
```

### 약물·처방 디테일

**프로클로르페라진(Stemetil, 스테메틸)**:
- 도파민 D2 수용체 차단제 — 항구역 효과
- 고령에서 지연성 운동장애(tardive dyskinesia), 추체외로 부작용 위험
- 처방 연쇄로 장기 복용 시 위험 누적 → 처방 시 명확한 적응증 확인 필수

### 환자 교육

> "어지럼증이나 구역이 새 약을 시작하고 나서 생겼다면, 그 약의 부작용일 수 있어요. 그럴 때 바로 다른 약을 더 드리기보다 먼저 원인 약 조정을 해 보겠습니다."

## 한계·주의

- 탐색적 분석 — 임상 지시 데이터 없어 진정한 처방 연쇄인지 확인 불가
- PSSA: 시간에 따른 처방 패턴 변화(계절·질환 진행)가 혼란변수로 작용 가능
- 아일랜드 데이터 — 한국 처방 패턴 직접 적용 시 주의
- 프로클로르페라진 적응증(중추성·말초성 구역·어지럼)이 명확한 경우와 처방 연쇄 구분 어려움
