# Nocturia: Evaluation and Management

- **PMID**: 40531150
- **저널 / 연도**: American Family Physician 2025 Jun
- **저자**: Getaneh FW et al.
- **출처 Scout**: inbox/scout/2026-05-01.md (과거 누락 복구)

## 초록 요약

야간뇨(nocturia)는 야간에 1회 이상 배뇨를 위해 깨어나는 것으로, 고령에서 유병률이 증가한다. 낙상·골절·인지저하·우울 위험과 연관되어 있어 단순한 생활 불편 이상의 임상적 의미를 갖는다.

야간뇨의 기전은 4가지로 분류된다: (1) 야간 소변 생성량 증가(nocturnal polyuria), (2) 방광 저장 용량 감소, (3) 불완전 배뇨, (4) 일차성 수면 장애. AFP 2025 리뷰는 이 4가지 기전을 체계적으로 정리하고, 각 기전에 맞는 치료 전략을 제시한다.

1차 치료는 생활습관 수정(야간 수분 제한, 이뇨제 복용 시간 조정, 수면 위생)이며, 약물치료는 원인 기전을 표적으로 한다. 불응성 야간뇨는 botulinum 주사, 천추 신경조절, BPH 수술 등을 고려한다.

## 주요 결과

- 야간뇨의 4대 기전: 야간 다뇨 / 방광 저장 용량 감소 / 불완전 배뇨 / 수면 장애
- 스크리닝은 권고되지 않으나 증상이 불편하면 평가·치료 대상
- 빈도-용량 일지(bladder diary)와 urinalysis는 모든 환자에게 시행
- 생활습관 → 원인 기전 기반 약물 → 불응성 시 시술 순

## 배경·방법

AFP "Evaluation and Management" 포맷 — 1차의료 의사를 위한 임상 실용 리뷰. 야간뇨는 성인에서 흔하며 낙상·인지저하·우울과의 연관으로 노인 환자에서 특히 중요하다. 기전 기반 접근이 다양한 약물 선택의 혼란을 줄이는 핵심임을 강조.

## 일차의료 적용 포인트

### 진단·평가

- 배뇨 증상 + 수분 섭취 패턴 + 동반 질환 동시 확인
- **빈도-용량 일지(bladder diary)**: 외래에서 1~2주 작성 요청 → 야간 다뇨 vs 방광 용량 문제 구분 핵심
- Urinalysis 기본 시행
- 이뇨제 복용 시간, 심부전·CKD, 수면무호흡 증상 확인

### 약물·처방 디테일

기전별 약물 매핑 [가이드라인 default 인용: AFP 2025]:
- 야간 다뇨 → Desmopressin (저나트륨혈증 위험: 시작 전·후 Na⁺ 측정 필수, 고령 주의)
- OAB → 미라베그론(β3 작용제) 우선 (항무스카린제는 고령 항콜린 부담↑)
- BPH → 알파차단제 ± 5-ARi
- GSM → 국소 에스트로겐

### 외래 결정 분기

```
야간뇨 호소
  → bladder diary 1~2주 작성
  → 생활습관 수정 (수분·이뇨제 타이밍·수면)
  → 동반 질환 치료 우선 (CHF, OSA, BPH, GSM)
  → 개선 없으면 기전 기반 약물 추가
  → 불응 → 비뇨기과 의뢰
```

### 환자 교육

> "야간뇨는 자연스러운 노화가 아니라 치료 가능한 문제입니다. 저녁 6시 이후 수분을 줄이고, 이뇨제를 아침에 드시면 많이 좋아질 수 있어요. 증상이 계속되면 약물 치료 옵션도 있습니다."

### 한국 외래 변환 시 확인

- 미라베그론(베타미가®) 한국 급여 기준 — OAB 진단 코드 필요 [출처 미확인 — researcher 검증 권장]
- Desmopressin 한국 보험 급여 — 야간뇨 적응 여부 [출처 미확인 — researcher 검증 권장]

## 한계·주의
