# 무월경: 진단과 관리를 위한 실용적 접근

## 미르의 첫 반응
> 이건 꼭 알고있어야겠다

## 미르 반응 심화 (이 노트의 핵심)

**적용 의도** — "꼭 알아야 한다" = 전문의 시험 핵심 + 외래 실전 알고리즘 내재화.

### 전문의 시험 핵심 패턴 (반드시 암기)

**FSH/LH/E2 패턴으로 병변 위치 결정**:

| 패턴 | 위치 | 진단 예 |
|---|---|---|
| FSH↑↑ + E2↓↓ | 난소 | POI, 터너증후군 |
| FSH↓/정상 + E2↓ | 시상하부/뇌하수체 | FHA, 고프로락틴혈증 |
| 프로락틴↑ | 뇌하수체 | 선종 |
| 안드로겐↑ + 정상 FSH | 난소 | PCOS |
| hCG↑ | — | 임신 (항상 먼저!) |

**1차 무월경 감별 3대**:
1. 터너증후군 (45,X) — 핵형
2. 마이어-로키탄스키 (자궁 부재) — E2·FSH 정상
3. 안드로겐 불감증 (46,XY + 외부 여성형) — 핵형 + 안드로겐

### 임상 시나리오 훈련

**시나리오 A**: 21세 여성, 6개월 월경 없음. BMI 18. 마라톤 주 70km 훈련.
→ FHA 가능성 높음. 검사: 임신↓, FSH↓/정상, E2↓, 프로락틴정상, TSH정상
→ 대응: 훈련 줄이기 + 칼로리 증가 + 골밀도 평가

**시나리오 B**: 35세 여성, 3개월 월경 없음. 두통, 유즙 분비 있음.
→ 고프로락틴혈증. 검사: 프로락틴↑ → 뇌하수체 MRI
→ 원인 약물 확인 (메토클로프라미드, 항정신병약) 먼저

**시나리오 C**: 38세 여성, 1년 월경 없음. 열감, 질건조.
→ POI. 검사: FSH↑↑, E2↓↓ → 핵형 확인
→ HRT 권고 (51세까지) + 골밀도 + 임신 계획 여부 확인

## 초록 요약

1차 무월경: 15세까지 초경 없음 또는 thelarche 3년 후. 2차: 규칙 월경 3개월 또는 불규칙 6개월 중단. 기본 검사: 임신 + E2·FSH·LH·프로락틴·TSH. FHA → 섭식장애·골밀도. POI → 51세까지 HRT. PCOS → 평생 대사 모니터링.

## 주요 결과

- 임신 검사: 항상 1순위
- 기본 세트: E2+FSH+LH+프로락틴+TSH
- FHA → 골밀도 평가 필수
- POI → HRT until avg menopause age

## 배경·방법

AFP 2026 리뷰. 1차의료에서 실용적 진단·관리 접근 제공.

## 일차의료 적용 포인트

### 진단·평가
- 임신 검사 후 → E2+FSH+LH+프로락틴+TSH
- 1차 무월경 → 핵형 추가
- 프로락틴>100 ng/mL → 뇌하수체 MRI

### 약물·처방 디테일
- POI HRT: estradiol + progesterone (연속 또는 주기적) [출처: 가이드라인 default — 구체 용량 기준 개별화 필요]
- PCOS + 무배란: 자궁내막 보호를 위해 주기적 프로게스틴

### 환자 교육
> "월경이 3개월 이상 없으면 원인을 찾아봐야 해요. 임신 검사부터 시작하고, 이후 호르몬 검사로 어디서 문제가 생겼는지 확인할 수 있어요."

## 한계·주의
- PCOS: 배제 진단 — 다른 원인 제외 후 진단
- 1차 무월경 + 고FSH → 핵형 검사 필수 (터너증후군)
