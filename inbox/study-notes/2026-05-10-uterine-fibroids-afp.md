# Uterine Fibroids: Rapid Evidence Review

- **PMID**: 41118184
- **저널 / 연도**: American Family Physician 2025 Oct;112(4):393-400
- **저자**: Keating MK, Jones KB, Hansell MW
- **출처 Scout**: inbox/scout/2026-05-07.md

## 초록 요약

자궁근종은 여성에서 가장 흔한 양성 종양으로, 대부분 무증상이다. 증상이 있으면 복부 팩만·빈뇨·변비(자궁 크기 증가), 월경과다(AUB), 골반통, 불임 등이 나타난다. 초기 평가는 부인과 병력·이중수지 진찰로 시작하고, 1차 영상은 경질+경복 초음파 조합이다. MRI는 수술 전 정밀 평가에 활용한다.

치료 선택은 근종 크기·위치와 임신·자궁 보존 의향을 함께 고려한다. 약물로는 COC·LNG-IUD·NSAIDs·tranexamic acid·GnRH 작용제/길항제가 사용되며, 수술로는 자궁절제술·근종절제술·UAE·고주파 절제술·HIFU가 선택 가능하다.

## 주요 결과

AFP RER(Rapid Evidence Review) 형식 — 주요 내용 요약:
- 1차 영상: TVUS + TAUS 조합
- 약물 치료: COC / LNG-IUD(52mg) / NSAIDs / tranexamic acid / GnRH 계열
- 수술: 자궁절제술(확정) / 근종절제술(임신 보존) / UAE(비수술적) / RFA / HIFU
- 비타민D 결핍: 보충이 진행 억제에 가능한 역할

## 일차의료 적용 포인트

### 진단·평가

- **1차 영상: TVUS + TAUS 조합** — 근종 위치(점막하·근층내·장막하)·크기·개수 확인
- **증상 분류**:
  - 월경과다(AUB) → 약물 1차
  - 압박 증상(빈뇨·복부 팩만) → 크기 감소 목표 시술/수술 고려
  - 불임 → 산부인과 의뢰

### 약물·처방 디테일

| 약물 | 역할 | 주의 |
|---|---|---|
| **COC** | AUB 조절 1차 | 근종 크기 감소 효과 없음 |
| **LNG-IUD 52mg** | AUB 효과적 | 자궁강 변형 없을 때 |
| **Tranexamic acid** | AUB 출혈량 감소 | 수술 대기 중 사용 가능 |
| NSAIDs | 월경통 + AUB 보조 | 지속 사용 위장 주의 |
| **GnRH antagonist** | 수술 전 근종 축소 | 장기 사용 골밀도 저하 |
| GnRH agonist | 수술 전 단기 | 갱년기 증상·골밀도 |

- **비타민D 결핍**: 결핍 확인 시 보충 — 근종 크기 안정 또는 감소에 초기 근거 있음

### 외래 결정 분기

```
자궁근종 의심 (월경과다·골반통·복부 팩만)
├── TVUS + TAUS 시행
├── 무증상 근종 → 경과 관찰 (6~12개월 초음파 추적)
├── 증상 있음
│   ├── AUB 주증상
│   │   ├── COC 또는 LNG-IUD 시작 (1차)
│   │   └── 효과 없음 → tranexamic acid 추가 or GnRH계열 고려
│   ├── 임신 계획 있음 → 산부인과 의뢰 (근종절제술 vs 임신 시도 timing)
└── 하 압박 증상·대형 근종 → 산부인과 의뢰 (시술/수술 논의)
```

### 환자 교육

> "자궁근종은 악성이 아니고 대부분 무증상이라서 바로 수술할 필요가 없습니다. 월경량이 많거나 통증이 있으면 먼저 약물로 조절해 보고, 아이 계획이 없으시다면 자궁에 삽입하는 호르몬 기구(IUD)도 효과적입니다."

## 한계·주의

- 근종 위치(점막하·근층내·장막하)에 따라 치료 접근 상이 — TVUS 위치 확인 필수
- UAE 후 임신 성공률 저하 가능 — 임신 계획 환자에게는 비권고
- GnRH 계열 장기 사용 시 골밀도 저하 → add-back 요법 고려 필요
