# Deprescribing Following Access to Lifestyle Treatment: A Retrospective Chart Review of Primary Care Outcomes in Patients with Type 2 Diabetes

- **PMID**: 41976866
- **저널 / 연도**: Journal of Clinical Medicine 2026
- **저자**: Jacob Y et al.
- **출처 Scout**: inbox/scout/2026-05-11.md

## 초록 요약

생활습관 의학(Lifestyle Medicine, LM)을 통합 적용하는 일차의료 2개 기관에서 T2DM 환자 650명의 전자의무기록을 후향적으로 검토했다. 연구 질문: 생활습관이 개선되면 실제로 혈당약을 줄일 수 있는가, 안전한가?

결과: 41명(6.3%)에서 감약 이벤트 발생. 메트포르민 용량 감량(34%), 메트포르민 중단(19.5%), 인슐린 용량 감량(19.5%)이 주요 유형. 감약 후 BMI -2.25, HbA1c -13%, 포도당 -25% 유의한 개선. 심각한 이상반응 0건.

생활습관 의학 처방(식이·운동)이 실제 약물 감량으로 이어지는 임상 경로를 실사 데이터로 뽒받침한 연구.

## 주요 결과

| 지표 | 결과 |
|---|---|
| 감약 이벤트 발생률 | 6.3% (41/650) |
| 메트포르민 용량 감량 | 34% |
| 메트포르민 중단 | 19.5% |
| 인슐린 용량 감량 | 19.5% |
| BMI 변화 | -2.25 kg/m² (p<0.0003) |
| 포도당 변화 | -25% (p<0.0003) |
| HbA1c 변화 | -13% (p<0.0013) |
| 생활습관 변화 기록 | 51% 에서 명시 |
| 심각한 이상반응 | 0건 |

## 배경·방법

생활습관 의학 개입이 혈당 조절을 개선할 수 있다는 근거는 있지만, 실제 임상 환경에서 약물 감약으로 이어지는지 기록한 연구는 드물다. 후향적 차트 리뷰, 2014-2023. 기존 deprescribing 프레임워크 활용. 미국 2개 생활습관 의학 클리닉.

## 일차의료 적용 포인트

### 외래 결정 분기
```
T2DM 환자 생활습관 개선 확인 시
  ↓
HbA1c 목표 이하 지속 (예: <6.5~7%) + 체중 감량
  ↓
메트포르민 감량 가능 여부 평가
  → 저혈당 위험 없음 확인 후 단계적 감량
  ↓
인슐린 집중 환자 → HbA1c 지속 목표 이하
  → 인슐린 용량 단계적 감량 (저혈당 모니터링 병행)
  ↓
감약 후: 2~4주 후 혈당 재확인
```

### 환자 교육
> "식사와 운동을 열심히 하신 덕분에 혈당이 잘 조절되고 있어요. 약을 조금 줄여도 될 것 같아서 같이 시도해 볼게요."
