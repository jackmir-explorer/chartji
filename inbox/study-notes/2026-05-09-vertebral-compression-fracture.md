# Vertebral Compression Fractures

- **PMID**: 41544281
- **저널 / 연도**: American Family Physician 2026 Jan
- **저자**: Creech-Organ J, Organ B
- **출처 Scout**: inbox/scout/2026-05-06.md

## 초록 요약

골다공증의 흔한 합병증인 척추압박골절(VCF)을 AFP 2026에서 종합 리뷰. 특이점은 기침·재채기·침대 뒤집기 등 일상적 동작으로도 발생 가능. 대부분 무증상이지만 자세 변화 시 통증을 보일 수 있음. 초기 영상은 전후측면 척추 X-ray, 음성 시 MRI. 보존치료(재활+약물)가 1차이며, 항골다공증 약물이 골절 후 통증 개선에도 효과. 6주 보존치료 무효 시 vertebroplasty/kyphoplasty 고려.

## 주요 결과

- VCF 흔한 촉발 인자: 기침·재채기·침대 뒤집기 (일상 동작)
- 많은 환자 무증상 (영상 우연 발견)
- 진단: AP+Lateral X-ray → 음성+강한 의심 → MRI
- 항골다공증 약물: 추가 골절 예방 + 통증 개선 효과 동시
- 수술(VP/KP): 6주 보존치료 무효 시 고려

## 배경·방법

AFP 2026 임상 리뷰 — 가정의학과 의사 대상. 초록 기반. VCF의 진단부터 치료, 예방까지 전주기 정리.

## 일차의료 적용 포인트

### 진단·평가

**"허리가 갑자기 아프다" + 고령 + 골다공증 위험인자 → VCF 즉시 감별:**

Red flags (전이성·외상성 원인 배제):
- 악성 종양 기왕력
- 외상 후 발생
- 발열·야간발한·체중 감소 동반 (감염·종양)
- 신경학적 결손 (근력 약화·대소변 장애 → 즉시 MRI + 응급 의뢰)

진단 흐름:
```
고령 + 골다공증 + 갑작스런 요통
         ↓
AP + Lateral 척추 X-ray
         ↓
VCF 확인 → 보존치료 시작 + 골다공증 약물
X-ray 음성 + 임상 강하게 의심 → MRI 추가
악성 의심 → MRI 우선
```

### 약물·처방 디테일

**통증 관리:**
- 1차: NSAID (단기), acetaminophen
- 항골다공증 약물: 통증 개선 + 추가 골절 예방 동시

**항골다공증 약물 — VCF 후 즉시 시작:**
- Bisphosphonate (alendronate 70mg/주 또는 zoledronate IV 1회/년)
- Denosumab (60mg SQ 6개월마다) — 신기능 저하 시 대안
- 처방 지연 금지 — 골절 후 조기 시작이 원칙 [가이드라인 default 인용: KSBMR 2024]

### 외래 결정 분기

```
VCF 진단 확인
         ↓
보존치료 시작 (재활 + 약물)
         ↓
골다공증 약물 미처방 상태 → 즉시 시작
골다공증 치료 중 발생 → 순응도 확인 + 약제 변경 검토
         ↓
6주 후 재평가
  → 통증 호전 → 보존치료 지속
  → 통증 지속·악화 → Vertebroplasty/Kyphoplasty 의뢰
         ↓
신경 압박·결손 → 즉시 척추외과 의뢰
```

### 환자 교육

> "기침이나 재채기처럼 별거 아닌 동작에서도 척추가 내려앉는 골절이 생길 수 있습니다. 이미 생겼다면 회복을 돕는 약을 같이 써야 다음 골절을 막을 수 있습니다. 안정만 취하시는 것보다 적절한 활동을 유지하시는 게 빠른 회복에 도움이 됩니다."
