# Update on Medical Management of Acute Peripheral Facial Palsy

- **PMID**: 39916394
- **저널 / 연도**: Journal of Audiology & Otology 2025;29(1):1-7
- **저자**: Kim SH, Kwak MY
- **출처 Scout**: inbox/scout/2026-05-21.md

## 초록 요약

급성 말초 안면 신경 마비는 연간 20~30/100,000명의 발생률을 보이는 흔한 신경학적 질환이다. 원인은 바이러스 재활성화·염증·허혈이며 예후는 신경 손상 정도와 치료 시작 시점에 크게 좌우된다.

Bell's palsy에서 스테로이드 치료는 염증 감소·회복 촉진의 cornerstone으로, **72시간 이내 시작**이 예후를 결정적으로 개선한다. 항바이러스제 병용 효과는 논란이 있으며, 현재 가이드라인은 중증 사례 또는 바이러스 관련성이 강히 의심되는 경우에만 선택적 사용을 권고한다. Ramsay Hunt syndrome 등 VZV 유발 안면마비에서는 병용요법이 후유증 감소에 도움될 수 있으나 고질의 근거가 부족하다.

## 주요 결과

Bell's palsy:
- 스테로이드 단독 = primary treatment (강한 근거)
- 항바이러스제 단독 추가 효과: 통계적 유의성 미충족
- 72시간 이내 스테로이드 시작 = 예후 개선 핵심

Ramsay Hunt Syndrome:
- 스테로이드 + 항바이러스 병용 = 권고 (중증·VZV 의심 시)
- RCT 근거 제한적 (2개 RCT, 474명 메타분석 — PMID:38520982에서 통계적 유의성 미충족)
- 자연 회복률 ~60% (Bell's palsy >80% 대비 불량)
- 영구 후유증: 안면마비·청력저하·이명·현기증

## 배경·방법

2025년 최신 업데이트 리뷰. 기존 Bell's palsy/RHS 치료 가이드라인과 최신 RCT/메타분석을 통합. 중점: 두 질환의 관리 분기와 항바이러스 추가의 적응증 명확화.

## 일차의료 적용 포인트

### 진단·평가

**Bell's palsy vs RHS 즉각 감별:**

| 단서 | Bell's palsy | Ramsay Hunt |
|---|---|---|
| 수포(vesicle) | 없음 | 외이도·이개·구강점막 |
| 귀 통증(otalgia) | 경미 | 심함 (수포 전 선행 가능) |
| 청력저하·이명 | 없음 | 가능 |
| 어지럼 | 없음 | 가능 |
| 예후 | >80% 회복 | ~60% 미만 |

→ 귀 수포·이통·청각/전정 증상 → RHS 의심 → 항바이러스 추가

### 약물·처방 디테일

**Bell's palsy:**
- Prednisolone 60mg/d (1mg/kg/d) 5일 → taper [가이드라인 default 인용: 한국 이비인후과학회/대한신경과학회]
- 항바이러스제: 중증 또는 VZV 의심 시 선택적 추가
- 72시간 내 시작이 골든타임

**Ramsay Hunt:**
- Prednisolone 1mg/kg/d 5일 → taper + Famciclovir 500mg TID 7일 (or Valacyclovir 1000mg TID 7일)
- 동일하게 72시간 내 시작 핵심

### 외래 결정 분기

```
급성 편측 안면마비 내원
  ↓
이통·외이도/이개 수포·청력저하·어지럼 확인
  ├── 없음 → Bell's palsy 가능성 → 스테로이드 (72h 이내)
  │    ├── 중증(HB grade IV+) → 항바이러스 추가 고려
  │    └── 황반변성 병력 → [[macular-degeneration-steroid-caution]] 확인
  └── 있음 → Ramsay Hunt 의심 → 스테로이드 + 항바이러스
       ├── 입원 기준 해당 시(구토·광범위 병변·빠른 진행) → 입원
       └── 황반변성 병력 → 안과 협진 + 항바이러스 단독 검토
```

### 환자 교육

> "안면마비는 지금 당장 치료를 시작하는 게 중요합니다. 72시간 안에 약을 시작해야 회복률이 훨씬 높습니다. 귀에 물집이 생기거나 귀가 많이 아프거나 들리지 않으면 대상포진이 원인일 수 있어 약이 달라집니다."
