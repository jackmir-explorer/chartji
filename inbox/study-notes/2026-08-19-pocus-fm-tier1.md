## 미르 반응 심화 (이 노트의 핵심)

**"구체적 예시"** — 적용 의도 유형. Tier 1 6가지를 외래에서 어떻게 쓸지.

### Tier 1 6가지 × 구체적 외래 시나리오

#### 1. Cellulitis (연조직염) — 항생제 vs 절개배농 결정

```
외래 시나리오:
- 환자: 종아리 발적·부종·열감 내원
- 문제: 육안으로만 보면 농양인지 순수 연조직염인지 불명확

POCUS 전:
→ 항생제 처방? 절개 시도? 추측으로 결정

POCUS 후:
→ 초음파: 피하 '코브라 머리' 형상 무에코 공간 = 농양 확인
→ 절개배농 + 항생제
또는
→ 균일한 피하 에코 증가 = 순수 연조직염
→ 항생제 단독 (절개 불필요)
```

**왜 중요:** 농양을 잘못 보고 항생제만 주면 치료 실패. POCUS 없이 드레인이 필요한데 안 하거나, 반대로 절개 안 해도 되는데 절개하는 경우를 막는다.

#### 2. Abscess drainage (농양 배액) — 정확한 위치·깊이 확인

```
절개배농 전 POCUS로:
- 농양 경계·깊이 확인 → 절개 깊이 결정
- 주요 혈관·신경 회피
- 내부 격막 확인 → 단순 I&D로 충분한지 판단
```

#### 3. Knee effusion (슬관절삼출) — 천자 여부 결정

```
외래 시나리오:
- 환자: 무릎 부종·통증 내원
- 문제: 무릎에 물이 찼는가? 얼마나 찼는가?

POCUS:
→ 슬개상 와(suprapatellar pouch) 무에코 삼출 확인
→ 삼출량 파악
→ 천자·스테로이드 주사 여부 결정

천자 대상:
- 급성 단관절 부종 → 감염성 관절염 배제 위해 천자
- 류마티스 관절염 악화 → 스테로이드 주사 동시 시행
```

#### 4. Bladder volume (방광용량) — PVR 측정

```
외래 시나리오:
- 환자: 배뇨 후에도 잔뇨감·빈뇨·요류감소 → BPH 의심
- 소아: 배뇨 곤란·요로감염 반복

POCUS:
→ 방광 길이 × 폭 × 높이 × 0.52 = 용적(mL)
→ PVR >150~200mL: 유의한 잔뇨 → 의뢰 또는 α차단제 시작 강화
→ PVR 정상: 과민성 방광(OAB) 방향으로 전환
```

**한국 적용:** BPH 외래에서 PVR 측정은 초음파 급여 적용 가능할 수 있음 [출처 미확인 — 확인 필요]

#### 5. Fetal presentation (태아위치) — 두정위·둔위 확인

```
외래 시나리오 (산전 진찰 제공 FM 의사):
- 임신 36주 외래 → 태아 위치 확인
→ POCUS: 두정위 (vertex) = 정상 경질 분만 계획
→ POCUS: 둔위 (breech) = 외회전술(ECV) 의뢰 또는 제왕절개 계획
```

### 5분 POCUS 루틴 (Tier 1 기술 기준)

Tier 1 6가지 중 외래 진료 흐름을 가장 많이 바꾸는 것:
1. **연조직염 감별** — 치료 방향 바꿈
2. **슬관절삼출** — 천자 결정에 직결
3. **방광 잔뇨** — BPH·OAB 감별에 직결

→ 이 세 가지만 습득해도 외래 결정의 질이 달라진다.

## 초록 요약

STFM POCUS Education Task Force가 FM 전공의 교육용 POCUS 적용 52가지를 도출, 5단계 tier로 분류. Tier 1(2028 역량 달성 목표): cellulitis·abscess·abscess drainage·knee effusion·bladder volume·fetal presentation 6가지. ABFM·AFMRD·ADFM 이사회 모두 승인.

## 주요 결과

- FM 전공의 POCUS 커리큘럼 Tier 1 = **6가지 공식 확정**
- 2028년까지 역량 달성 목표
- 전문의 시험 POCUS 문항 출제 기준 = 이 Tier 1에서 나올 가능성
- Tier 2~5는 추후 단계적 확대 예정 [전문 미확인 — 원문 참조 권장]

## 배경·방법

STFM POCUS Education Task Force 1차 작업 결과 보고. 52개 POCUS 적용 도출 → 5 tier 분류 → Tier 1 6가지 다기관 합의. FM 레지던트 교육 표준화 목표.

## 일차의료 적용 포인트

### 외래 결정 분기 (연조직염 POCUS)

```
피부·연부조직 발적 외래 환자
    ↓
POCUS 가능?
    YES → 피하 초음파 → 농양 유무 확인
        농양 ✅ → 절개배농 + 항생제
        농양 ✖ → 항생제 단독
    NO  → 임상 판단 (변동 유연성·압통·파동감)
```

### 환자 교육

> "초음파로 확인해볼게요. 피부 아래에 고름이 있는지 없는지 보면 어떻게 치료할지 바로 결정할 수 있어요."
