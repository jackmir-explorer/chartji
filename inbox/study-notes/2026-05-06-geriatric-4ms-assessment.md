# The Age-Friendly Geriatric Assessment (4Ms Framework)

- **PMID**: 41544278
- **저널 / 연도**: American Family Physician 2026 Jan
- **저자**: Rubenstein C et al.
- **출처 Scout**: inbox/scout/2026-05-03.md (과거 누락 복구)

## 초록 요약

미국 노인 인구가 증가함에 따라 가정의들이 65세 이상 성인을 더 많이 진료하게 됐다. 노인 평가를 위한 권장 프레임워크는 **4Ms**: What Matters(무엇이 중요한가), Medication(약물), Mentation(인지·기분), Mobility(이동능력)이다.

각 영역별 핵심: What Matters — 환자·가족과 일상·의료에서 가장 중요한 것 대화; Medication — 부적절 약물 확인·중단 + 필요 약물 누락 점검; Mentation — Mini-Cog로 인지 평가, 가역 원인 탐색 후 MCI·치매 진단, 우울·섬망 위험 확인; Mobility — STEADI 도구로 낙상 위험 스크리닝, 양성 시 운동 중재·물리치료.

## 주요 결과

4Ms 프레임워크 (Age-Friendly Health Systems 권고):
- **What Matters**: 개방형 질문으로 환자 목표 확인
- **Medication**: Beers/STOPP 기준 + 다약제 검토
- **Mentation**: Mini-Cog (3단계) + 우울(PHQ-2) + 섬망 위험
- **Mobility**: STEADI 3문항 → TUG test ≥12초 → 고위험

## 배경·방법

AFP "Clinical Review" 포맷. Age-Friendly Health Systems Initiative (IHI + John A. Hartford Foundation 주도)에서 4Ms 프레임워크를 개발·보급. 4Ms는 노인 진료의 핵심을 구조화하는 도구로 미국 가정의학 레지던시 교육에 통합.

## 일차의료 적용 포인트

### 진단·평가

**4Ms 외래 통합 루틴** (≥65세 정기 방문에 단계적 적용)

**① What Matters**
- 외래 시작 시: "오늘 가장 걱정되시는 것은?" / "건강에서 가장 중요하게 유지하고 싶은 것은?"
- 답변이 진료 목표 설정의 기준 → 과도한 치료·불필요한 검사 방지

**② Medication**
- 전체 약물 목록 검토 — 매 방문
- Beers Criteria 고위험 약물: 항히스타민·BZD·Z-drug·항콜린 요실금약·NSAIDs
- ACB ≥1 약물도 구강건조증·낙상 위험 (PMID:41824280 근거)

**③ Mentation — Mini-Cog**
- 인지 우려 시 즉시 시행 (3분 내 완료)
- 이상 → 가역 원인 배제(갑상선·B12·약물·우울) → 신경심리 검사 의뢰
- 우울: GDS-5 또는 PHQ-2 루틴 스크리닝 (노인에서 종종 무감동·신체 증상으로 발현)

**④ Mobility — STEADI**
- 3가지 질문:
  1. "지난 1년간 넘어진 적 있나요?"
  2. "걷거나 균형 잡을 때 불안정하다고 느끼나요?"
  3. "낙상이 걱정되어 활동을 줄인 적 있나요?"
- 하나라도 양성 → TUG test: ≥12초면 고위험
- 고위험 → 물리치료(균형·근력), 약물 조정(항고혈압제·수면제·항콜린제)

### 외래 결정 분기

```
≥65세 방문
  → What Matters 질문 (첫 1분)
  → Medication 목록 검토 (Beers/STOPP)
  → Mentation 우려 시 Mini-Cog
  → STEADI 3문항
      ├ 음성: 기본 운동 권고
      └ 양성: TUG test → 고위험 시 PT 의뢰 + 약물 조정
```

### 환자 교육

> "이 질문들은 나이 드실수록 중요한 것들을 미리 확인하기 위한 거예요. 넘어지지 않으려면 약도 맞게 드셔야 하고, 꾸준히 걷는 연습도 도움이 됩니다."

### 한국 외래 변환 시 확인

- Mini-Cog 한국어 표준화 버전 — MMSE 또는 K-MMSE가 더 일반적으로 사용됨 [출처 미확인 — researcher 검증 권장]
- STEADI 도구 한국어 번역 버전 가용 여부 [출처 미확인]
- 물리치료 의뢰 급여 기준 (낙상 예방 목적) [출처 미확인 — researcher 검증 권장]

## 한계·주의

- AFP 임상 리뷰 — 4Ms 각 요소의 직접 임상 시험 결과보다 전문가 권고 기반
- Mini-Cog는 스크리닝 도구 — 치매 진단 도구 아님
- 4Ms를 단일 방문에 모두 완료하기 어려울 수 있음 — 여러 방문에 분산 적용 현실적
