# Evaluation of Neck Masses in Adults

- **PMID**: 41839107
- **저널 / 연도**: Am Fam Physician 2026;113(2):156-165
- **저자**: Wilbur J, Tran VL, Doobay MF
- **출처 Scout**: inbox/scout/2026-05-27.md

## 초록 요약

경부종괴는 외래에서 흔하다. 감별진단 범위는 넓지만 **95%는 양성**이다. 악성 종괴를 빠르고 정확하게 감별하는 것이 핵심 목표다. 탐문 틀(investigatory framework)을 사용하면 진료 지연 없이 정확한 진단이 가능하다.

현재 두경부암의 주요 변화: **HPV 관련 구인두 편평세포암(HPV-OPSCC)이 신규 두경부암 진단의 약 70%를 차지**하게 됐다. 감별진단은 급성(감염)·아급성(악성/육아종)·만성(선천성/갑상선)의 3범주로 나눌 수 있다.

병력·위험인자·신체진찰만으로 진단 불가 시 영상 또는 생검이 필요하다. 비박동성·비갑상선 종괴 → 조영CT, 갑상선 종괴 → 초음파, 박동성 → CTA, 뇌신경 침범 → MRI, 전이 가능성 → PET. FNA: 정확도 93%·민감도 90%·특이도 97%.

## 주요 결과

- 경부종괴 95%는 **양성**
- HPV-OPSCC = 신규 두경부암의 **약 70%**
- FNA 정확도: 93%, 민감도: 90%, 특이도: 97% (해부학적 위치 무관)
- CE-CT = 비박동성 비갑상선 종괴의 1차 영상
- 갑상선 종괴 → 초음파(US) 1차

## 배경·방법

AFP 종합 리뷰. 경부종괴 감별 진단 틀을 acuity 기반 3범주(급성·아급성·만성)로 체계화하고, 영상·생검 선택 알고리즘을 임상 단서와 연결. HPV 관련 두경부암의 역학 변화 반영.

## 일차의료 적용 포인트

### 진단·평가

**외래 첫 평가 체크리스트:**
1. 지속 기간 (급성 <2주 / 아급성 2~6주 / 만성 >6주)
2. B증상 (발열·야간 발한·체중 감소) → 림프종 배제
3. 위험 인자 (흡연·과음·HPV 노출·두경부 방사선 치료 병력)
4. 동반 증상 (연하 곤란·목소리 변화·이통)
5. 촉진: 위치·크기·경도·이동성·압통

**3범주 감별 틀:**
- **급성** (<2주): 감염성 (세균·바이러스 림프절염, 농양)
- **아급성** (2~6주): 악성종양(전이성/HPV-OPSCC), 육아종성 (TB, 사르코이드)
- **만성** (>6주): 선천성 이상, 갑상선 결절, 지방종, 피지낭종

**영상 선택 알고리즘:**
```
비갑상선·비박동성 → CE-CT
갑상선 → 초음파 (US)
박동성 → CTA
뇌신경 침범 의심 → MRI
전이 가능성 → PET
```

### 외래 결정 분기

```
경부종괴 내원
  ↓
지속 기간 + 위험인자 + 증상 평가
  ├── 급성 + 감염 단서 (발열·압통·인후통) → 항생제 ± 추적
  ├── 4~6주 이상 지속 or 치료 반응 없음 → 영상 (CE-CT or US)
  ├── B증상 동반 → 림프종 배제 우선 → 혈액종양과 의뢰
  ├── 고위험군 (흡연+음주+HPV) → 조기 CE-CT + FNA 고려
  └── 갑상선 결절 → 초음파 → TIRADS 기반 FNA 결정
```

### 환자 교육

> "목에 혹이 생겼다고 모두 암은 아닙니다. 95%는 양성입니다. 다만 6주 이상 지속되거나 열이 나고 체중이 빠지는 증상이 함께 있으면 빠르게 검사가 필요합니다. 담배와 술을 오래 하셨거나 목소리·삼킴이 달라지셨다면 특히 검사를 서두르는 게 좋습니다."
