## 미르의 첫 반응
> 오케이

## 미르 반응 심화 (이 노트의 핵심)

**"오케이" — 실용적 임상 레퍼런스로 사용**

이 논문의 가치: 무릎 통증 외래 프로토콜의 **전체 알고리즘을 5단계 신체검진 + POCUS + 오타와 규칙으로 통합**.

### 무릎 통증 빈도 (외래 맥락)

| 진단 | 연령대 | 유병률 |
|---|---|---|
| **증상성 무릎 OA** | 40세 이상 | 30–45% |
| **슬개대퇴통증증후군(PFPS)** | 젊은 성인 | 25–40% |
| 반월판·인대 손상 | 활동적 성인 | 다양 |

→ 외래 근골격 주소 최상위권 → 이 프로토콜 자주 활용

### 5단계 신체검진 프레임워크

| 단계 | 검사 항목 | 임상 목적 |
|---|---|---|
| **1. 육안 검사** | 부종·발적·변형·보행 | 삼출·관절염 초기 감별 |
| **2. 촉진** | 삼출 여부·압통점 | Bulge sign/Ballottement으로 삼출 확인 |
| **3. 능동/수동 ROM** | 굴곡·신전 범위 | OA·관절내 병변 선별 |
| **4. 근력** | 대퇴사두근·햄스트링 | 기능적 제한도 확인 |
| **5. 특수 검사** | Lachman·McMurray·valgus/varus | 인대·반월판 손상 감별 |

**핵심 원칙**: 단일 검사보다 **조합**이 더 정확 (sensitivity/specificity 합산)

### 오타와 무릎 규칙 (Ottawa Knee Rule)

외상 후 무릎 통증에서 **방사선 촬영 여부** 결정:

촬영 필요 조건 (다음 중 하나):
- 나이 ≥55세
- 비골두(fibular head) 압통
- 슬개골 단독 압통
- 굴곡 <90°
- 체중 부하 불가

→ 위 조건 없으면 X-ray 생략 가능 — **불필요한 방사선 회피**

### POCUS 유도 관절천자 (Arthrocentesis)

**적응증**: 삼출 확인 시 (염증성·감염성·혈관절증 감별 목적)

```
삼출 의심 환자
    ↓
POCUS로 삼출 위치·양 확인
    ├─ 소량 → 임상 감별로 충분
    └─ 중등량 이상 → POCUS 유도 관절천자
              ├─ 관절액 분석: WBC·결정체(요산·피로인산칼슘)·세균·배양
              ├─ WBC >50,000/μL → 세균성 관절염 의심 → 응급 의뢰
              └─ 결정체 + WBC 낮음 → 통풍/CPPD → MRA 처방
```

**POCUS 유도 이점**: 정확도↑ (맹법보다 삽입 성공률↑) + 합병증↓

### 연령별 감별 진단

| 연령 | 우선 고려 진단 |
|---|---|
| 10–25세 | PFPS, 오스굿-슐라터, 인대/반월판 손상 |
| 25–45세 | 반월판 손상, PFPS, 초기 OA |
| 45세 이상 | 골관절염(OA), 통풍, CPPD |
| 모든 연령 | 감염성 관절염 (고열+단관절 급성 → 응급) |

## 초록 요약

AFP 2026 종합 리뷰. 성인·청소년 무릎 통증 외래 초기 평가의 5단계 신체검진·오타와 규칙·POCUS 유도 관절천자를 통합. 외래 1차 진료에서 즉시 참조 가능한 프로토콜 제공.

## 일차의료 적용 포인트

### 외래 결정 분기

```
무릎 통증 신규 환자
    ↓
5단계 신체검진
    ├─ 외상 병력 → 오타와 규칙 → X-ray 결정
    ├─ 삼출 확인 → POCUS 유도 관절천자 고려
    │        └─ 감염 의심(발열·급성) → 즉시 의뢰
    ├─ 40세 이상 + 활동 시 통증 → OA → 보존적 치료
    └─ 젊은 성인 + 전방 무릎 통증 → PFPS → 물리치료
```

### 감염성 관절염 응급 신호

> 발열 + 단관절 급성 발적·부종·열감 → 감염성 관절염 배제 전까지 응급 처치

## 한계·주의
