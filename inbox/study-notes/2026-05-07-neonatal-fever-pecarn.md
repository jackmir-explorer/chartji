# Prediction of Bacteremia and Bacterial Meningitis Among Febrile Infants Aged 28 Days or Younger

- **PMID**: 41359314
- **저널 / 연도**: JAMA 2026
- **저자**: Burstein B et al.
- **출처 Scout**: inbox/scout/2026-05-03.md (과거 누락 복구)

## 초록 요약

생후 28일 이하 발열 신생아에서 침습세균감염(균혈증·세균성 수막염)을 예측하는 PECARN 예측 룰의 진단 정확도를 6개국 4개 전향 코호트 풀드 분석으로 평가한 연구. 기존 국제 가이드라인은 28일 이하 발열 신생아 모두에게 요추천자(LP)를 루틴으로 권장했으나, 이 연구는 저위험군을 정확히 선별해 LP 선별 적용을 지지하는 근거를 제공한다.

n=1,537명, 침습세균감염 유병률 4.5%. 저위험 기준(소변검사 음성+PCT≤0.5+ANC≤4000)을 충족한 41.1%의 환자에서 세균성 수막염은 단 한 건도 발생하지 않았다. 이는 LP 루틴화에 대한 재고를 촉구하는 데이터다.

## 주요 결과

| 지표 | 수치 |
|---|---|
| 민감도 | **94.2%** (85.6–97.8%) |
| 특이도 | 41.6% (36.7–46.7%) |
| 양성예측도(PPV) | 6.9% (4.8–9.9%) |
| 음성예측도(NPV) | **99.4%** (98.1–99.8%) |
| 저위험 분류 비율 | 41.1% (n=632) |
| 저위험군 내 세균성 수막염 | **0건** |

- 민감도 94.2% = 100명 중 약 6명은 감염이 있어도 저위험으로 분류될 수 있음 (완전 배제 아님)
- NPV 99.4% = 저위험 판정 시 침습감염 배제 신뢰도 높음

## 배경·방법

발열(≥38.0°C)은 생후 1개월 이내 신생아에서 침습세균감염의 유일한 징후일 수 있어, 기존엔 모든 환자에게 혈액·소변·뇌척수액 배양을 포함한 full sepsis workup + LP를 시행해왔다. PECARN 예측 룰은 PCT, ANC, 소변검사 3가지 변수를 결합해 저위험군을 선별하는 다변수 임상 예측 모델.

연구 설계: 6개국 소아응급연구네트워크(PERN) 코호트 풀드 분석. 대상: 건강했던 만삭아(≥37주), 정상 출현(non-ill-appearing), 38.0°C 이상 발열.

## 일차의료 적용 포인트

### 진단·평가

- 생후 ≤28일 발열 신생아 = **항상 즉시 의뢰** (일차의료에서 단독 관리 부적절 — 응급실·소아과)
- 의뢰 전 PECARN 기준을 인지하면 **불필요한 LP 논의·가족 불안 관리** 가능
- **저위험 3기준**: ① 소변검사/딥스틱 음성 ② PCT ≤0.5 ng/mL ③ ANC ≤4,000/mm³

### 외래 결정 분기

- 가정의학과에서 이 환자군을 직접 관리하는 상황은 드물지만: 발열 신생아가 외래 내원 시 → **즉각 응급실 이송**이 표준 (예측 룰 단독 적용 비권고)
- 응급실 협진 후 저위험 판정 시 → LP 여부를 공유의사결정으로 결정 가능 (NPV 99.4% 근거로 설명 가능)
- ill-appearing / 미숙아 / 기저질환 → 예측 룰 적용 제외

### 환자 교육

> "신생아에서 열이 나는 건 매우 심각한 상황이에요. 지금 바로 응급실로 가셔야 합니다. 요즘은 혈액검사로 검사 범위를 줄일 수 있는 방법이 생겼는데, 응급실에서 검사 결과를 보고 의사가 설명해줄 거예요."

## 한계·주의

- 외래 응급 의뢰가 원칙 — 일차의료 단독 관리 대상 아님
- PCT 검사 가용성: 국내 응급실별 즉시 결과 확인 가능 여부 확인 필요 [출처 미확인 — researcher 검증 권장]
- 민감도 94.2% — 완전 배제 불가. LP 생략은 공유의사결정과 귀가 후 관찰 계획 포함 필요
- 연구 대상 기관: 소아응급 전문 센터 — 일반 지역 응급실 외삽 주의
