# Stop guessing: A clinician's guide to demystifying spine-related arm pain in primary care

- **PMID**: 41956881
- **저널 / 연도**: Musculoskeletal Science & Practice 2026 Mar
- **저자**: Hage R et al.
- **출처 Scout**: inbox/scout/2026-05-06.md

## 초록 요약

팔 통증은 단순 근골격 장애부터 심각한 척추 병변까지 다양한 원인을 가지며, 1차의료에서 감별이 어렵다. 이 논문은 척추유발 상지통(SAP — Spine-related Arm Pain)을 통증 기전에 따라 분류(통해성·신경병증성·중추감작성)하고, 임상 우려 층화 및 의무적 신경학적 검진 절차를 포함한 진단 알고리즘을 제안한다. IASP 용어와 Neuropathic Pain Special Interest Group 권고 기반으로 구성됐으며, 3가지 가상 시나리오로 알고리즘 적용을 시연한다.

## 주요 결과

- SAP 진단 알고리즘: 기전 분류 → 임상 우려 층화 → 신경학적 검진 → Safety-netting
- 3가지 통증 기전 분류: Nociceptive(통해성) / Neuropathic(신경병증성) / Nociplastic(중추감작성)
- 1차의료에서 반드시 시행할 신경학적 검진: 피부절 감각, 근절 근력, 심부건반사, Spurling test, ULTT

## 배경·방법

기전 기반 접근(mechanism-based reasoning)이 1차의료에서 SAP 진단 자신감·관리 역량을 높인다는 근거에서 출발. 문헌 기반 합의 알고리즘 — 전향적 검증 연구는 아닌 교육·지식 번역 도구.

## 일차의료 적용 포인트

### 진단·평가

**통증 기전 분류 3가지:**
1. **Nociceptive(통해성)**: 조직 손상 반응, 활동·자세 연관, 명확한 위치, 쉬면 완화
2. **Neuropathic(신경병증성)**: 타는 느낌·전기충격·피부절 방사, 근력 약화·감각 저하, Spurling(+)
3. **Nociplastic(중추감작성)**: 다발 부위 통증, 자극 과민, 비해부학적 분포, 심리적 요소 동반

**Red flag (즉시 평가):**
- 갑작스런 근력 약화, 보행 장애
- 대소변 장애 (척수 압박)
- 발열·체중 감소 동반
- 점진적 신경 결손 악화

### 약물·처방 디테일

- Neuropathic SAP → duloxetine, gabapentin, pregabalin [가이드라인 default 인용: AAN NPN 권고]
- Nociceptive SAP → NSAID 단기, 물리치료 우선
- Nociplastic SAP → CBT, 운동, 심리적 접근; 약물 단독 효과 제한적

### 외래 결정 분기

```
"팔이 아프다"
      ↓
Red flag 확인 → 있으면 즉시 의뢰
      ↓
신경학적 검진 (피부절·근절·반사·Spurling·ULTT)
      ↓
Neuropathic 확인되면 → 신경병증 통증 치료 + EMG 고려
Nociceptive        → 물리치료 + 단기 NSAID
Nociplastic        → 심리적 접근 + 운동 + CBT
      ↓
2~4주 후 Safety-netting 재평가
```

### 환자 교육

> "팔 통증의 원인이 목 척추에서 오는 경우가 있습니다. 신경이 눌리면 저리거나 타는 느낌이 팔까지 내려오는데, 이런 경우는 허리나 목 재활과 적절한 약물로 관리할 수 있습니다."

### 한국 외래 변환 시 확인

- 신경병증 통증 약물 (gabapentin·pregabalin 등) 보험 기준 [출처 미확인 — researcher 검증 권장]
- EMG 검사 한국 급여 기준

## 한계·주의

- 가상 시나리오 기반 교육 도구 — RCT 검증 없음
- 3가지 기전 분류는 단순화된 프레임 — 실제 환자는 혼합형 많음
