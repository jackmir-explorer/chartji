# Lowering DVT-Related ED Visits via a Primary Care POCUS Pathway

- **PMID**: 42131561
- **저널 / 연도**: POCUS Journal 2026;11(1):45-49
- **저자**: Hui W, Suffoletto JA, Lin S (Stanford 대학병원 가정의학과)
- **출처 Scout**: inbox/scout/2026-05-27.md

## 초록 요약

하지 DVT는 폐색전증 예방을 위한 신속 진단이 중요하나 대부분 응급실(ED)로 의뢰된다. 이 QI 프로젝트는 Stanford 대학병원 가정의학과 외래에서 POCUS fellowship 수련 의사 1명을 전담으로 배치해 DVT 의심 환자를 내부 의뢰하는 경로를 구축한 결과를 보고한다.

2024년 6월~2025년 8월, 80명 평가. DVT 양성률 5%(4/80). **46%의 환자(37/80)가 ED 방문을 회피**, 약 $85,100 비용 절감. 의뢰 의사의 98%가 환자 안전 향상·인지 부담 감소·ED 의뢰 감소에 동의.

## 주요 결과

| 지표 | 수치 |
|---|---|
| 평가 환자 수 | 80명 |
| DVT 양성률 | 5% (4/80) |
| ED 방문 회피 비율 | **46%** (37/80) |
| 추정 비용 절감 | **$85,100** |
| 의뢰 의사 만족도 | 98% (43/44명) |
| 설문 응답률 | 98% |

## 배경·방법

Wells score + D-dimer가 일차의료 DVT 배제 도구로 검증됐으나, 이 연구는 POCUS를 2단계로 추가한 전체 경로의 QI 근거를 제시한다. 설계: 전향적 QI 프로젝트. POCUS fellowship 수련 가정의학과 의사 1명 전담, 다른 의사로부터 DVT 의심 환자 내부 의뢰 수령, POCUS 평가 + 관리 일원화.

## 일차의료 적용 포인트

### 외래 결정 분기 (DVT POCUS 경로 모델)

```
DVT 의심 환자 (다리 부종·통증·발적)
  ↓
Wells DVT score
  ├── High probability → 즉시 압박 초음파 (POCUS or 혈관 초음파)
  └── Low/intermediate probability
        ↓
      D-dimer
        ├── 음성 (±연령보정) → DVT 배제
        └── 양성 → POCUS 또는 영상의학 초음파 의뢰
              ↓
            POCUS 음성 → 추적 or 추가 확인
            POCUS 양성 → 항응고 치료 시작 + 혈관외과/혈액종양과 협진
```

### 진단·평가

- 이 연구의 DVT 양성률 5% — "낮은 사전확률 군에서 대부분 음성"이 예상 결과
- Wells score 활용 시 ED 불필요 비율이 거의 절반 → 환자 부담·의료비 절감 가능
