# 만성 비암성 통증 오피오이드 감량 — 행동변화 기법 체계적 문헌고찰

## 미르의 첫 반응
> 행동치료의 구체적 적용방안? 이런게없으면 무의미.

## 미르 반응 심화 (이 노트의 핵심)

**"구체적 적용방안이 없으면 무의미" — 그래서 BCT를 처방으로 번역한다**

이 논문의 핵심 발견: 오피오이드 감량 성공 개입들이 공통으로 사용한 BCT는 **Behaviour Substitution (행동 대체)** 하나뿐이었다.

### Behaviour Substitution이란?

**정의**: 오피오이드가 채워줬던 기능(통증 억제, 불안 감소, 수면 유도)을 **다른 행동으로 대체**하도록 처방

| 오피오이드 기능 | 대체 행동 처방 | 메커니즘 |
|---|---|---|
| 통증 완화 | **운동 처방** (유산소·근력) | 내인성 오피오이드↑, 중추감작↓ |
| 불안·긴장 완화 | **이완 훈련** (복식호흡·점진근이완) | ANS 조절, 통증 역치↑ |
| 주의분산 | **마음챙김 기반 프로그램** (MBSR) | 통증 수용, 재앙화↓ |
| 수면 유도 | **수면 위생 교육** | 수면 질↑ → 통증 역치↑ |

### 외래에서 BCT를 어떻게 처방하나?

**2분 외래 처방 방식 (Behaviour Substitution)**:

```
Step 1: 오피오이드가 어떤 역할을 하는지 확인
    "지금 약이 없으면 어떤 게 제일 힘드세요? — 통증? 수면? 불안?"

Step 2: 해당 기능의 대체 행동 처방
    "그 부분을 약 없이도 해결할 방법을 같이 찾아봅시다"
    → 운동: "걷기 30분, 주 3회부터 시작"
    → 이완: "잠들기 전 복식호흡 5분 — 오늘부터 할 수 있어요"
    → 마음챙김: "스마트폰 앱 (코끼리, 마보) 7분 하루 한 번"

Step 3: 감량 계획 병행 설정
    "이 활동이 자리잡으면 2주 후에 용량 10% 줄여보겠습니다"
```

### 왜 Behaviour Substitution만 일관되게 효과적이었나?

다른 BCT (교육, 목표 설정, 자기모니터링)는 단독으로는 비일관적. Behaviour Substitution은:
- 오피오이드의 **기능적 공백**을 채워줌
- 대체 행동이 신경가소성을 통해 통증 조절 회로를 변경
- 감량 중 **금단 불안** 감소 (무언가로 대체되므로)

### BCT 분류 체계 요약 (이 연구 기반)

| BCT | 효과 | 비고 |
|---|---|---|
| **Behaviour Substitution** | ✅ 일관되게 효과 | 유일한 검증된 BCT |
| 정보 제공 (교육) | ❌ 단독 비효과 | 지식만으로는 부족 |
| 자기모니터링 | △ 비일관 | 병행 시 보조 가능 |
| 목표 설정 | △ 비일관 | 병행 시 보조 가능 |

## 초록 요약

CNCP(만성 비암성 통증) 환자 오피오이드 감량 성공 개입의 BCT 분류체계 분석 체계적 고찰. 13편(RCT 7 + 코호트 6), 3,130명. Behaviour Substitution이 유일하게 일관된 효과적 BCT로 확인. 구체적 대체 행동: 이완 훈련, 운동 처방, 마음챙김 기반 중재.

## 주요 결과

| 지표 | 결과 |
|---|---|
| 포함 연구 | 13편 (RCT 7 + 코호트 6) |
| 총 대상자 | 3,130명 |
| 유일 일관 효과 BCT | **Behaviour Substitution** |
| 구체 대체 행동 | 이완·운동·마음챙김 |

## 배경·방법

BCT(Behaviour Change Technique) 분류체계 v1 적용 체계적 고찰. 오피오이드 용량 감소 성공 개입에서 공통 BCT 요소 추출. 2015–2025년 문헌.

## 일차의료 적용 포인트

### 외래 결정 분기

```
CNCP 오피오이드 처방 중인 환자 (감량 검토)
    ↓
Behaviour Substitution 확인
    ├─ 이미 운동/이완/마음챙김 중 → 감량 계획 수립
    └─ 대체 행동 없음 → 먼저 Behaviour Substitution 처방
              → 4-8주 후 대체 행동 정착 확인
              → 정착되면 감량 시작 (10%/2주)
```

### 환자 교육

> "약을 줄이려면 약이 해줬던 역할을 다른 방법으로 채워야 합니다. 예를 들어 잠들기 전 복식호흡을 하거나, 통증이 심한 날 걷기 30분을 하면 몸이 자연스럽게 통증 조절 능력을 되찾습니다."

### 한국 외래 변환 시 확인

- 마음챙김 앱 한국어 지원: 코끼리, 마보, 마인드풀 — 무료 사용 가능
- MBSR 8주 프로그램 지역 가용성: 서울·수도권 일부 병원 심리학과 운영 [출처 미확인]
- 운동 처방 건강보험 연계: 병원 기반 운동 처방 급여 여부 [출처 미확인 — researcher 검증 권장]
