## 미르의 첫 반응
> 고혈압초진에서 ARR 내려면 환자 설득이 필요할거같다

## 미르 반응 심화 (이 노트의 핵심)

**환자 설득이 필요한 이유와 전략:**

### 왜 환자가 저항할 수 있나

1. **증상이 없다**: "혈압이 좀 높을 뿐인데 왜 추가 검사를 하나요?"
2. **비용 부담**: ARR은 알도스테론+레닌 동시 검사 → 비용 발생
3. **귀찮음**: 검사 전 준비 사항(β차단제 중단 등)이 번거로울 수 있음
4. **"어차피 혈압약 먹으면 되는 거 아닌가"**

### 설득 전략 (2분 외래 설명)

**1단계: 왜 중요한지 (임상적 근거)**
> "고혈압 환자 10명 중 1-2명은 혈압이 높은 진짜 원인이 콩팥 위 작은 샘(부신)에서 호르몬이 너무 많이 나와서입니다. 이런 경우 일반 혈압약으로는 심장이나 뇌혈관 손상을 막기 어렵습니다."

**2단계: 치료 가능성 강조**
> "하지만 원인을 찾으면 표적 치료가 가능합니다. 약 하나로 조절이 훨씬 잘 되거나, 수술로 완치되는 경우도 있습니다."

**3단계: 검사 간단함 강조**
> "피 한 번 뽑으면 됩니다. 오늘 처방해도 됩니다."

### ARR 검사 전 실제 준비 (임상 장벽 해소)

| 방해 약물 | 처리 방법 |
|---|---|
| β차단제, 클로니딘 | 이상적으로는 중단(2-4주) 후 측정 — 현실적으로 어려우면 결과 해석 시 감안 |
| ACEi/ARB | ARR에 영향 있으나 심한 오류 안 생기는 경우 많음 |
| CCB (암로디핀), α차단제(독사조신) | ARR에 최소 영향 → 혈압 조절 목적으로 교체 가능 |
| 이뇨제 | 저칼륨 유도 → 결과 왜곡 → 먼저 칼륨 교정 후 측정 |

**현실적 전략**: 고혈압 새 환자에게 처음부터 암로디핀+독사조신으로 시작하면 ARR 동시 측정 가능.

### PA 발견 시 임상 의의

- PA 환자는 **같은 혈압**에서도 본태성 고혈압보다 심혈관 이환율↑
- 심방세동, 좌심실비대, 신부전, 뇌졸중 위험 ↑
- 조기 발견 + 표적 치료(MRA or 수술) → 심혈관 위험 감소

## 초록 요약

2025 Endocrine Society PA 가이드라인. 고혈압 환자 전원 ARR 선별 권고로 패러다임 전환. 이전 선별: 저항성 고혈압·저칼륨혈증 등 고위험군 한정 → 2025: **모든 고혈압 환자**. GRADE 방법론, 10개 핵심 질문. 치료: MRA(스피로노락톤 우선) 또는 부신절제술(편측성). 편측성 판단: CT + AVS.

## 주요 결과 (가이드라인 권고)

1. **전원 선별**: 고혈압 환자 → 알도스테론 + 레닌 → ARR
2. **ARR 저위험**: PA 배제 → 일반 고혈압 관리
3. **ARR 중간**: 알도스테론 억제 검사 → 양성이면 CT+AVS
4. **ARR 고위험** (편측성 PA 강하게 시사): 억제 검사 생략 가능 → CT+AVS
5. **PA 확진**: MRA(스피로노락톤) 또는 부신절제술
6. 부신 선종 동반 PA: 1mg 야간 덱사메타손 검사 (쿠싱 배제)

## 배경·방법

다학제 패널, GRADE 방법론. 2013 Endocrine Society 지침 이후 최신 근거 통합.

## 일차의료 적용 포인트

### 진단·평가

- 모든 고혈압 초진 + 혈압 조절 불량 환자 → ARR 측정 권고
- ARR cutoff: 검사실 기관마다 다름 — 기관 기준 확인 필요

### 외래 결정 분기

1. 고혈압 새 환자 → ARR 처방 (알도스테론 + 레닌)
2. ARR 결과에 따라 3가지 경로
3. PA 의심 → 내분비내과 의뢰 (확진 + AVS 계획)

### 한국 외래 변환 시 확인

- 한국에서 ARR 검사 보험 급여 현황 [출처 미확인 — researcher 검증 권장]
- AVS(부신정맥 샘플링) 가능 기관 현황 [출처 미확인]
- 스피로노락톤 PA 적응증 급여 [출처 미확인]

## 한계·주의

- 이 연구 기반 PA 유병률(최대 14%)은 서구 데이터 — 한국 PA 유병률 별도 확인 필요
- ARR 검사 전 준비 부담 → 실제 1차 진료에서 시행률 낮을 수 있음
- AVS는 숙련된 기관에서만 가능 — 전국적 접근성 제한
