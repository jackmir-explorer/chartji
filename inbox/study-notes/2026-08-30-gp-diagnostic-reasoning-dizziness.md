# 경험 많은 GP가 의대 졸업생에게 진단추론 지다 — 급성 어지럼 빈네트 연구 (PLoS One 2026)

## 미르의 첫 반응

> 정확한 추론은 '많은 경험' 그 자체보다, 세부분야에 대한 학습과 인지부하가 적을수록 달성가능하다. 나는 신경학적 진찰에 자신이 없는데 그게 자기효능감에 속할거같다.

## 미르 반응 심화 (이 노트의 핵심)

미르가 정확히 파악했다. 이 논문의 핵심 메시지 2개:
1. **경험 ≠ 추론 정확도** — 임상 경력이 자동으로 추론 질을 높이지 않음
2. **자기효능감 = 추론 정확도의 독립 예측인자** — "내가 이 영역을 알 수 있다"는 확신

### "나는 신경학적 진찰에 자신이 없다" — 이것이 자기효능감 부족의 전형적 모습

자기효능감(self-efficacy)은 Bandura의 개념: "이 과제를 내가 할 수 있다"는 신념.
신경학적 진찰 자기효능감이 낮다는 것은:
- 신경과 시나리오 환자를 만나면 → 빠르게 "잘 모르겠다, 신경과로" (회피 반응)
- 문진/진찰을 깊이 하기 전에 이미 "어차피 나는 모른다"로 귀결
- 이것이 추론 정확도를 낮추는 메커니즘

이 연구에서 **자기효능감이 높은 GP가 더 정확하게 추론**한 이유:
→ 불확실 시나리오에서도 적극 탐색, 포기하지 않고 단서를 더 많이 수집, HiNTS 등 체계적 검진 시행

### 미르에 대한 직접 적용: 신경학적 진찰 자기효능감 향상 경로

**현재 상태 진단**: "신경학적 진찰에 자신이 없다" = 이 영역의 CME 우선 대상

**경로 (논문 예측인자 기반):**
1. **어지럼 특화 CME/세미나 수강** → 가장 강한 예측인자 (β=0.77)
   - HiNTS (Head Impulse - Nystagmus - Test of Skew) 실습 위주 강의
   - 전정신경염 vs BPPV vs 중추성 감별 케이스 시뮬레이션
2. **반복 노출 (어지럼 환자 체계적 진찰 연습)**
   - 처음 몇 명은 어색해도 → 시행하면서 "아, 이게 되는구나" 확인 → 자기효능감 축적
3. **인지부하 낮추기 (하루 외래 건수 관리)**
   - 논문: 30명/일 미만이 정확도 높음
   - 복잡한 어지럼 환자 = System 2 추론 필요 → 과부하 외래에서 빠른 회피 결정 위험

### 급성 어지럼 진단추론 체크리스트 (반복 연습용)

```
어지럼 환자 진입
├── 1. 어지럼 성격: 회전성(vertigo) vs 전신 불안정(unsteadiness) vs 전실신(presyncope)?
├── 2. 발병 양식: 갑작스러운(acute onset)?
├── 3. 동반 증상: 청력저하·이명(귀 증상)? 복시·구음장애·연하곤란(뇌간증상)?
├── 4. HiNTS 3항목 (갑작스러운 지속 어지럼일 때):
│   ├── Head Impulse Test: 비정상(catch-up saccade) → 말초성 시사
│   ├── Nystagmus 방향: 방향 고정 → 말초성; 방향 전환 → 중추성 ⚠
│   └── Test of Skew (alternate cover test): 수직 편위 → 중추성 ⚠
└── 5. HiNTS 이상 조합 → 중추성(소뇌·뇌간 뇌졸중) 배제 → MRI DWI
```

> **핵심 메모리**: HINTS 3항목 중 하나라도 중추성 신호 → 즉시 영상. "이 환자는 안전하다"고 확신하려면 3항목 모두 말초성 패턴 필요.

## 초록 요약

호주/유럽 GP(실습 중) vs. 의대 졸업반 학생을 표준화 급성 어지럼 빈네트(Script Concordance Test + Key Feature Problem)로 비교. GP 정확도 54% < 졸업반 61%(유의한 차이). GP 중에서 어지럼 CME 수강, 자기효능감, 하루 외래 건수 적음이 독립적으로 정확도를 높임.

## 주요 결과

- GP 54% vs 학생 61% (통계적 유의 차이)
- CME β=0.77 (95% CI 0.03–1.51): 가장 강한 독립 예측인자
- 자기효능감 높음: 독립적 양의 예측인자
- 외래 건수 <30명/일: 독립적 양의 예측인자

## 배경·방법

- 연구 설계: 빈네트 기반 단면 연구 (급성 어지럼 케이스 표준화)
- SCT: Script Concordance Test — 전문가 패널 합의 정답과 일치도 측정
- KFP: Key Feature Problem — 핵심 임상 결정 포인트 판단력 측정

## 일차의료 적용 포인트

### 진단·평가

- 급성 어지럼 = 일차의료에서 어려운 진단 중 하나 (BPPV·전정신경염·소뇌경색 감별)
- HiNTS: 갑작스러운 지속 어지럼 환자에서 중추성 배제의 핵심 도구

### 외래 결정 분기

- 자세 변환 시 유발·단시간(1분 이내) → BPPV 우선 → Dix-Hallpike 확인 + Epley maneuver
- 갑작스러운 지속 어지럼·구역 → HiNTS → 중추성 신호 있으면 즉시 MRI DWI
- 일측 청력 저하 + 심한 어지럼 → 전정신경염·미로염 vs 내이 혈관 사건 감별

### 한국 외래 변환 시 확인

- HiNTS 훈련 기회 [한국 내 CME 과정 출처 미확인]
- 어지럼 환자 진찰 시간 확보 어려울 경우 체계적 진찰 단축 버전 필요 [인지부하 관리]

## 한계·주의

- 빈네트 기반 → 실제 임상 환자와 차이 있을 수 있음
- 단면 연구 → 자기효능감과 정확도의 인과 방향성 확정 불가
- 한국 일차의료 외삽 시 교육 시스템 차이 고려
