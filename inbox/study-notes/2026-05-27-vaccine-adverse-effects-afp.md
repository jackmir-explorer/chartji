# Vaccine Adverse Effects: An Overview

- **PMID**: 42101598
- **저널 / 연도**: Am Fam Physician 2026;113(4):339-348
- **저자**: Coles S
- **출처 Scout**: inbox/scout/2026-05-27.md

## 초록 요약

백신은 현대 의학의 가장 성공적인 성과 중 하나다. 그러나 환자들은 점점 더 백신의 필요성에 의문을 제기하고 있어, 가정의학과 의사는 이상반응의 근거를 정확히 알고 백신 망설임(hesitancy) 환자에게 상담할 수 있어야 한다.

백신과 관련된 5대 주요 우려를 AFP 근거로 정리: ① Thimerosal 신경독성(없음), ② MMR-자폐 연관(없음), ③ RSV 임신 접종 위험(사산·기형·성장제한 위험 증가 없음), ④ COVID mRNA 심근염(최소한의 위험 증가), ⑤ 일반 이상반응(국소 반응 흔하나 정상 면역 반응). VAERS·VICP 시스템 설명도 포함.

## 주요 결과

| 우려 | AFP 결론 |
|---|---|
| Thimerosal 신경독성 | 연관성 **없음** (현재 다회용 독감 백신 바이알에만 사용) |
| MMR → 자폐스펙트럼 | 연관성 **없음** (Wakefield 1998 논문 철회 확인) |
| RSV 임신 접종 | 사산·신생아 사망·기형·성장 제한 위험 **증가 없음** |
| COVID mRNA 심근염 | **최소한의** 위험 증가 (절대 위험 매우 낮음) |
| 국소 이상반응 | 통증·발적 흔함 — **정상 면역 반응 신호** |

## 배경·방법

AFP 종합 리뷰. 체계적 문헌 검토 기반으로 가장 흔한 백신 이상반응 우려를 근거 중심으로 정리. VAERS(자발적 이상반응 신고 시스템)와 VICP(백신 피해 보상 제도) 설명 포함.

## 일차의료 적용 포인트

### 외래 결정 분기 — 백신 망설임 유형별 대응

```
백신 거부·망설임 환자
  ↓
주요 우려 파악
  ├── "Thimerosal 독성 걱정" → 현재 다회용 독감 바이알에만 사용, 신경 이상 연관 없음
  ├── "MMR 자폐 걱정" → Wakefield 1998 논문 철회, 반복 연구에서 연관 없음 확인
  ├── "RSV 임신 중 위험" → 사산·기형·성장 제한 위험 증가 없음 (AFP 2026)
  ├── "COVID 백신 심근염" → 매우 낮은 절대 위험, 감염 시 심근염이 훨씬 높음
  └── "부작용이 너무 심할 것 같아요" → 국소 반응 정상 설명 + 접종 후 관찰 시간 제공
```

### 환자 교육 (우려별 스크립트)

**MMR-자폐 우려:**
> "MMR 백신과 자폐의 관련성은 1998년 한 논문에서 제기됐지만, 그 논문은 연구 조작으로 철회됐고 이후 수십 개의 대규모 연구에서 반복적으로 관련성이 없다고 확인됐습니다."

**COVID 심근염 우려:**
> "코로나 백신과 심근염 위험이 약간 높아지는 것은 사실이지만, 그 위험은 매우 낮고 대부분 경미하게 지나갑니다. 코로나 감염 자체로 생기는 심근염이 백신보다 훨씬 위험합니다."

**RSV 임신 상담:**
> "RSV 백신을 임신 중에 맞으면 아기에게 항체가 전달돼 신생아를 보호합니다. 사산이나 기형 위험이 높아진다는 근거는 없습니다."

### VAERS·VICP 설명 포인트

- **VAERS**: 자발적 이상반응 신고 시스템 — 인과관계 입증이 아닌 신호 감지 도구. "신고됐다"≠"백신이 원인"임을 환자에게 설명
- **VICP**: 미국 백신 피해 보상 제도. 한국은 KDCA 예방접종 피해조사반·질병관리청 피해보상 제도 [출처 미확인 — 한국 제도 확인 권장]

### 한국 외래 변환 시 확인

- 한국 VAERS 해당 제도: 예방접종 이상반응 신고센터 [출처 미확인]
- RSV 백신 임신 접종 한국 허가 현황 [출처 미확인 — researcher 검증 권장]
- COVID mRNA 심근염 한국 역학 데이터 [출처 미확인]
