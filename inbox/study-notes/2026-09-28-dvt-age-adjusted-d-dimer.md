# Age-Adjusted D-Dimer Cutoff Levels to Rule Out Deep Vein Thrombosis

- **PMID**: 41490105
- **저널 / 연도**: JAMA 2026;335(5):416-424
- **저자**: Le Gal G et al.
- **출처 Scout**: inbox/scout/2026-09-21.md

## 미르의 첫 반응
> 선별하는것은 중요

## 미르 반응 심화 (이 노트의 핵심)

**"선별이 중요하다"는 반응의 actionable takeaway:**

이 논문의 핵심 메시지는 **선별의 정확도를 높이면서 불필요한 검사를 줄일 수 있다**는 것이다.

### 왜 나이-보정이 중요한가?

고령 환자에서 표준 D-이합체(500 µg/L)는:
- 노령에서 염증·응고 기저 활성으로 D-이합체가 자연히 높게 나옴
- 75세 환자의 경우 DVT 없어도 500을 넘기 쉬움
- 결과: 불필요한 압박 초음파가 75세 이상의 **91.3%**(음성 비율 8.7%만)에서 시행됨

나이-보정(나이×10) 적용 시:
- 75세 이상 음성 비율: 8.7% → **26.1%** 로 세 배 증가
- VTE 사건 0% (95% CI 0–2.3%) — 안전성 확인

**외래 즉시 적용 가능한 공식:**
> 50세 이상에서 D-이합체 결과가 500~(나이×10) 사이에 있으면 → DVT 배제 가능

예: 72세 환자 D-이합체 650 µg/L → 500 기준으로는 양성 → **720 기준 적용 시 음성** → 압박 초음파 불필요

## 초록 요약

다국가 전향적 관리 연구(27개 센터, 벨기에·캐나다·프랑스·스위스). DVT 의심 응급실 외래 환자 3,205명. Wells 점수 + D-이합체 순차 전략에서 나이-보정 기준치(50세 이상: 나이×10 µg/L) 적용 시 DVT 안전 배제 여부 검증. 나이-보정 기준 이하 161명에서 3개월 VTE 사건 0건(95% CI 0–2.3%). 75세 이상에서 음성 비율 8.7%→26.1%.

## 주요 결과

| 지표 | 결과 |
|---|---|
| 전체 대상 | 3,205명 (중앙 59세, 여성 54%) |
| DVT 유병률 | 14% |
| 표준 기준(500) 음성 비율 | 24.5% (531/2169명) |
| 나이-보정 추가 배제 | 7.4%포인트 추가 (161명) |
| 나이-보정 기준 이하 VTE 사건 | **0% (95% CI 0–2.3%)** |
| 75세+ 음성 비율 변화 | 8.7% → 26.1% |

## 배경·방법

나이-보정 D-이합체는 이미 PE(폐색전증)에서 검증됨. 본 연구는 DVT에서 최초 전향적 다국가 검증. 2015-2022년 모집.

## 일차의료 적용 포인트

### 진단·평가

**Wells DVT 점수** (저/중위험, 즉 Wells <3) + **D-이합체 측정**:
- D-이합체 <500 µg/L → DVT 배제
- 50세 이상: D-이합체 500~(나이×10) 사이 → **DVT 배제** (나이-보정 적용)
- D-이합체 ≥나이×10 → 압박 초음파

### 외래 결정 분기

1. 하지 통증·부종 + 신규 증상 → Wells 점수 계산
2. Wells ≥3 → 즉시 초음파 (D-이합체 불필요)
3. Wells <3 → D-이합체 → 나이-보정 기준 적용
4. 양성이면 압박 초음파 → DVT 확진 or 배제

### 환자 교육 (고령)

> "피검사에서 혈전 표지자가 나왔는데, 선생님 연령대 기준으로는 정상 범위입니다. 다리 초음파는 필요 없을 것 같습니다. 증상이 나빠지면 바로 오세요."

### 한국 외래 변환 시 확인

- 한국 응급실·외래에서 나이-보정 D-이합체 기준 적용 현황 [출처 미확인 — researcher 검증 권장]
- 고감도 D-이합체 assay 확인 (기관별 기준치 다름)

## 한계·주의

- 응급실 기반 연구 — 외래 1차의료 직접 적용 시 검전 확률 다를 수 있음
- 고감도 D-이합체 assay 필수 (저감도 assay에서는 적용 제한)
- Wells 점수 계산 정확도에 의존 — 항목 누락 시 오류
