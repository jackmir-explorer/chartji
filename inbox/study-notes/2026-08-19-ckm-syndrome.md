## 미르 반응 심화 (이 노트의 핵심)

**"친절한 설명"** — 적용 의도 유형. 미르가 CKM 개념을 환자나 동료에게 설명할 수 있는 형태로 정리되길 원한다.

### CKM 증후군 — 친절한 설명 3단계

**1단계: 왜 CKM이라는 새 이름이 필요한가?**

> "심장, 신장, 혈당 — 이 셋은 따로 노는 병이 아니에요."

전통적 접근: 당뇨과 → 혈당약 처방, 신장내과 → CKD약 처방, 심장과 → 심장약 처방
→ 결국 환자는 10가지 약을 먹는다

CKM 접근: "이 셋은 하나의 악순환 고리" → 하나의 약이 세 가지를 동시에 해결

**2단계: 병태생리를 그림으로 (1분 설명)**

```
비만 → 인슐린 저항성
    ↓
신장: 단백뇨·eGFR 감소
    ↓
심장: 볼륨 과부하 → 심부전·관상동맥질환

→ 이 세 개가 서로를 악화시킨다
```

**환자에게 할 수 있는 1분 설명:**
> "혈당이 높으면 신장이 망가지고, 신장이 망가지면 심장에 물이 차고, 심장이 나빠지면 혈당 조절도 더 어려워져요. 그래서 지금 드리는 이 약 하나가 세 가지를 동시에 도와줘요."

**3단계: 0~4기 분류 (10초 틀)**

| 단계 | 한 줄 요약 |
|---|---|
| 0기 | 완전 정상 — 예방만 |
| 1기 | 비만·당뇨전단계·고혈압 — 생활습관 |
| 2기 | 신장 손상 시작 (단백뇨·eGFR↓) — 신보호 약 시작 |
| 3~4기 | 심장질환 동반 — 최적 통합 처방 |

### 외래에서 CKM 프레임이 실제로 유용한 순간

**시나리오:** DM + 고혈압 + 단백뇨 + 미세심부전 의심 환자

기존 접근: 메트포르민 + 혈압약 + 신장과 의뢰 + 심장과 의뢰 = 다약제

CKM 접근 질문: "이 환자에게 SGLT-2i 하나로 혈당 + 신장보호 + 심부전 예방을 동시에 잡을 수 있는가?"
→ CKM 2기 이상 + DM + eGFR ≥20 → SGLT-2i 먼저

**핵심 실천:** CKM 관점 = "어떤 약 하나가 이 환자의 여러 문제를 동시에 해결하는가?" 먼저 묻기

## 초록 요약

CKM(심혈관-신장-대사) 증후군은 ≥2개 위험인자 상호작용으로 전반적 심혈관 건강이 저하되는 전신 장애. AHA 2023이 제안한 통합 패러다임. 유병률 증가 + 이환율·조기 사망 상승. 단일 다장기 이익 약제(SGLT-2i·GLP-1RA·PCSK9i) 발전이 치료 기회. PCPs가 단계별 환자 관리를 위한 실전 가이드.

## 주요 결과

[초록 기반 — 전문 미확인: 단계별 치료 알고리즘 상세는 원문 표 참조 권장]

- CKM 0~4기 분류 = AHA 2023 Presidential Advisory 기반
- 핵심 약제: SGLT-2i(심장+신장+혈당), GLP-1RA(체중+심혈관+신장), PCSK9i(LDL)
- 치료 원칙: 단일 약제 → 여러 CKM 요소 동시 개선 (처방 간소화)

## 일차의료 적용 포인트

### 외래 결정 분기

```
외래 DM + CKD + 심혈관 동반 환자
    ↓
CKM 단계 판단:
    1기: 대사이상만 → 생활습관 + 메트포르민
    2기: CKD 동반 (단백뇨·eGFR↓) → SGLT-2i + RAS 차단제 추가
    3~4기: CVD 동반 → SGLT-2i + GLP-1RA + PCSK9i 단계적 통합
    ↓
"이 환자에게 하나의 약으로 여러 문제를 동시에 잡을 수 있는가?" 먼저 확인
```

### 약물·처방 디테일

**CKM 2기 이상 핵심 처방 (SGLT-2i):**
- eGFR ≥20: 신보호 목적 시작 가능 [가이드라인 default: ADA 2025, KDIGO 2024]
- 적용: 단백뇨 + CKD + DM 동반 시
- 한국 급여: DM 병용 조건·HbA1c 기준 [출처 미확인 — researcher 검증 권장]

**GLP-1RA (비만 + CKM 1기 이상):**
- 비만·DM 동반: 체중 감소 + 심혈관 보호 동시
- FLOW 연구: semaglutide → 신장 보호 효과 [가이드라인 default: KDIGO 2024]

### 환자 교육

> "선생님 몸에서 혈당, 신장, 심장 세 가지가 서로 연결되어 있어요. 그래서 지금 드리는 이 약 하나가 세 가지를 동시에 돕는 역할을 해요. 예전처럼 각각 다른 약을 잔뜩 쓰지 않아도 됩니다."

### 한국 외래 변환 시 확인

- SGLT-2i 급여 기준: T2DM 병용 여부·HbA1c 기준 [출처 미확인]
- GLP-1RA 급여: BMI 기준·당뇨 동반 여부 [출처 미확인]
- CKM 증후군 진단코드 아직 없음 [출처 미확인]
