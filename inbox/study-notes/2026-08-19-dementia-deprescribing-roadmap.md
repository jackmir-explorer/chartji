# Deprescribing for People with Dementia: A Roadmap

- **PMID**: 40856967
- **저널 / 연도**: Drugs & Aging 2025 Aug 26;42(9):795-806
- **저자**: Green AR et al.
- **출처 Scout**: inbox/scout/2026-08-10.md

## 미르의 첫 반응
> 궁금하다.

## 미르 반응 심화 (이 노트의 핵심)

"궁금하다" = 단순 감상·놀람 유형. Actionable takeaway 도출:

**무엇이 궁금한가? → 치매 환자의 감약이 실제로 안전한가?**

논문의 답: 안전하다 — 단, **치매 특유의 복잡성을 다루는 구조화된 접근이 필요**.

**핵심 takeaway — 치매 감약의 세 가지 독특한 장벽:**

1. **BPSD(행동·심리증상) 재발 위험** — 항정신병약을 감약하면 초조·공격성이 돌아올 수 있다는 두려움 → FRAME으로 보호자와 사전 합의 후 천천히 감량
2. **가변적 경과** — 오늘 괜찮아도 내년에 악화되면 약을 다시 써야 할 수도 있음 → 감약 = 영구 중단이 아니라 재점검하는 것
3. **보호자 중심 의사결정** — 환자 본인이 목표·선호를 표현하기 어려움 → 보호자와의 소통이 핵심, FRAME 도구 사용

**외래 적용 시나리오:**

치매 + 다약제 외래 환자 만날 때:
1. STOPP/Beers 기준으로 먼저 스캔 → 항콜린제·수면제·항정신병약 확인
2. 보호자와 FRAME 접근으로 감약 목표·우려 공유
3. 4단계 로드맵 적용 (선별 → 계획 → 사전 조치 → 추적)
4. 첫 번째 감약은 가장 부작용 위험이 큰 약(항콜린제 우선)

**실천 질문 하나:**
> 지금 내 외래에서 치매 환자 중 항콜린 부담(ACB ≥2) 약을 쓰고 있는 사람이 있는가? → 이 로드맵의 1단계부터 시작.

## 초록 요약

치매 환자는 다약제와 잠재적 부적절 약물에 집중 노출된다. 이 리뷰는 Johns Hopkins 팀이 기존 노인·말기 환자 감약 프레임워크를 치매에 맞게 수정한 4단계 로드맵을 제시한다: ① 감약 대상 선별(약물 관련 목표 파악 + 위험·이득 검토), ② 감량 계획 수립, ③ 감약 전 사전 조치, ④ 밀접 추적관찰. FRAME 도구로 환자·보호자와 소통하는 전략도 포함.

## 주요 결과

- 리뷰 논문 — 직접 RCT 결과 수치 없음
- 기존 노인 다약제 감약 프레임워크 → 치매 특유 장벽(BPSD 재발·가변적 경과·보호자 중심) 반영 수정
- FRAME = 외래 면담 스크립트 (Framing·Rationale·Acknowledgement·Making a plan·Empathy)

## 배경·방법

치매 환자의 다약제는 의인성 해를 높이고 웰빙을 저하. 기존 Deprescribing 알고리즘은 치매의 특수성을 충분히 반영하지 않아 실제 외래 적용이 어려웠음. NIH 지원 Johns Hopkins 노인의학 팀이 실증 근거 + 전문가 경험을 통합.

## 일차의료 적용 포인트

### 외래 결정 분기

치매 외래 환자 다약제 재검토 시:

```
STOPP/Beers 스캔
    ↓
부적절 약물 발견?
    YES → FRAME으로 보호자 면담 → 4단계 로드맵
    NO  → 6~12개월 후 재점검
```

### 약물·처방 우선순위 (치매 환자)

1. 항콜린제 (oxybutynin, amitriptyline, promethazine, diphenhydramine) — 인지·낙상 위험
2. BZD·Z-drug — 낙상·진정·의존
3. 항정신병약 — BPSD 이외 적응증 없을 때
4. 스타틴·경구혈당강하제 — 임종기·기대여명 단기 시
5. PPI — 무증상 예방 목적으로 장기 사용 시

### 환자 교육 (보호자 교육)

> "지금 드시는 약 중에 어르신에게 오히려 해가 될 수 있는 것이 있어요. 약을 줄이면 더 안전하게 지내실 수 있습니다. 증상이 나빠지면 언제든 다시 이야기할 수 있어요."

## 한계·주의

- 리뷰 논문 — 감약 안전성에 대한 직접 RCT 근거 부족
- FRAME은 미국 맥락 개발 — 한국 보호자 문화(정서적 표현 방식, 의사결정 스타일)에 맞는 조율 필요
- 치매 단계(경증·중등도·중증)별 우선 감약 목록 상세는 원문 참조 필요 [초록 기반 — 전문 미확인]
