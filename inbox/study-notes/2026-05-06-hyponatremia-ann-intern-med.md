# Hyponatremia (Ann Intern Med — In the Clinic)

- **PMID**: 41359965
- **저널 / 연도**: Annals of Internal Medicine 2025 Dec
- **저자**: Henry DA et al.
- **출처 Scout**: inbox/scout/2026-05-03.md (과거 누락 복구)

## 초록 요약

저나트륨혈증(혈청 Na⁺ <135 mEq/L)은 입원 환자에서 가장 흔한 전해질 이상이다. 급성(< 48시간)은 뇌부종 예방을 위해 고장식염수로 빠르게 교정해야 하며, 만성(>48시간)은 뇌가 세포 용적을 정상화한 상태라 교정 속도를 제한해야 삼투성 탈수초화(ODS)를 막을 수 있다.

경한 만성 저나트륨혈증도 인지기능 저하, 골다공증, 낙상·골절 위험 증가, 입원 기간 연장, 사망률 증가와 연관된다. 조기 인식과 적절한 치료가 결과 개선에 필수적이다.

## 주요 결과

- 저나트륨혈증: 입원 환자 가장 흔한 전해질 이상
- 급성: 고장식염수 즉시 → 뇌부종 감소
- 만성 교정 속도 제한: **≤6~8 mEq/L/24시간** (ODS 예방)
- 경한 만성도 인지저하·골다공증·낙상 연관 → 외래 무증상 저나트륨혈증도 관리 필요
- SIADH 1차 치료: 수분 제한

## 배경·방법

Annals of Internal Medicine "In the Clinic" 포맷 — 1차의료 최적화 임상 리뷰. 저나트륨혈증은 입원 환경에서 주로 다루어지나, 외래 노인 환자(이뇨제·SSRI 복용)에서도 흔하고 임상 결과에 영향을 미친다.

## 일차의료 적용 포인트

### 진단·평가

**저나트륨혈증 감별 접근** (외래)

```
혈청 Na⁺ < 135 mEq/L 확인
  → 혈청 삼투압 측정
  → 소변 삼투압·소변 Na⁺ 측정
  → 혈량 상태 평가 (저혈량성/정상혈량성/고혈량성)
      ├ 저혈량성: 이뇨제·구토·설사
      ├ 정상혈량성: SIADH(가장 흔함), 갑상선저하, 부신부전
      └ 고혈량성: 심부전, 간경화, 신증후군
```

**외래 노인 고위험 약물 조합**:
- Thiazide + SSRI → SIADH 위험 급증 → 시작 후 1개월 Na⁺ 재검
- Carbamazepine, oxcarbazepine → 정기 모니터링

### 약물·처방 디테일

**SIADH 치료** [In the Clinic 기반]:
1. 수분 제한 800~1000 mL/일 (1차)
2. 원인 약물 중단 (이뇨제·SSRI 재검토)
3. Tolvaptan: 전문가 감독 하 단기 사용 — 간독성 위험, 처방 전 간기능 확인 [출처 미확인 — 한국 보험·적응증 researcher 검증 권장]

**만성 저나트륨혈증 교정 속도**:
- ≤6~8 mEq/L/24시간 (절대 초과 금지)
- 교정 속도 초과 위험: ODS(삼투성 탈수초화) — 비가역적 신경 손상

### 외래 결정 분기

```
외래 노인, 새로운 혼란·낙상·인지저하
  → 전해질 패널 확인
  → Na⁺ 저하 확인 시
      → 원인 약물 점검 (thiazide·SSRI·carbamazepine)
      → 갑상선기능검사(TSH)
      → 소변검사(삼투압·Na⁺)
      → Na⁺ < 120 mEq/L 또는 증상 심각 → 입원 의뢰
      → 경한 만성: 외래 수분 제한 + 원인 관리 + 추적
```

### 환자 교육

> "이뇨제와 항우울제를 같이 드시면 혈액 소금 농도가 낮아질 수 있어요. 갑자기 어지럽거나 헷갈리거나 힘이 없으면 바로 연락주세요. 처음 약을 시작하고 한 달 후에 피검사 한 번 하겠습니다."

### 한국 외래 변환 시 확인

- Thiazide(hydrochlorothiazide, indapamide) 급여 고혈압 처방 매우 흔함 → 저나트륨혈증 모니터링 습관화 필요
- 한국 SSRI 처방 증가 추세 — 이뇨제 병용 환자 특히 주의
- Tolvaptan(삼스카®) 한국 보험 기준 [출처 미확인 — researcher 검증 권장]

## 한계·주의

- In the Clinic 리뷰 — 개별 RCT 아닌 종합 권고
- 교정 속도 기준(6~8 mEq/L/24h)은 유럽 가이드라인 기반; 미국·한국 가이드라인과 세부 차이 가능
- 외래 경한 저나트륨혈증 관리 전략의 임상 시험 근거 제한적
