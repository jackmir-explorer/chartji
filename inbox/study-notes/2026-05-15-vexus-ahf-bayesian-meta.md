# VEXUS protocol as a prognostic tool in acute heart failure: A systematic review and Bayesian meta-analysis

- **PMID**: 41747972
- **저널 / 연도**: Current Problems in Cardiology 2026
- **저자**: Chaves VB et al.
- **출처 Scout**: inbox/scout/2026-05-15.md

## 초록 요약

급성 심부전(AHF)에서 전신 정맥 울혈(systemic venous congestion)은 예후를 결정하는 핵심 인자다. VExUS(Venous Excess Ultrasound) 스코어는 침상 옆에서 울혈 정도를 정량 평가하는 도구로 주목받고 있으나, AHF에서의 예후 가치는 아직 불확실했다.

이 연구는 PubMed·Embase·Cochrane을 검색해 AHF에서 VExUS의 예후 가치를 평가한 5개 연구(565명)를 베이즈 무작위효과 메타분석으로 통합했다. 1차 평가변수는 원내 사망률이며, VExUS ≤1(낮은 울혈군)과 VExUS ≥2(중등–고도 울혈군)를 비교했다.

연구 대상 대부분은 VExUS grade 3(최고도 울혈)이며 박출률 감소 심부전(HFrEF) CICU 입원 환자였다. 베이즈 메타분석은 사전 분포를 달리한 민감도 분석에서도 일관된 결과를 보였다.

## 주요 결과

| VExUS 등급 | 원내 사망률 |
|---|---|
| VExUS ≤1 | **1.9%** (4/210명) |
| VExUS ≥2 | **14.1%** (50/355명) |

- 평균 OR: **0.175** (95% CrI: 0.061–0.497)
- 연관성 사후 확률 (OR<1): **99.91%**
- 임상적 유의 효과 사후 확률 (OR<0.8): **99.93%**
- 예측 분포: 미래 연구에서 진 OR이 0.045–0.681 범위에 있을 확률 95%

## 배경·방법

AHF 환자에서 정맥 울혈 평가에 기존 BNP·흉부X선·청진이 사용되나 정량적 평가가 어려웠다. VExUS는 IVC 확장(>2 cm + collapsibility 저하) + 간정맥 파형(S파 소실·역류) + 문맥 간헐성 + 신장 정맥 간헐성 4개 요소로 0–3점 점수화한다. 베이즈 분석 방법은 빈도론적 접근보다 소규모 연구 통합에 유리하며, 사후 확률로 직접 임상 판단을 지원한다.

## 일차의료 적용 포인트

### 진단·평가

VExUS는 4개 초음파 뷰(IVC·간정맥·문맥·신장 Doppler)로 구성. AHF 의심 외래·응급 환자에서 입원 결정 보조 도구로 활용 가능하다.

- VExUS ≥2 → 원내 사망률 ~7배 높음 → 집중 치료·이뇨제 적극 최적화 시사
- 기존 BNP + 폐 POCUS B-line 조합에 정맥 울혈 정보를 추가하는 확장 프로토콜

### 외래 결정 분기

- AHF 증상(호흡곤란·부종·야간발작성호흡곤란) + BNP 상승 → VExUS 측정 시 ≥2이면 입원 적극 고려
- VExUS ≤1 + 경증 증상 → 집중 이뇨제 외래 치료 후 재평가 가능 (단, 1차의료 직접 적용 시 술기 숙련도 필요)

### 한국 외래 변환 시 확인

- VExUS 술기 교육은 국내 POCUS 확장 교육 필요 [출처 미확인 — researcher 검증 권장]
- 심장내과·응급의학과 협진 시 VExUS 정보 제공으로 치료 결정 지원 가능

## 한계·주의

- 5연구 565명 소규모, 대부분 LVEF<50% CICU 입원 — 일차의료·외래 경증 AHF 직접 외삽 제한
- 베이즈 메타분석의 사전 분포 설정 의존성 (단, 민감도 분석 일관)
- VExUS 술기 표준화·훈련 필요 — 초음파 경험 없는 일차의사 즉시 적용 어려움
