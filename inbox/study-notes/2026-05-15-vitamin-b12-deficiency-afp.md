# Vitamin B12 Deficiency: Common Questions and Answers (AFP 2025)

- **PMID**: 40961307
- **저널 / 연도**: American Family Physician 2025
- **저자**: Patel H, McGuirk R
- **출처 Scout**: inbox/scout/2026-05-15.md

## 초록 요약

비타민 B12 결핍은 미국 성인의 2–3%에서 발생하는 흔하지만 놓치기 쉬운 상태다. 위험인자는 흡수 저하(메트포르민·PPI·위절제·IBD), 식이 제한(채식·비건), 고령, 위축성 위염이 포함된다. 증상은 결핍 중증도에 따라 피로·brain fog·우울부터 말초신경병증·실조까지 다양하게 나타난다.

AFP의 "Common Questions and Answers" 포맷은 일차의료 임상가가 실제 진료에서 가장 자주 마주치는 B12 관련 질문들에 근거 기반 답변을 제공한다. 진단은 혈청 B12 <180 pg/mL에서 확진이며, 경계치(180–350)에서는 MMA 추가 측정이 필요하다.

핵심 실천 포인트는 두 가지다: 경구 B12 보충이 IM과 동등하다는 것, 그리고 B12 >1000 pg/mL의 지속 상승은 악성종양·심혈관 위험 신호라는 것이다.

## 주요 결과

| 수치 | 의미 |
|---|---|
| 혈청 B12 **<180 pg/mL** | 결핍 확진 |
| 혈청 B12 **180–350 pg/mL** | 경계치 → MMA 추가 |
| MMA 상승 | B12 결핍 확진 (경계치에서) |
| B12 **>1000 pg/mL** (2회 반복) | 악성종양·혈액암·CV 사망 위험 |

**경구 vs IM**: 비열등성 확인 — 대부분 환자 경구 처방 가능

## 일차의료 적용 포인트

### 진단·평가

**언제 검사할 것인가:**
- 보편적 선별 아님
- **위험인자 ≥1개 + 임상 증상 ≥1개** 동시 존재 시 검사

**가장 중요한 위험인자 조합:**
- 메트포르민 복용 당뇨 환자 + 피로·신경 증상
- PPI 장기 복용(≥12개월) + 피로·cognitive slowing
- 고령(≥65세) + 비건/채식
- 위절제 과거력

**진단 흐름:**
```
혈청 B12 → <180 pg/mL 확진 / 180-350 경계 → MMA
→ 원인 불명 → H. pylori + anti-IF Ab 검사
```

### 약물·처방 디테일

**경구 B12:**
- 대부분 환자에서 IM과 비열등
- 흡수 장애가 있어도 수동 확산으로 일부 흡수 가능
- 처방 편의성·비용·순응도 우위

**IM 우선 상황:**
- 신경학적 증상 (말초신경병증·실조)
- 중증 결핍
- 흡수 장애 (위절제·심한 IBD)

> [구체 용량·기간은 논문 전문 기준 — researcher 검증 권장]

### 외래 결정 분기

```
메트포르민·PPI 장기 복용 당뇨/역류 환자 + 피로·신경 증상
→ 혈청 B12 측정
→ <180 → 경구 B12 보충 시작
→ 180-350 → MMA → 상승 시 치료
→ 원인 불명 → H. pylori + anti-IF Ab
→ B12 >1000 (2회) → 악성종양 워크업
```

### 환자 교육

> "메트포르민(당뇨약) 또는 역류약을 오래 드셨다면 비타민 B12가 부족해질 수 있어요. 피로하거나 손발이 저리면 혈액 검사를 해보시는 게 좋습니다. 부족하면 주사 안 맞아도 약으로 보충할 수 있어요."

> "혈액 검사에서 B12가 너무 높게 나오면 (1000 이상) 다른 원인이 있는지 확인이 필요합니다."
