# Acute Low Back Pain: Diagnosis and Management

- **PMID**: 41252835
- **저널 / 연도**: American Family Physician 2025 Nov
- **저자**: Earwood JS et al.
- **출처 Scout**: inbox/scout/2026-05-03.md (과거 누락 복구)

## 초록 요약

급성 요통은 특이적(specific)과 비특이적(nonspecific) 두 범주로 나뉜다. 특이적 원인은 척추 내재성 문제, 전신 질환, 또는 타 장기에서의 방사통이다. 하지만 대부분의 급성 요통은 비특이적이다.

최근 외상이 없는 경우, 대부분의 환자는 Red Flag 소견이 없으면 영상이 필요하지 않다. Red Flag 소견이 있으면 즉각적인 영상과 전문과 의뢰·상담이 필요하다.

비특이적 급성 요통의 1차 치료는 활동 유지, 온열 요법, 기타 비약물치료(dry needling, TENS, 침술)이다. 약물치료로는 NSAIDs, 유발점 주사, 방사통 시 전신 코르티코스테로이드가 있다. 루틴으로 사용하지 말아야 할 약물: 벤조다이아제핀, 가바펜틴, 프레가발린, 오피오이드, **아세트아미노펜**. 적절한 치료에도 8주 이상 지속되면 영상·검사실 평가를 고려한다.

## 주요 결과

- 비특이적 요통: 대부분 4~6주 자연 회복
- Red Flag 없으면 영상 불필요 (과도한 영상 검사 지양)
- 1차 비약물: 활동 유지 + 온열 요법 + dry needling/TENS/침술
- 약물 1차: NSAIDs
- 루틴 금지 약물: 벤조다이아제핀·가바펜틴·프레가발린·오피오이드·**아세트아미노펜**
- 방사통(radicular LBP): 전신 코르티코스테로이드 고려 가능

## 배경·방법

AFP "Diagnosis and Management" 포맷 — 전문가 리뷰, 실용 임상 지침. 급성 요통은 1차의료에서 가장 흔한 호소 중 하나이며, 근거 기반 접근 vs 관습적 처방(오피오이드·MRI) 간 괴리가 큰 영역.

## 일차의료 적용 포인트

### 진단·평가

**Red Flag 체크 (해당 시 즉시 영상·전문과 의뢰)**
- 신경학적 결손: 하지 근력 저하, 감각 이상, 방광·직장 기능 이상 → 마미증후군 배제
- 최근 외상
- 발열·체중감소·야간통·면역저하·IV drug use → 감염·악성종양
- 골다공증·스테로이드 장기 복용 → 척추 압박 골절
- 암 과거력

비특이적 요통: 영상 즉시 불필요 — 환자에게 명확히 설명 필요

### 약물·처방 디테일

| 약물 | 권고 |
|---|---|
| **NSAIDs** | 1차 — 단기 사용 (GI·심혈관 위험 고려) |
| 전신 코르티코스테로이드 | 방사통(radiculopathy) 동반 시 단기 고려 |
| 유발점 주사(trigger point injection) | 국소 통증점 동반 시 |
| 근이완제 | 일부 지침 허용하나 졸음·낙상 위험 주의 [가이드라인 default 인용: AAFP 2025] |
| **아세트아미노펜** | **루틴 사용 권고 안 함** (AFP 2025 명시) |
| 오피오이드 | **루틴 사용 금지** |
| 가바펜틴·프레가발린 | **루틴 사용 권고 안 함** |
| 벤조다이아제핀 | **루틴 사용 금지** |

### 외래 결정 분기

```
급성 요통 호소
  → Red Flag 확인
    ├ 있음: 즉시 영상 + 전문과 의뢰
    └ 없음: 비특이적 요통으로 관리
        → 활동 유지 + 온열요법 + 비약물치료
        → NSAIDs 단기 처방
        → 4~6주 경과 관찰
        → 8주 이상 지속 → 영상·검사실 평가 + 만성화 위험인자 평가
```

### 환자 교육

> "허리가 아프다고 무조건 쉬시면 안 됩니다. 천천히 움직이시는 게 빨리 낫는 데 도움이 돼요. 사진(MRI)은 지금 당장 필요하지 않고, 4~6주 내 대부분 좋아집니다. 다리 힘이 빠지거나 소변·대변이 이상하면 즉시 오세요."

### 한국 외래 변환 시 확인

- 아세트아미노펜 루틴 사용 지양 — 한국 임상 관행과의 괴리 (타이레놀 선호도 높음) → 환자 설명 필요
- NSAIDs 급여 기준 (요통 상병 코드) [가이드라인 default 인용: 심평원]
- Dry needling 한국 의료법상 시행 자격 [출처 미확인 — researcher 검증 권장]

## 한계·주의

- AFP 리뷰 — 체계적 고찰 아닌 전문가 기반 권고
- 아세트아미노펜 권고 안 함은 최근 근거(NNT 낮음)에 기반하나 논란 있음
- 방사통 코르티코스테로이드: 단기 증상 완화 효과는 있으나 장기 예후 개선 불확실
