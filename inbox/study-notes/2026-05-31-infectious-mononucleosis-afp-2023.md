# Infectious Mononucleosis: Rapid Evidence Review

- **PMID**: 36689975
- **저널 / 연도**: American Family Physician 2023
- **저자**: Sylvester JE et al.
- **출처 Scout**: inbox/scout/archive/2026-05-18.md

## 초록 요약

전염단핵구증(mono)는 EBV에 의한 바이러스 증후군으로, 발열·인두염·후경부 림프절병증을 특징으로 한다. 주로 15~24세에 발생하며 타액을 통해 전파된다. AFP 2023 Rapid Evidence Review는 비용효율적 초기 검사 순서(CBC diff + Monospot), 검사 한계, 보존치료 원칙, 비장파열 예방을 위한 3주 운동 제한, 그리고 EBV와 9종 암 연관성까지 체계적으로 정리했다.

## 주요 결과

| 지표 | 수치 |
|---|---|
| Heterophile antibody test 민감도 | 87% |
| Heterophile antibody test 특이도 | 91% |
| 위음성 위험 | 5세 미만, 발병 첫 주 |
| 운동 제한 기간 | 발병 후 3주 |
| EBV 연관 암 종류 | 9가지 (Hodgkin 림프종, non-Hodgkin 림프종, 비인두암 포함) |

## 배경·방법

AFP Rapid Evidence Review 형식. 전염단핵구증의 임상 증상·검사·치료·합병증·EBV 장기 연관성에 대한 최신 근거를 일차의료 관점에서 요약. 진단 검사의 정확도, 보존치료 원칙 확인, 운동 복귀 타이밍 등 실무 지침 중심.

## 일차의료 적용 포인트

### 진단·평가

**LAP + 발열 청소년·청장년** → Mono 감별 우선 고려:
- CBC with differential: **>40% 림프구 + >10% 비정형 림프구**
- Rapid heterophile antibody test (Monospot)
  - Sens 87%, Spec 91% — 비용효율적 1차 검사
  - **위음성 주의**: 5세 미만 소아, 발병 첫 1주
- Heterophile 음성 + 강한 임상 의심 → EBV VCA-IgM 검사 (더 민감·특이, 비용↑)
- **간효소 상승** → heterophile 음성에서도 EBV 의심 강화 단서

### 약물·처방 디테일

- **항바이러스제(acyclovir 등) routine 사용 비권고**
- **Corticosteroid routine 사용 비권고**
  - 합병증(기도 폐쇄, 혈소판감소성 자반, 용혈성 빈혈)에는 개별 고려 가능
- **Ampicillin/Amoxicillin 금기** — 전신 발진 고빈도 발생
- 보존치료: 수분, NSAID·acetaminophen (해열·통증)

### 외래 결정 분기

```
LAP + 발열 (15~24세) 내원
  ↓
CBC diff + Monospot
  ├── 양성: Mono 진단 → supportive care, 3주 운동 금지
  ├── 음성 + 발병 첫 주: 재검 고려 or EBV VCA-IgM
  ├── 음성 + 간효소 상승: EBV 의심 강화 → EBV VCA-IgM
  └── 음성 + 증상 지속·악화: CMV·HIV·림프종 감별
```

**비장파열 예방**: 발병 후 3주간 접촉 스포츠 금지, 복귀 시기는 환자와 shared decision-making.

### 환자 교육

> "단핵구증은 바이러스 감염으로, 대부분 저절로 낫는 병이에요. 항생제는 도움이 안 됩니다. 운동을 무리하면 비장(왼쪽 배 안 장기)이 파열될 수 있어서 3주는 격렬한 운동을 삼가야 해요. 발병 후 3주가 지나면 상태에 따라 같이 결정해 봅시다."
