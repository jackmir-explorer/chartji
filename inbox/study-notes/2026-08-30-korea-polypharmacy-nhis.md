## 미르 반응 심화 (이 노트의 핵심)

미르가 세 가지를 요청했다:
1. STOPP/START/Beers 소개
2. 약사-의사 처방 최적화의 의미
3. 약 줄일 때의 불안감 — 의사·환자 모두

### 1. STOPP / START / Beers — 3대 도구 소개

이미 [[deprescribing]] knowledge 파일에 추가됨. 핵심만 요약:

**STOPP (Stop)**
- 유럽 기원, "피해야 할" 약물을 임상 맥락과 결합해 탐지
- 예: BZD 처방 중인 ≥65세 낙상 위험 환자, 콩팥 기능 저하 환자의 NSAIDs, 당뇨 환자의 1세대 항히스타민

**START (Start)**  
- "빠진 약" 탐지 — 처방해야 하는데 안 하고 있는 경우
- 예: ACEi/ARB (심부전 환자에서 빠짐), 스타틴 (고위험 심혈관 환자에서 빠짐), 칼슘+D (골다공증 예방)

**Beers Criteria (AGS)**
- 미국 기준, 노인에서 피해야 할 약물 목록
- 잘 알려진 포함 약물: 아미트립틸린(저용량도), 디펜히드라민(항히스타민), BZD/Z-drug, 근이완제(카리소프로돌)

**3도구 중 일차의료에서 가장 실용적인 것: STOPP**
→ 이유: 임상 맥락(진단 + 약물 조합) 기반 → "이 환자에게 이 약이 맞는가?" 질문에 직결

### 2. 약사-의사 처방 최적화 — "무슨 의미지?"

**처방 최적화(Medication Optimization)의 정의:**
환자가 현재 복용 중인 모든 약물을 체계적으로 검토하여:
1. **불필요한 약 중단** (적응증 없음, 부작용 > 이득)
2. **용량 조정** (과다·과소 용량)
3. **상호작용 해소** (복수 약물의 위험한 조합)
4. **누락 처방 추가** (START에서 잡는 것)
5. **복약 순응도 개선** (복잡한 복약 스케줄 단순화)

**약사-의사 협력의 역할 분담:**

| 역할 | 의사 | 약사 |
|---|---|---|
| 임상 판단 | 진단·적응증·증상 결정 | 약물 상호작용·대사 경로 |
| 약리 전문성 | 제한적 | 전문 영역 |
| 환자 소통 | 치료 목표·경과 | 복약 방법·부작용 설명 |
| 처방 변경 결정 | 최종 결정 | 제안·권고 |

**한국 NHIS 프로그램(이 논문)에서의 협력:**
- 입원 환자 대상 약사가 처방 목록 전체 리뷰 → 의사에게 보고 → 공동 결정 → 퇴원 처방 최적화

### 3. 약 줄일 때의 불안감 — 의사도, 환자도

이 불안감은 **양쪽 모두에 정당한 이유가 있다**.

**환자의 불안:**
- "이 약이 나를 지켜주고 있다" — 오랫동안 복용해온 약에 대한 심리적 의존
- "약을 끊으면 병이 나빠질 것 같다" — 회피 학습
- "의사가 왜 갑자기 약을 끊으려 하나" — 불신, "비용 아끼려는 건가?"
- 실제로 금단 증상이 생기는 경우 (BZD, 항우울제, 고용량 오피오이드)

**의사의 불안:**
- "내가 이 약을 끊었다가 환자가 악화되면 내 책임" — 의료 책임 회피 심리
- "이 약을 처음 처방한 의사와의 갈등" — "왜 선생님은 끊으려 하나요?"
- "환자가 따르지 않을 것 같다" — 의사-환자 관계 훼손 우려
- 실제로 중단 후 증상 악화 경험 → 이후 중단 시도를 더 꺼림

**해결 전략 (근거 기반):**

| 전략 | 내용 |
|---|---|
| **근거 먼저 설명** | "이 약을 계속 드시면 낙상·인지저하 위험이 있습니다" — 위험을 구체화 |
| **점진적 감량 (tapering)** | 급격한 중단 아닌 조금씩 줄이기 → 금단·반동 위험 최소화 |
| **안전망 제공** | "약을 줄이다가 불편하면 언제든 연락 주세요" — 환자 보안감 제공 |
| **중단이 실패 아님** | "중단 시도 후 증상 재발 시 다시 처방 가능" — 양방향 소통 |
| **목표 공유** | "약을 줄이는 것이 더 건강하게 사는 방법입니다" — 동기 일치 |
| **약사 협력** | 약사가 복약 상담·부작용 모니터링 → 의사 부담 분산 |

**환자에게 효과적인 한 문장:**
> "약을 너무 많이 드시면 약들 사이에서 서로 부작용을 만들어낼 수 있습니다. 지금 필요한 약만 잘 드시는 게 더 도움이 됩니다."

## 초록 요약

한국 HIRA 시범 다약제 관리 프로그램 (2020-21, 34개 병원): ≥65세·≥10종 약물 입원 환자 대상 약사-의사 협력 처방 최적화 → 90일 재입원 aHR 0.85 (15% 감소), 의료비 $340 절감, 비용편익비 3.8. 한국 국가 데이터 기반 다약제 관리 효과 최초 대규모 실증.

## 주요 결과

## 일차의료 적용 포인트

### 진단·평가 (처방 검토 우선순위)

- ≥65세 + ≥10종 약물 → 처방 재검토 강력 권고 (이 프로그램의 대상 기준)
- STOPP: 부적절 처방 탐지
- START: 누락 처방 탐지

### 외래 결정 분기

```
≥65세 다약제 환자 (5-10종 이상)
├── 연 1회 처방 전체 재검토
│   ├── STOPP 체크: 피해야 할 약 있나?
│   ├── START 체크: 필요한데 빠진 약 있나?
│   └── 상호작용 확인
├── 처방 변경 계획 수립 (점진적 감량)
├── 환자·보호자 상담 (불안 해소)
└── 추적: 중단 후 1-4주 증상 모니터링
```

### 환자 교육

> "약을 줄이는 것이 겁나시는 건 당연합니다. 하지만 약이 너무 많으면 약끼리 부딪혀서 생기는 부작용이 있고, 낙상·어지러움·기억력 문제로 이어질 수 있습니다. 천천히, 조금씩 줄여가면서 불편하면 바로 말씀해 주세요."
