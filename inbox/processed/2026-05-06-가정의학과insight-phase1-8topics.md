고위험군은 무조건 고강도 statin부터
목표 도달 안 하면 → ezetimibe → PCSK9 순서
부작용 시에는 switching/병용 고려
Lifestyle management는 항상 병행

ACC/AHA 2018, ESC/EAS 2019:
LDL-C를 인위적으로 올리기 위해 statin을 감량·중단하라는 근거는 없다.
LDL-C가 <40 mg/dL이라도 특별한 부작용이 없으면 계속 유지 가능하다.

예외적으로 약제 감량/중단 고려하는 경우
1) 부작용 동반 시 : 근육통, CK 상승, 간기능 이상, 새로운 당뇨 발생/악화 → 약제 감량/교체 고려
2) 저위험군에서 LDL 과잉 억제된 경우: ASCVD도 없고, 당뇨/CKD도 없는 1차 예방 환자에서 LDL이 30대 이하로 떨어진 경우 → 굳이 고강도 statin을 유지할 필요는 없음, 이때는 중등도 statin 또는 저용량 유지로 step-down 가능
3) 고령/여러 약제 복용 중인 환자 : Polypharmacy를 줄여야 하는 상황에서는 목표 도달을 넘긴 약제는 최소화 고려

추가검사
1) carotid IMT sono : Plaque or 내막 0.1cm 이상 두꺼워지면 의미있다. 
목적: 죽상경화증의 아급성 지표(서브클리니컬 atherosclerosis)를 확인 → 위험도 평가 강화
가이드라인 적응증 :
   중간 위험군(10년 ASCVD 위험도 5~20%) 에서 치료 여부가 애매할 때
   예: 45세 여성, LDL 150, 당뇨·고혈압 없음 → Statin 시작할지 불확실 → IMT에서 죽상경화 반 확인 시 치료 강화
   젊은 환자(40세 이하)에서 가족력 등으로 위험이 의심되나 전통적 리스크 점수만으로는 설명 안 되는 경우

2) Coronary calcium score (CT) : ASCVD 위험이 중간 정도일 때 statin 시작할지 고민되는 경우 가장 많이 사용. CAC >100 또는 ≥75 percentile → statin 강력 권고
3) ABI (ankle-brachial index): 말초동맥질환 의심되는 경우
4) hs-CRP: 염증성 리스크 평가 (JUPITER trial 근거)

1. 추가검사 적응증 : 추가검사(IMT, CAC, ABI 등) 는 원래 치료 시작 전, 위험도 분류가 애매할 때 도움이 됩니다.
이미 statin을 시작했다면, 치료 결정을 위한 추가 risk stratification 목적은 사라지므로 추가검사 적응증이 거의 없습니다.

2. 예외적으로 고려할 수 있는 경우
치료 순응도 향상 : 환자가 “나는 괜찮은데 왜 약 먹어야 하냐”고 계속 묻는 경우 → IMT, CAC 등에서 죽상경화증을 직접 보여주면 환자 설득에 도움

심혈관질환 의심 증상 동반 : 흉통, 호흡곤란, 간헐적 파행 등 → 기본 risk stratification을 넘어서 진단 목적 검사 필요할 수 있음

다른 질환 선별 목적 예: 40세 이상 여성 환자 → 국가검진 차원의 유방촬영/초음파 병행 (고지혈증 자체 때문이 아니라 건강검진 차원)

골밀도(BMD) 검사: 1~2년마다 평가.
전해질 검사(Ca, P, Mg): 저칼슘혈증 모니터링.
CTX, P1NP(골대사 표지자): 치료 반응 평가.

- 치과 치료시 휴약기 고려
일반적인 치과 치료(스케일링, 충치 치료) → 중단 필요 없음.
침습적 치과 치료(발치, 임플란트, 치주 수술 등)
가능하면 투여 직후 1개월 이내 시행(골흡수 억제 효과가 최대가 아닌 시점).
만약 이미 5개월 이상 경과했다면 → 다음 주사 투여 후 시행을 권장.
장기 사용(5년 이상) 또는 ONJ 위험 요인(흡연, 당뇨, 스테로이드 병용 등)이 있는 경우:
치과 전문의 및 골다공증 담당 의사와 협의 후 일시 중단 고려 가능.
하지만 **중단 시 골다공증 악화 가능성(반동성 골흡수 증가)**이 있어 신중한 판단 필요.

- 장기치료시 플랜
1) 보험적용 되는 경우: 데노수맙 계속 사용 (5년까지는 휴약기 고려하지 않음)
--> 5-10년 장기 사용시 턱뼈괴사, 대퇴골 골절 위험 증가
--> 5년 이후 골밀도, 골표지자 평가하여 지속 여부 결정
2) 보험적용 안되는 경우 
2-1) 비급여로 6개월 마다 투여
2-2) 비스포스포네이트로 변경 : 알렌드로네이트 또는 리세드로네이트
데노수맙 마지막 주사 후 6개월 지나고 6~12주 이내에 비스포스포네이트 복용 시작.
알렌드로네이트 70mg 주 1회 또는 리세드로네이트 35mg 주 1회를 최소 1~2년 이상 복용


*** 데노수맙 보험기준 
1) 중심골[Central bone; 요추, 대퇴]: DEXA (T-score ≤ -2.5).
2) 골다공증성 골절 확인 : 대퇴골, 척추, 요골, 상완골, 골반골, 천골, 발목골절
--> 1)에 해당하는 경우에는 1년(2회)
--> 2)에 해당하는 경우에는 3년(6회)
추적검사에서 T-score가 -2.5 이하로 약제투여가 계속 필요한 경우는 급여토록 함. (최대 2년, 4회)
--> 원래 -2.5 이하였는데, 추적검사에서-2.5 초과 -2.0 이하로 호전된 경우 지속투여 급여. (최대 1년, 2회)

***비스포스포네이트 보험기준
(1) DEXA 중심골 T-score가 -2.5 이하인 경우
(2) 1,2 이외 골밀도 측정 시 T-score가 -3.0 이하인 경우(T-score≤-3.0)
(3) 방사선 촬영(단순 X-ray는 인정하지 않음) 등에서 골다공증성 골절이 확인된 경우, 
--> (1)의 경우 1년 이내 보험 인정, (2)의 경우 6개월간 보험 인정되며, (3)의 경우 3년 이내로 약제를 보험으로 사용 가능. 
--> 약제는 추적검사에서 T-score가 -2.5 이하로 약제 투여가 계속 필요한 경우는 급여가 가능하나 졸레드로네이트의 경우 6회까지 보험이 인정된다. 
--> 추적검사에서 투여대상에 따른 골밀도 측정값이 골감소증(-2.5 < T-score ≤ -2.0)에 해당될 경우에도 1년 급여로 추가투여를 인정

[2] Red flags / 즉시 확인할 것
급격한 진행: 수일 내 악화되는 위약감 (Guillain-Barré 증후군 의심).
중추신경계 소견: 복시, 구음장애, 편측 마비, 보행 실조.
대소변 장애: 신경인성 방광/장 증상 (말미집 증후군, 척수 압박).
전신 증상: 의도치 않은 체중 감소, 발열 (악성 종양 또는 혈관염 의심).

[3] 진단 기준 또는 감별 포인트
대칭성 (Glove and stocking):
당뇨병성, 알코올성, 항암제/약물 유발, 비타민 B12 결핍, 요독증.

비대칭성 / 국소성:

- 신경근: 경추/요추 디스크, 협착증 (피부분절에 따른 방사통).
- 기타: 갑상선 기능 저하증, 과호흡(입 주변 저림 동반).

[4] 필요한 검사 / 하지 않아도 되는 검사
기본 혈액검사: HbA1c, CBC, Chemistry(L/RFT), Electrolyte.
추가 고려: TSH, Vit B12/Folate(고령, 채식주의자, 기력저하 시).

1) 진짜 혈뇨?
Gross hematuria vs. Microscopic hematuria
- 약물, 음식, 한약 확인
- Dipstick (+) 로 내원
--> UA 2회 이상 (Dysmorphic RBC, 단백뇨 검사 포함)
--> 혈액검사 CBC, BC, PT/APTT, Uric acid, Ca, P

2) 사구체혈뇨 vs. 비사구체혈뇨
사구체혈뇨 (RBC cast +, Dysmorphic RBC >40% +/- 단백뇨 동반) --> 신장내과 consult

                                                    --> 하부요로 평가 (방광경, cytology) : 비뇨기과 consult

심부전 의심증상 (research 필요)
심부전 의심증상 : 
호흡곤란 (누웠을때, 잘때), 부정맥, 발등부종, 비특이적 운동기능약화/피로감/소화불량...

심부전 유발약물 : NSAIDs, Beta blocker, Verapamil/Ditiazem

신체진찰 : 청진 (심음, 폐음)

진단검사 : CXR, ECG, CBC, BC, BNP, TFT
-> F/u 검사 : CBC, BNP, BC, 전해질
(특히 anemia, K+, BNP는 예후와 관련)

-> NT pro BNP > 125 또는 BNP > 35 인 경우
-> 확진검사 : ECHO

진단기준 : 
1) 박출률 감소 심부전 : LVEF <40%, 증상
2) 경계 박출 심부전 : LVEF 40-49%, 증상, BNP 상승, 심장구조이상
3) 박출률 보존 심부전 : LVEF 50% 이상, 증상, BNP 상승, 심장구조이상

치료방법 :
1) 환자 심부전 stage 분류 (ACC/AHA stage)
Stage A : 고위험군 (고혈압,당뇨,비만,대사증후군, 가족력...)
Stage B : 구조적 심질환 (MI 병력, 심비대, EF 저하, 판막질환 등) + 무증상 
Stage C : 구조절 심질환 + 유증상
Stage D : 불응성, 반복적 입원
2) 비약물 : 저염식, 수분섭취제한, 금연, 음주제한, 유산소운동, 심장재활
3) 약물
- 사망률 감소 약제 : ACEi, ARB, BB
- 증상 호전 약제 : 위 약물 + 이뇨제, Digoxin
- 고지혈증 동반된 경우 : statin
- Afib 동반된 경우 : CHADsVASC 점수, BB, 항응고제 고려

Stage A : ACEi/ARB, statin
Stage B : ACEi/ARB 우선, BB 추가, 시술/수술
Stage C : ACEi/ARB, BB, 이뇨제 (thiazide 우선 -> 효과 없을 시 루프 이뇨제로 변경)
              Digoxin, 동반질환 조절
Stage D : 심장이식...
