# inbox/ — 핸드폰 → Liby 메시지 큐

## 사용법 (핸드폰에서)

1. GitHub 앱 또는 Working Copy 앱에서 이 폴더에 파일 업로드/생성
2. 파일명: `YYYY-MM-DD-짧은제목.[확장자]`
3. 내용 작성 또는 이미지/PDF 업로드 후 push

## 지원 형식

### 텍스트 메모 (`.md`)
```markdown
출처: by ENT교수  (← 출처 힌트 있으면 꼭 적기. 없으면 데스크탑에서 확인)
내용:
여기에 임상 메모 자유롭게 작성
```

### 이미지 (`.jpg` `.jpeg` `.png` `.webp`)
- 슬라이드 사진, 교재 페이지, 필기 사진 등
- 파일명 예: `2026-04-15-위고비선택기준.jpg`
- 출처 힌트는 파일명에 포함하거나 데스크탑에서 Liby가 질문함

### PDF (`.pdf`)
- 가이드라인, 논문, 강의자료 등
- 파일명 예: `2026-04-15-비만치료가이드라인.pdf`

## 데스크탑에서

git pull 후 "Liby, inbox 확인해줘" → Liby가 자동 처리 후 draft 생성

## 주의
- 환자 이름·날짜·기관명 절대 포함 금지
- 처리 완료된 파일은 Liby가 inbox/processed/ 로 이동
