만성 비암성 통증 4형, 비오피오이드 약물 선택 체계 — AFP 2025 종합 리뷰

American Family Physician 2025 Aug;112(2):187-196 · PMID 40834375 ↗
📌 핵심
OA·만성요통·신경병증·섬유근통 4형별 비오피오이드 약물을 체계화한 AFP 2025 리뷰 — 오피오이드는 모든 대안 소진 후 최후 수단, 비생물심리사회적(BPS) 접근을 처방 전제로 명시.
📄 세부 요약 펼치기 deep · 초록 기반
만성 비암성 통증(≥3개월, 성인 1/5)의 비오피오이드 약물 선택을 통증 유형별로 정리. 오피오이드는 최후.
  • 골관절염(OA): 국소·경구 NSAID가 유의한 통증완화. SNRI·gabapentinoid는 근거 제한적.
  • 만성 요통: 유의한 통증·기능 개선을 주는 약물은 없음. NSAID·SNRI가 단기 소폭 개선(근거도 단기 한정).
  • 신경병성 통증: duloxetine·gabapentin·pregabalin·고농도(8%) 캡사이신 패치 = 중등도 효과.
  • 섬유근통: pregabalin 최선 근거(중등도), 이어 SNRI(duloxetine·milnacipran).
  • 공통: 생물심리사회 접근·기능/삶의질 목표·정신건강 동반 치료. 오피오이드는 타 전략 실패 + 위험-이익 평가 후에만.
시험·실무 포인트 유형별 1차: OA=NSAID / 요통=뾰족한 약 없음 / 신경병성=duloxetine·gaba·pregab·캡사이신 / 섬유근통=pregabalin
1차의료 적용 1차의료: 통증 유형을 먼저 분류한 뒤 유형별 비오피오이드 1차약을 매칭. 요통 환자에겐 약물 기대치를 낮추도록 상담.

미르의 첫 반응

궁금하다

미르 반응 심화 (이 노트의 핵심)

적용 의도 — 외래에서 바로 쓸 수 있는 병태별 약물 선택 알고리즘.

병태별 외래 처방 알고리즘 (즉시 적용)

골관절염 (OA):

  1. Topical diclofenac 먼저 (무릎·손 관절 — 전신 부작용 최소)
  2. Topical capsaicin (0.025-0.075%) 보조 옵션
  3. Oral NSAID (이부프로펜, naproxen) — GI 위험 고려, PPI 병용
  4. Duloxetine 30→60 mg (SNRI — 통증+우울 동반 시 특히 유용)
  5. 모두 실패 → 오피오이드 고려 (위험-편익 평가 후)

신경병증 통증 (Neuropathic pain):

  1. Duloxetine 60 mg (1일 1회) — 당뇨신경병증·섬유근통 동반 시 1차
  2. Gabapentin 300-900 mg tid 단계적 증량 — 어지럼 부작용 주의
  3. Pregabalin 150-300 mg/일 — 더 빠른 용량 적정 가능
  4. 8% Capsaicin patch — 전문 시술 영역

섬유근통 (Fibromyalgia):

  • Pregabalin 150-450 mg/일 (최강 근거)
  • Duloxetine 60-120 mg 또는 Milnacipran 100-200 mg
  • Tricyclics (amitriptyline 10-50 mg 취침 전) — 수면 + 통증

만성 요통 (Chronic LBP):

  • 솔직한 메시지: "약물 단독으로 큰 도움이 되지 않아요"
  • NSAIDs 단기(2-4주): 가장 낫지만 효과 작음
  • SNRI (duloxetine): 소폭 도움
  • 핵심 = 비약물 우선: 운동, CBT, 침, 물리치료

초록 요약

만성 통증(≥3개월) 미국 성인 5명 중 1명. 병태별 접근: OA=NSAIDs 우선, 만성 요통=유효 약물 없음(단기 NSAIDs/SNRI만), 신경병증=duloxetine/gabapentin/pregabalin, 섬유근통=pregabalin. 오피오이드는 최후 선택지.

주요 결과

  • OA: Topical/oral NSAIDs 가장 강한 근거
  • 만성 요통: 통계적 유의성 있어도 임상적 의미 제한적
  • 신경병증: duloxetine/gabapentin/pregabalin 중등도 효과
  • 섬유근통: pregabalin > SNRIs

일차의료 적용 포인트

약물·처방 디테일

  • Duloxetine: 30 mg 1주 → 60 mg 목표, 최대 120 mg
  • Pregabalin: 75 mg bid → 150 mg bid (최대 300 mg bid)
  • Gabapentin: 100-300 mg hs → tid 단계적
  • Topical NSAIDs: diclofenac gel/solution 1-4회/일

환자 교육

"만성 통증은 완전히 없애기 어려울 수 있어요. 목표는 통증을 줄여서 하고 싶은 활동을 할 수 있게 하는 거예요. 약만으로는 한계가 있어서 운동, 수면, 심리 지원을 함께 하는 것이 가장 효과적입니다."

미르 반응 심화 (이 노트의 핵심)

미르가 세 가지를 요청했다:

  1. STOPP/START/Beers 소개
  2. 약사-의사 처방 최적화의 의미

1. STOPP / START / Beers — 3대 도구 소개

이미 deprescribing knowledge 파일에 추가됨. 핵심만 요약:

STOPP (Stop)

  • 유럽 기원, "피해야 할" 약물을 임상 맥락과 결합해 탐지
  • 예: BZD 처방 중인 ≥65세 낙상 위험 환자, 콩팥 기능 저하 환자의 NSAIDs, 당뇨 환자의 1세대 항히스타민

START (Start)

  • "빠진 약" 탐지 — 처방해야 하는데 안 하고 있는 경우
  • 예: ACEi/ARB (심부전 환자에서 빠짐), 스타틴 (고위험 심혈관 환자에서 빠짐), 칼슘+D (골다공증 예방)

Beers Criteria (AGS)

  • 미국 기준, 노인에서 피해야 할 약물 목록
  • 잘 알려진 포함 약물: 아미트립틸린(저용량도), 디펜히드라민(항히스타민), BZD/Z-drug, 근이완제(카리소프로돌)

3도구 중 일차의료에서 가장 실용적인 것: STOPP → 이유: 임상 맥락(진단 + 약물 조합) 기반 → "이 환자에게 이 약이 맞는가?" 질문에 직결

2. 약사-의사 처방 최적화 — "무슨 의미지?"

처방 최적화(Medication Optimization)의 정의: 환자가 현재 복용 중인 모든 약물을 체계적으로 검토하여:

  1. 불필요한 약 중단 (적응증 없음, 부작용 > 이득)
  2. 용량 조정 (과다·과소 용량)
  3. 상호작용 해소 (복수 약물의 위험한 조합)
  4. 누락 처방 추가 (START에서 잡는 것)
  5. 복약 순응도 개선 (복잡한 복약 스케줄 단순화)

3. 약 줄일 때의 불안감 — 의사도, 환자도

이 불안감은 양쪽 모두에 정당한 이유가 있다.

환자의 불안:

  • "이 약이 나를 지켜주고 있다" — 오랫동안 복용해온 약에 대한 심리적 의존
  • "약을 끊으면 병이 나빠질 것 같다" — 회피 학습
  • "의사가 왜 갑자기 약을 끊으려 하나" — 불신, "비용 아끼려는 건가?"
  • 실제로 금단 증상이 생기는 경우 (BZD, 항우울제, 고용량 오피오이드)

의사의 불안:

  • "내가 이 약을 끊었다가 환자가 악화되면 내 책임" — 의료 책임 회피 심리
  • "이 약을 처음 처방한 의사와의 갈등" — "왜 선생님은 끊으려 하나요?"
  • "환자가 따르지 않을 것 같다" — 의사-환자 관계 훼손 우려
  • 실제로 중단 후 증상 악화 경험 → 이후 중단 시도를 더 꺼림

미르의 첫 반응

가정의학과 외래에서 잘 선별하는게 매우 중요한듯

미르 반응 심화 (이 노트의 핵심)

반응 유형: 적용 의도 — "가정의학과 외래에서 잘 선별"이라는 구체적 실천 의도.

왜 외래 선별이 이렇게 중요한가?

ITC 논문의 핵심 메시지: "허약 확인 → 위험 감소(risk mitigation) + 환자 목표 정렬(goals of care)"

외래에서 선별하지 않으면 일어나는 일:

  1. 고위험 약물·시술 결정 오류 — 허약 상태에서 tight control(혈당·혈압 집중 강하), 침습적 시술, 폴리파마시 유지가 오히려 해를 끼침. 모르고 있으면 막을 수 없음.
  2. 입원 예방 기회 상실 — 허약 확인 후 예방접종·낙상 예방·Deprescribing이 입원의 가장 큰 예방 레버 — 외래에서만 가능한 개입.
  3. 가역적 단계 놓침 — 전허약(prefrailty)은 연간 4.6% 자연 회복; 개입 시 더 높음. 증상 없는 prefrailty를 찾는 건 오직 스크리닝으로만 가능.

가정의학과 외래에서 실제로 어떻게 선별할 것인가?

누구에게:

  • ≥65세 외래 환자 전원 — 증상 없어도
  • 특히 우선도 높은 대상: ≥75세, 다약제(≥5종), 최근 입원력, 낙상력, 체중감소

언제:

  • 연 1회 건강검진 방문 시 루틴으로 통합
  • 새 만성질환 진단 시 (당뇨·고혈압 첫 방문) → 치료 강도 결정 전 필수
  • 수술·침습적 시술 계획 전

어떤 도구:

  • FRAIL Scale (5문항): 피로·저항력·보행·질환 수·체중감소 — 각 1점, ≥3점=허약, 1-2점=전허약
  • 가정의학과 외래: 5문항 구두로 1~2분, 별도 장비 불필요 → 1순위 권장
  • CFS (Clinical Frailty Scale) 1-9점: 관찰 기반, 영상 없어도 가능 — 이미 환자를 오래 봐온 주치의에게 적합
  • Fried Phenotype (5기준): 악력계·타이머 필요 — 연구·전문 세팅

선별 후 즉시 할 일 (외래 결정 분기):

결과외래 조치
허약(≥3점)1. 약물 목록 전면 검토(Beers/STOPP). 2. 낙상 위험 평가 + 환경 상담. 3. 영양 상담(단백질 ≥1.2g/kg/일). 4. 운동 처방(저항운동 주 2-3회). 5. 만성질환 치료 목표 de-intensification 검토. 6. CGA 의뢰 고려.
전허약(1-2점)예방 집중: 영양·운동 상담, 예방접종 확인, 6~12개월 후 재평가.
허약 아님(0점)생활습관 유지 격려 + 연 1회 재스크리닝 일정화.

이 논문이 변화를 주는 것

  • 기존 접근: 노인 환자가 "피로해요", "자꾸 넘어져요" 호소해야 허약 생각함 → 증상 의존적 = 늦음
  • ITC 권고: 만성질환 관리 + 입원 케어 모두에서 허약 선별 권고 = 증상 없어도 루틴
  • 실천 전환: "≥65세 = 허약 스크리닝 대상"으로 내부화 → FRAIL Scale 5문항을 문진표에 통합하거나 진료 시작 시 구두로

초록 요약

(Based on PubMed article metadata. [DOI: 10.7326/ANNALS-25-04412](https://doi.org/10.7326/ANNALS-25-04412))

Frailty는 다계통 생리적 예비능(physiologic reserve) 저하 증후군으로, 입원·장애·시설화·사망 위험 증가와 연관된다. 허약 환자(대부분 고령)는 고위험 약물·시술에 의한 의인성 합병증 위험이 더 높다.

가이드라인은 만성질환 관리와 입원 치료 양쪽 모두에서 허약 선별을 권고한다. 선별을 통해 위험 감소와 환자 목표 정렬이 가능하다. 일부 중재(영양·운동·다약제 감소)는 허약을 지연·역전시킬 수 있다.

본 ITC 리뷰는 허약 정의, 진료 환경별 평가 접근, 관리를 체계적으로 정리한다.

주요 결과

  • 위험: 허약 → 입원·장애·시설화·사망 + 의인성 합병증
  • 가이드라인 권고: 만성질환 관리 + 입원 케어에서 허약 스크리닝
  • 역전 가능성: 영양 중재·저항운동·Deprescribing·만성질환 최적화
  • 핵심: 선별 → 위험 감소 + Goals of Care 정렬

배경·방법

허약은 단일 질환이 아닌 증후군으로, 이질적 정의와 측정 도구가 공존한다(Fried Phenotype vs. 누적 결함 모델). Annals In the Clinic(ITC) 포맷은 복잡한 임상 주제를 일차의료에서 즉시 적용 가능한 수준으로 체계화한다. 서로 다른 진료 환경(외래·입원·지역사회)에서의 평가 접근을 비교 제시.

일차의료 적용 포인트

진단·평가

  • FRAIL Scale (외래 권장): 피로(Fatigue)·저항력(Resistance = 1층 계단)·보행(Ambulation = 100m)·질환수(Illness = ≥5개)·체중감소(Loss = 5% 초과)
  • 0점: 비허약 / 1-2점: 전허약 / ≥3점: 허약
  • CFS: 1(Very Fit)~9(Terminally Ill) — 긴 외래에서 관찰 기반 판단

외래 결정 분기

허약 확인 후 즉시 → Deprescribing(Beers/STOPP) + 낙상 예방 + 영양 상담 + 운동 처방. 치료 목표 재조정: tight control에서 goal de-intensification으로.

환자 교육

"허약은 나이 들면 어쩔 수 없는 게 아닙니다. 지금 약을 정리하고 단백질 드시고 운동하시면 몸 상태가 실제로 나아질 수 있습니다."

미르의 첫 반응

그동안 신발을 신경쓰지는 않았다. 어떤 신발, 어떤 브랜드? 구체적 예시 필요

미르 반응 심화 (이 노트의 핵심)

반응 유형: 적용 의도 — "앞으로 낙상 예방 상담에 신발을 포함하고 싶다. 구체적 제품 정보가 필요하다."

브랜드 질문에 대한 직접 답: 이 고찰은 특정 브랜드를 명시하지 않는다. 대신 세 가지 설계 특성을 제시한다.

  • 최소 아웃솔 (minimal outsole): 얇고 평평한 밑창
  • 질감 인솔 (textured insole): 발바닥에 감각 피드백을 주는 표면
  • 높은 칼라 (high collar): 발목·복사뼈를 감싸는 디자인

한국 시장 특정 브랜드·모델은 이 논문 범위 밖 [출처 미확인 — researcher 검증 권장]. 그러나 특성 기반으로 현재 시판 제품을 찾아 상담에 활용할 수 있다.

임상 적용의 핵심 전환점:

  • 지금까지: "집에서 슬리퍼 신지 마세요" (부정적 지시)
  • 앞으로: "이런 특성의 신발을 신으세요" (구체 권고) — 더 actionable한 메시지

"맨발 조심" 추가: 이 고찰에서 맨발은 일부 연구에서 균형 악화로 나타났다. 가정에서 맨발로 다니는 노인에게 "맨발보다 기능성 실내화가 낫다"는 근거가 생겼다.

초록 요약

부적절한 신발은 노인 낙상의 수정 가능한 위험인자로 알려져 있으나, 구체적으로 어떤 신발 특성이 보행·균형에 영향을 미치는지에 대한 종합 고찰이 없었다. 13개 연구(2017–2024)를 체계적으로 분석한 결과, 최소 아웃솔·질감 인솔·높은 칼라 조합이 노인 균형에 가장 일관된 효과를 보였다. 발가락 경사형은 근거가 혼재했고, 맨발은 일부 연구에서 균형 악화를 보였다.

주요 결과

신발 특성균형 효과
최소 아웃솔 (minimal outsole)일관된 개선
질감 인솔 (textured insole)일관된 개선
높은 칼라 (high collar)일관된 개선
발가락 경사형 (toe-beveled)혼재, 일부 음성
두꺼운 쿠션 / 낮은 고정력 / 맨발일부 연구에서 음성 효과

PubMed·IEEE Xplore·Scopus·Web of Science·Clinical Trials 검색(2017–2024). 노인 대상 신발 특성과 보행·균형 관계를 다룬 13개 연구 포함. 보행 평가·균형 평가 외에 지각 기반 설문도 포함 — 복합 평가가 단일 지표보다 신발 효과를 더 포괄적으로 파악함.

암환자가 아니더라도 적용?

미르 반응 심화 (이 노트의 핵심)

반응 유형: 적용 범위 의문 — "암 아닌 환자에도 이 가이드가 적용되는가?"

이 질문에 대한 직접적인 답: YES, 이 고찰은 암환자에 한정되지 않는다.

논문 포함 기준: "adults with advanced or severe acute disease" — 진행성 또는 중증 급성 질환을 가진 성인 전체. 암성 말기 외에도 COPD 말기, 심부전 말기, 간질성 폐질환, 심한 폐렴 등 모든 원인의 급성 호흡곤란이 포함 대상이다.

임상 시사점:

  • 비암성 COPD 말기 환자가 급성 호흡곤란 에피소드를 겪을 때 SC 모르핀이 적용 가능
  • 심부전 말기 환자에서도 동일 원칙 적용 (폐부종과 구분하여 판단 필요)
  • 재택의료 환자에서 SC 경로는 특히 실용적 — 정맥 확보 없이도 투여 가능
  • 단, 이 고찰의 대부분 연구는 입원·호스피스 세팅 — 순수 외래 환경에서의 적용은 [초록 기반]

가정의학과에서 재택의료·완화의료를 하는 의사에게 핵심 takeaway:

  1. 흡입 모르핀을 쓰고 있다면 → 근거 없음, SC/IV로 전환 고려
  2. 미다졸람을 경험적으로 쓰고 있다면 → 호흡곤란에는 근거 불충분, 모르핀 우선
  3. "암이 아니니 오피오이드 망설임" → 진행성 질환이라면 비암성도 동등 적용 가능

초록 요약

급성 호흡곤란은 수분 안에 peak에 달할 수 있다. 중추신경계 작용 약물이 빠른 완화에 사용되지만 근거가 불명확했다. 이 체계적 고찰은 성인 진행성/중증 급성 질환에서 치료 20분 이내 결과를 측정한 RCT 11개(n=334)를 포함해 15개 비교를 분석했다.

핵심 message: SC/IV 모르핀만 위약 대비 유의한 급성 호흡곤란 완화 효과를 보였다. 흡입 오피오이드, 비강내 펜타닐, 미다졸람은 효과가 없었다. 항정신병약·카나비노이드는 연구 자체가 없었다.

배경·방법

호흡곤란은 진행성 질환에서 가장 고통스러운 증상 중 하나. 기존에는 흡입 오피오이드·미다졸람도 경험적으로 사용됐으나 근거가 불명확했다. CENTRAL·MEDLINE·Embase(~2025년 9월) 검색, RCT만 포함, 20분 이내 결과 측정을 필수로 했다. 대부분 소규모 교차 설계 연구, 경로·용량·세팅이 다양해 메타분석은 어려웠다.

미르 반응 심화 (이 노트의 핵심)

"구체적 적용방안이 없으면 무의미" — 그래서 BCT를 처방으로 번역한다

이 논문의 핵심 발견: 오피오이드 감량 성공 개입들이 공통으로 사용한 BCT는 Behaviour Substitution (행동 대체) 하나뿐이었다.

Behaviour Substitution이란?

정의: 오피오이드가 채워줬던 기능(통증 억제, 불안 감소, 수면 유도)을 다른 행동으로 대체하도록 처방

통증 완화운동 처방 (유산소·근력)내인성 오피오이드↑, 중추감작↓

외래에서 BCT를 어떻게 처방하나?

2분 외래 처방 방식 (Behaviour Substitution):

``` Step 1: 오피오이드가 어떤 역할을 하는지 확인 "지금 약이 없으면 어떤 게 제일 힘드세요? — 통증? 수면? 불안?"

Step 2: 해당 기능의 대체 행동 처방 "그 부분을 약 없이도 해결할 방법을 같이 찾아봅시다" → 운동: "걷기 30분, 주 3회부터 시작" → 이완: "잠들기 전 복식호흡 5분 — 오늘부터 할 수 있어요" → 마음챙김: "스마트폰 앱 (코끼리, 마보) 7분 하루 한 번"

Step 3: 감량 계획 병행 설정 "이 활동이 자리잡으면 2주 후에 용량 10% 줄여보겠습니다" ```

왜 Behaviour Substitution만 일관되게 효과적이었나?

다른 BCT (교육, 목표 설정, 자기모니터링)는 단독으로는 비일관적. Behaviour Substitution은:

  • 오피오이드의 기능적 공백을 채워줌
  • 대체 행동이 신경가소성을 통해 통증 조절 회로를 변경
  • 감량 중 금단 불안 감소 (무언가로 대체되므로)

  • ④ **오타와 무릎 규칙** — 외상 시 골절 의심 영상 촬영 여부 결정; 불필요한 방사선 회피.

환자 설득이 필요한 이유와 전략:

왜 환자가 저항할 수 있나

  1. 증상이 없다: "혈압이 좀 높을 뿐인데 왜 추가 검사를 하나요?"

  3. 귀찮음: 검사 전 준비 사항(β차단제 중단 등)이 번거로울 수 있음
  4. "어차피 혈압약 먹으면 되는 거 아닌가"

설득 전략 (2분 외래 설명)

1단계: 왜 중요한지 (임상적 근거)

"고혈압 환자 10명 중 1-2명은 혈압이 높은 진짜 원인이 콩팥 위 작은 샘(부신)에서 호르몬이 너무 많이 나와서입니다. 이런 경우 일반 혈압약으로는 심장이나 뇌혈관 손상을 막기 어렵습니다."

2단계: 치료 가능성 강조

3단계: 검사 간단함 강조

"피 한 번 뽑으면 됩니다. 오늘 처방해도 됩니다."

"선별이 중요하다"는 반응의 actionable takeaway:

이 논문의 핵심 메시지는 선별의 정확도를 높이면서 불필요한 검사를 줄일 수 있다는 것이다.

왜 나이-보정이 중요한가?

고령 환자에서 표준 D-이합체(500 µg/L)는:

  • 노령에서 염증·응고 기저 활성으로 D-이합체가 자연히 높게 나옴
  • 75세 환자의 경우 DVT 없어도 500을 넘기 쉬움
  • 결과: 불필요한 압박 초음파가 75세 이상의 91.3%(음성 비율 8.7%만)에서 시행됨

나이-보정(나이×10) 적용 시:

  • 75세 이상 음성 비율: 8.7% → 26.1% 로 세 배 증가
  • VTE 사건 0% (95% CI 0–2.3%) — 안전성 확인

외래 즉시 적용 가능한 공식:

50세 이상에서 D-이합체 결과가 500~(나이×10) 사이에 있으면 → DVT 배제 가능

GP가 심장pocus는 어떤 요소들을 꼭 봐야하나?

미르 반응 심화 (이 노트의 핵심)

GP가 심장 POCUS에서 반드시 체크해야 할 5가지 요소:

1. LV 수축 기능 (EF 시각 평가)

  • 뷰: 파라스터널 장축(PLAX), 4-방 심첨
  • 판단: "EF 정상(≥50%)" vs "EF 감소(<40%)" vs "경계(40-50%)" — 시각적 eyeballing으로 구분
  • 임상 의의: EF 감소 = HFrEF → ACEi/ARNi + β차단제 + MRA + SGLT-2i 즉시 시작

2. 판막 이상 (스크리닝)

  • 뷰: PLAX(대동맥판·승모판) + 4-방(삼첨판)
  • 주요 소견: 칼슘화·두꺼워진 판막, 수축 제한, 색 도플러 역류 제트
  • AI 보조: AI가 자동 탐지·flagging — 전문의 확진으로 이어지는 경로

3. 심낭 삼출

  • 뷰: 4-방 심첨, 검상돌기하 (subxiphoid)
  • 판단: 에코 없는 공간(anechoic space) 확인 → 소량/중량/대량 분류
  • 압전 징후 확인: IVC 확장 + 우심방 collapse → 심낭 압박 응급

4. IVC 크기·호흡 변이

  • 뷰: 검상돌기하 종단 스캔
  • 정상: IVC ≤2.1 cm + 흡기 시 50% 이상 허탈
  • 이상: IVC >2.1 cm + 변이 <50% → 중심정맥압↑ → 전신 울혈 시사

5. 폐 B-line (폐 POCUS 병행 권장)

  • 뷰: 앞가슴 좌우 각 2~4구역
  • 정상: A-line(수평 인공음영) 주도
  • 이상: B-line ≥3개/구역 → 폐포간질 액체↑ → 폐울혈 시사
  • 핵심 조합: B-line ↑ + EF 저하 = 심부전 강력 시사

MASLD 진단·관리 — 지방간 1차 치료는 생활습관 처방 (운동·식이·금연·절주)

Am Fam Physician 2026 Jun;113(6):578-585 · PMID 42301877 ↗
📌 핵심
MASLD(구 NAFLD) 1차 치료 = 체중 ≥5% 감량 + 주 150분 중등도 유산소 운동 + 건강식이 + 금연·절주; 섬유화 동반 MASH에는 semaglutide·resmetirom FDA 승인(2024)
왜 유용한가
  • ① **생활습관처방 구체 수치**: 체중 감소 ≥5%(지방증 개선), ≥150분/주 중등도 유산소(심혈관 위험↓) — 외래에서 그대로 처방 가능한 숫자.
  • ② **MASLD 명칭 전환 시험 포인트**: 2023년 다학제 consensus로 NAFLD → MASLD 개명 (cardiometabolic risk factor ≥1개 포함, 낮은 음주도 허용).
  • ③ **외래 스크리닝 알고리즘**: FIB-4 지수 1차 위험 분류 → 중간위험 이상 → vibration-controlled transient elastography(또는 초음파 기반 탄성검사) 2차 평가.
  • ④ **새 약물(처방 변화)**: semaglutide(GLP-1, MASH+F2-F3 섬유화 대상 FDA 2024 승인), resmetirom(갑상선수용체 β 작동제 — 새 기전, MASH+중등-중증 섬유화 FDA 2024 승인).
  • ⑤ **절주·금연 독립 예후 인자**: 낮은 알코올도 진행 촉진; 금주·금연 시 간 관련 사망·전체 사망 유의미 감소.
  • ⑥ **시험 포인트**: MASLD vs MASH 구분, 위험인자(당뇨·비만·CKD·대사증후군·유전), 섬유화가 가장 강력한 예후 예측인자.

지방간이 있어도 섬유화 여부는 꼭 체크하지 않았었는데, fibroscan을 해서 예후인자를 확인해야겠구나. 기계가 없으면 어떡하지?

미르 반응 심화 (이 노트의 핵심)

섬유화가 왜 가장 중요한 예후 인자인가?

MASLD의 예후를 결정하는 것은 단순 지방증이 아니라 섬유화 단계(fibrosis stage)다. 지방간이 있어도:

  • F0-F1 (무~경도 섬유화): 간경변·HCC 위험 낮음 — 생활습관 관리로 충분
  • F2-F3 (중등~중증 섬유화): 간경변 진행 위험↑ — 적극 약물 치료 적응증
  • F4 (간경변): 간세포암·간부전 위험 — 전문의 집중 관리

FibroScan 없으면?

FIB-4 지수로 1차 분류가 가능하다: `` FIB-4 = 나이(세) × AST(U/L) ──────────────────────────── 혈소판(10³/µL) × √ALT(U/L) ``

  • FIB-4 <1.30 → 진행성 섬유화 배제 가능 (일차진료에서 모니터링)
  • FIB-4 1.30-2.67 → 중간 위험 → FibroScan 있는 기관으로 의뢰
  • FIB-4 ≥2.67 → 고위험 → 간전문의 즉시 의뢰

FibroScan 없는 클리닉의 실제 워크플로우:

  1. MASLD 의심 환자 → FIB-4 계산 (CBC+LFT 있으면 즉시 계산)
  2. <1.30이면 → 생활습관 처방 + 6-12개월 재확인
  3. ≥1.30이면 → 소화기내과 협진 또는 FibroScan 가능 기관 의뢰
  4. ≥2.67이면 → 즉시 의뢰, 신약(semaglutide/resmetirom) 적응증 검토

초록 요약

MASLD(구 NAFLD)는 대사기능장애 동반 지방간으로 만성 간질환의 가장 흔한 원인 중 하나로 증가 중. 당뇨·비만·대사증후군이 주요 위험인자. 2023년 NAFLD/NASH → MASLD/MASH로 국제 명칭 변경. 1차 진료에서 FIB-4로 섬유화 위험 분류하고, 중간~고위험이면 탄성검사(VCTE 또는 초음파 기반)로 2차 평가. 생활습관 개입이 1차 치료이며, MASH F2-F3에서 semaglutide·resmetirom FDA 2024 허가.

주요 결과

  • 체중 ≥5% 감량 → 간지방·ALT 개선
  • 주 ≥150분 중등도 유산소 운동 → 심혈관 위험↓
  • Semaglutide: 2024 FDA 승인, MASH F2-F3 섬유화
  • Resmetirom: 갑상선수용체 β 작동제(신기전), 2024 FDA 승인, MASH + 중등~중증 섬유화

배경·방법

AFP 종합 리뷰. MASLD 스펙트럼 전체(경도 지방증~MASH~간경변)를 1차 진료 관점에서 정리.

일차의료 적용 포인트

진단·평가

  • MASLD 의심 기준: 지방간 초음파 + 대사위험인자 ≥1개 (비만·당뇨·HTN·이상지질혈증·흡연)
  • FIB-4 < 1.30: 진행성 섬유화 배제 → 일차진료 모니터링
  • FIB-4 1.30-2.67: 중간 위험 → VCTE(FibroScan) 또는 초음파 탄성검사
  • FIB-4 ≥ 2.67: 고위험 → 간전문의 의뢰

외래 결정 분기

  1. FIB-4 <1.30: 생활습관 처방 (체중 5%↓, 운동 150분/주) + 추적
  2. FIB-4 ≥1.30: 의뢰 + 당뇨·비만 동반 시 GLP-1RA 병행 고려
  3. MASH F2-F3 확인 시: semaglutide/resmetirom 처방 또는 전문의 협진

환자 교육

"지방간은 초기에는 대부분 증상이 없지만, 간이 딱딱해지는 섬유화가 진행되면 간경변이나 간암으로 갈 수 있습니다. 지금 체중을 5%만 줄이고 일주일에 150분 운동하는 것이 가장 효과적인 치료입니다. 술은 가급적 안 드시는 게 좋습니다."
