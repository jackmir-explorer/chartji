## 결정 배경

QA 가이드 재현 결과 P0 #2 (TRIAGE에서 LPR-consensus 누락) / P1 #3 (UTI 주호소 bullet drop) / P1 #4 (TIPS 라벨 0건 매핑) 세 결함이 관찰되었다. 근본 원인은 LLM prompt 계약이 **금지 규칙**만 있고 **우선순위 규칙**이 없어서, LLM이 안전한 default(=단일 카테고리, Tier 1 편향, 주제 부조화 시 무조건 drop)로 빠지는 데 있었다.

Designer는 기존 금지 규칙을 유지한 채 **상위 계층에 "우선순위"를 신설**하는 방향으로 설계했다. 특히:
- 출처 라벨은 **신설 금지**. `임상 표준 — 관례적 진료` 같은 새 라벨을 만들면 sourcing-rules.md 체계가 오염된다. 대신 `[TIPS — 일반 약리 지식]` sub-form(이미 sglt2·vitamin-d ingest에서 도입됨)을 공식 등재하고, Tier 1 + TIPS(by {이름/소속}) + TIPS(일반 약리 지식)의 3 class를 prompt에 명문화해 "1급 동등"임을 선언.

## 건드린 파일 목록 및 상세

### 1. `src/prompts.js`

#### TRIAGE_PROMPT
- 삽입 위치: `calcCategories:` 설명 바로 다음, 카테고리 목록(`dyslipidemia...`) 바로 위 (기존 L20 → L21~32 블록 추가)
- 추가 내용:
  - "감지 원칙 (Phase L2 - 2026-04-22)" 블록 — 복수 감지 장려, 구·신 공존 원칙
  - "구·신 관계 매트릭스" — LPR/LPR-consensus, urticaria/아나필락시스, diabetes/sglt2/obesity, heart-failure/hf-referral/sglt2 4행
  - 복수 감지 예시 배열 샘플
- 제거: 없음 (기존 카테고리 리스트·규칙 전량 보존)

#### KNOWLEDGE_CURATION_PROMPT
**A. "bullet 선택 우선순위" 블록 삽입**
- 위치: `==지식 근거 규칙 (최우선, 절대 준수)==` **바로 위** (즉 기존 rule 최상단)
- 4단계 우선순위:
  - ① 환자 주호소·우려 직결 bullet (DROP 절대 금지, 단 주제-일치 출처 필수)
  - ② RedFlag 동반 맥락
  - ③ Drug safety·금기·환자 교육
  - ④ 일반 indication·protocol·monitoring
- "DROP 규칙은 위 4단계 이후 적용" 명시 — 기존 drop 규칙 삭제 아님, 순서만 정의

**B. "공식 출처 라벨 3 class" 블록 삽입**
- 위치: 기존 출처 표기 규칙 ①~⑧ 블록 뒤, `==출력 형식==` 바로 위
- 3 class 명문화:
  1. Tier 1 — 학술/가이드라인/규제 (`[CLINICAL]`·`[REGULATORY]` 태그)
  2. TIPS — by {이름/소속} (`[TIPS]`·`[INSIGHTS]` 태그)
  3. TIPS — 일반 약리 지식 (2 class sub-form, sglt2·vitamin-d 도입)
- 모든 예시를 기존 v2 엔트리와 같은 `[출처: ...]` prefix 포맷으로 통일 (sglt2-inhibitors.md의 `[출처: Swanson J et al...]` 표본과 일치)
- 신설 라벨 없음. `임상 표준 — 관례적 진료` 같은 새 라벨 도입 금지 원칙 준수

**C. "Tier 편향 금지" 블록 삽입**
- 위치: 3 class 블록 바로 뒤, `==출력 형식==` 위
- 3 class 동등 선언. "학술 출처가 더 확실" 판단으로 TIPS bullet 내리는 것 금지
- 한 엔트리 내 혼재 시 주호소 직결 bullet 고루 출력

#### 변경 영향 받지 않은 prompt
- `MISSING_PROMPT`·`REDFLAG_PROMPT`·`PROBLEMS_PROMPT`·`WORKING_DRAFT_PROMPT`·`DRAFT_REVIEW_PROMPT` 미수정 (L2 범위 외)

## 회고
- 예상과 달랐던 점
  - `knowledge/by-drug/sglt2-inhibitors.md`의 출처 포맷이 **`[출처: ...]` prefix** 사용 중임을 확인해서 prompt 예시도 같은 포맷으로 통일. 설계서 §2 박스 원본 템플릿에도 이미 `[출처: ...]` 형태로 작성되어 있어 일관성 유지가 자연스러웠음
  - "bullet 선택 우선순위"와 기존 "지식 근거 규칙(원문에 없는 내용 bullet 금지)"의 잠재 충돌 — ① 단계 "주호소 직결 drop 금지"가 "원문 근거 없으면 drop"보다 먼저 해석되면 곤란. 이 때문에 ① 단계 설명에 "단, 이 bullet도 공식 출처 3 class 중 하나를 sources[]·primarySources에서 가져와야 한다. 출처 없는 정보 합성·추정은 절대 금지"를 명시적으로 삽입
- 다음 세션 반영
  - Reviewer는 "우선순위 ①과 기존 원문-근거 규칙이 충돌 없는가"를 중점 검토. 잠재적으로 LLM이 ①을 ② "출처 없어도 drop 금지"로 오독할 여지가 남았는지 확인
  - sourcing-rules.md 신규 sub-form은 agents/librarian.md 에서도 인지되어야 함 — B2 Phase (다음 세션에서 진행 예정)
