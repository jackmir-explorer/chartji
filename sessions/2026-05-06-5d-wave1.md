## 회고
- 예상과 달랐던 점:
  1. bundle 표기가 두 종류(top-level `"key": {…}` vs `var _xx = {…}; KNOWLEDGE_BUNDLE["key"] = _xx`) — 1차 시도에서 24건 source-block-not-found. var 스타일 + unquoted section key 두 패턴 모두 지원하도록 보강 후 0건.
  2. 8건 no-token-match는 사전 우려처럼 keyword 부재가 아니라, **같은 섹션의 앞선 후보가 공통 토큰을 선점**한 결과 (e.g. `glp1-selection-strategy`가 `semaglutide`·`tirzepatide` 토큰 선점). 입력 파일 줄 순서가 우선순위로 작용 — Wave 2 입력 정렬 시 우선순위 의도를 명시 필요.
  3. cross-keyword 매칭 사례 발생: `[[zepbound|마운자로]]` 같이 target과 디스플레이가 의미상 어긋나 보일 수 있음. 5-D 스펙(`target.keywords ∪ {target}` 토큰 후보) 그대로 준수했지만, 향후 룰 정교화 여지 — 디스플레이 토큰이 target 별칭일 때만 허용하는 가드 등.
