## 회고

### 예상과 달랐던 점
1. **SURMOUNT-1 vs SURMOUNT-5 비대칭성** — 미르 지시 "중복은 제거"에 직역하면 양쪽 모두 drug에서 삭제가 맞지만, 실제 의도된 경계는 "전략·비교 수치"(SURMOUNT-5)와 "약 단독 용량 판단 수치"(SURMOUNT-1)가 다르다는 것. 후자는 drug에 남아야 마운자로 단독 처방 시 의사가 "10mg 이상 올릴 실익" 판단 가능. "중복 제거" 원칙을 기계적으로 적용하지 않고 맥락을 갈라서 판단함.
2. **semaglutide 엔트리 1섹션 구조의 효용** — 성분명이 transcript에 나오는 빈도는 낮지만, fallback 경로로 존재 의의 있음. `guide:["overview"]` 단일 섹션으로도 kind:drug 기본 동작 정상(Phase 4 dysphonia 1섹션 케이스와 동일 구조 재활용).
3. **primarySources 차등** — wegovy=FDA, ozempic=심평원으로 명시한 반면 mounjaro는 정리 가능한 공식 출처가 md에 없어서 빈 배열로 두는 편이 규칙 ⑧ 작동에 불리하지 않음 확인(섹션 내 출처 문자열로 대체 가능).

### 다음 세션 반영
1. **역할 재정립 패턴 정형화** — drug/topic 공존 시 중복 제거 기준을 "수치 맥락" 기반으로 판단. 단일 문구 반복은 제거, 맥락이 다른 수치 재인용은 공존. Phase 6+ 비슷한 상황 재발 시 재현 가능.
2. **Chrome 실기 수준 차등** — Phase 3C(새 경로 도입)·Phase 4(새 topic 키 도입)는 LLM end-to-end 실기 필수였지만, Phase 5c(기존 shape 내 내용 재구성)는 데이터 레벨 + bundle 로드 경량 실기로 충분. 원칙: "dispatch 경로가 이미 검증된 경우 경량 검증 허용".
3. **미르 공부 연동** — Phase 5b(원본 md gap 보강)는 의학 지식 채우기라서 Claude 단독으론 불가. 미르가 공부/진료 시 TIPS/INSIGHTS/CLINICAL이 쌓이면 Liby로 ingest → 자동 v2 엔트리 생성 가능.
