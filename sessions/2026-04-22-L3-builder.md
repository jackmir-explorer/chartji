## 구현 상세

### A. `buildCurationCtx(entry, key)` 헬퍼 추출 (DRY)

**위치**: `src/app.js` L47-L85 (App 함수 외부, 순수 함수)

**반환**: `{ctx: string, debug: {reason, emittedKeys}}`

**로직**:
- v2 (`entry.sections` 존재): `getUiHooks(entry).guide` 키 순회, `"*"` 면 전 섹션. `primarySources` 있으면 ctx 포함. 섹션 sources[]가 모두 `[TIPS — 임시` 시작이면 skip (L2-patch 복제).
- v1 (`sections` 없음): `e.exam` + `e.draftAppend` 만 반영 — `handleCuration` 실제 로직과 정확히 일치.
  - ⚠ 의도된 엄격성: `e.treatment` / `e.differential` 은 Working Draft 경로에서만 쓰이므로 v1 엔트리가 `treatment` 만 있고 `exam`·`draftAppend` 없으면 Smoke #1이 broken 으로 잡음. 이게 Phase B4 (v1 fallback 삭제) 전제 검증 목적.

**handleCuration 리팩터**: L158-L168 의 30 line ctx 빌드 블록을 `knowledgeCtx += buildCurationCtx(e, c).ctx;` 한 줄로 축소. 동작 변경 0 (순수 추출).

### B. Smoke #1 + #3 useEffect (`src/app.js` L163-L189)

```js
useEffect(function(){
  if(typeof KNOWLEDGE_BUNDLE==="undefined") return;
  var host=(typeof location!=="undefined"&&location.hostname)||"";
  if(host!=="localhost"&&host!=="127.0.0.1") return; // dev only
  var broken=[], noSource=[];
  Object.keys(KNOWLEDGE_BUNDLE).forEach(function(k){
    var e=KNOWLEDGE_BUNDLE[k]; if(!e) return;
    var r=buildCurationCtx(e,k);
    if(!r.ctx) broken.push(k);
    if(e.sections&&(!e.primarySources||!e.primarySources.length)) noSource.push(k);
  });
  if(broken.length) console.warn("[KB-SMOKE] Guide ctx 공백 엔트리:", broken);
  if(noSource.length) console.warn("[KB-SMOKE] primarySources 누락 v2 엔트리:", noSource);
  if(!broken.length && !noSource.length) console.log("[KB-SMOKE] 통과 — 공백 엔트리 0, primarySources 누락 0");
},[]);
```

빈 dep array — 앱 부팅 시 1회만 실행. 앱 동작 영향 0.

## 부팅 시 예상 경고 리스트

### Smoke #1 (Guide ctx 공백) — 예상: v1 엔트리 중 `exam`·`draftAppend` 둘 다 없는 것만 broken

v1 엔트리는 약 30개 잔존(L1 B4 전까지). 대부분 `treatment` 는 있지만 `exam` 이 없는 경우가 많음.
- **명확히 잡힐 후보**: `LPR` v1 (현재 이미 진단된 상태 — L1 B1 에서 v2 LPR-consensus 승격으로 참조 공유 완료이지만 v1 껍데기 잔존 여부에 따라)
- **잡히지 않을 것**: `exam` 또는 `draftAppend` 중 하나라도 있는 v1 엔트리 (대다수)
- **L1 B4 목표**: 이 리스트가 0 이어야 v1 fallback 삭제 가능

실제 수는 첫 부팅에서 dev 콘솔로 확인. 이게 L1 B2·B3·B4 우선순위 리스트 시드.

### Smoke #3 (primarySources 누락 v2) — 예상: 약 10건

grep 결과 `"primarySources": []` 가 10개. 주요 후보:
- `semaglutide` (L577) — 성분명 fallback, 상세는 상품명 엔트리로
- `마운자로` (L595)
- `LPR-consensus` (L1833 근처) — B1에서 Tier 1 출처가 섹션별 sources[]로만 커버되는 의도된 빈 배열
- 기타 L2/L2-patch 과정에서 fallback primarySources 미설정 엔트리

경고 표시 자체가 문제는 아님 (주의 환기 용도). Liby ingest 시 primarySources 채우는 관례로 해소.
