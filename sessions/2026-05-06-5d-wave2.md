### §5-D.1 가드 적용
Wave 1 회고에서 식별된 cross-keyword 오변환 (MASH·zepbound 등) 재발 방지를 위해
신규 priority/충돌해소/섹션-토큰 단위 1회 강화 가드를 transform 스크립트에 내장:

1. **token-target priority 인덱스**: 모든 entry의 (key, keywords) → token map 사전 구축
   - priority 1: token == target.key
   - priority 2: token == target.keywords[0]
   - priority 3: token == target.keywords[1+]
2. **충돌 해소**: 같은 토큰이 후보 A(prio 1·2) + 후보 B(prio 3) 동시 매칭 시 A 단독 변환,
   B는 `ambiguous-token` 사유로 skip
3. **(섹션, 토큰) 1회 강화**: 같은 섹션 내 동일 토큰은 wikilink 1개만, target 다르더라도 두 번째 등장 skip
