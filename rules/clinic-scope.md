# rules/clinic-scope.md — 진료실 범위 정의

이 문서는 Chartji가 동작하는 진료실의 물리적 한계와 가능한 범위를 정의한다.
모든 임상 패널(Disposition, 판단 검토, 추천검사/치료)은 이 문서를 기준으로 판단한다.

---

## 진료실 형태
- 병원급 외래 (병상 있음)
- 가정의학과 외래 1차 진료

---

## 원내 가능한 검사

### 가능
- 혈액검사: CBC, 생화학 (간기능, 신기능, 지질, 혈당, HbA1c 등)
- 소변검사 (요검사, 요배양)
- 심전도 (ECG, 12-lead)
- 단순 X-ray (흉부, 복부, 사지)
- 초음파 (복부, 갑상선, 근골격계)
- 위내시경
- 폐기능검사 (PFT, 스파이로메트리)
- 산소포화도 측정 (SpO2)

### 불가 → 외부 영상의학과 의뢰 또는 타 기관
- CT
- MRI
- 핵의학 검사 (골스캔, PET 등)
- 심장초음파 (Echo)
- 관상동맥 조영술
- 조직 생검 (피부 제외)

---

## 원내 가능한 처치

### 가능
- 정맥주사 / 수액 투여
- 근육주사
- 상처 봉합 / 드레싱
- 석고 부목
- 관절 주사 (스테로이드, 히알루론산)
- 산소 투여
- 네뷸라이저 치료

### 불가 → ER 또는 해당 전문과
- 응급 수술
- 기관삽관 / 기도 확보 (응급상황 외)
- 흉관 삽입
- 심폐소생술 지속 관리
- 투석
- 수혈

---

## 협진 / 의뢰 가능 전문과

### 원내 협진 가능
- 신경과
- 신경외과
- 산부인과
- 정신건강의학과
- 소아과
- 피부과
- 안과
- 이비인후과
- 비뇨기과
- 응급의학과

### 원내 없음 → 타 기관 의뢰
- 내과 세부전문 (순환기, 소화기, 호흡기, 내분비, 혈액종양)
- 외과
- 정형외과
- 흉부외과
- 재활의학과
- 류마티스내과

---

## Disposition 단계 (우선순위 순)

| 단계 | 조건 예시 |
|------|----------|
| 즉시 119 호출 | 의식 저하, 호흡 곤란, 흉통+활력징후 불안정, 뇌졸중 의심 |
| 응급실 직접 전원 | 활력징후 경계, 급성 복증, 고위험 흉통, 중증 알레르기 |
| 당일 응급실 방문 권고 | 증상 지속 시 악화 가능, 활력징후 정상이나 고위험 |
| 타 전문과 의뢰 | 원내 해당 전문과 필요, 당일 또는 예약 |
| 다음날 재방문 | 단기 경과 관찰 필요, 검사 결과 확인 |
| 1주 이내 재방문 | 치료 반응 확인, 증상 호전 기대 |
| 1개월 이내 재방문 | 만성질환 추적 관찰, 생활습관 교정 평가 |

---

## 이 진료실에서 할 수 없는 판단

- "MRI에서 보이는 소견으로 판단하면" → 불가. 외부 영상 의뢰 후 판단.
- "입원 치료가 필요하다" → 병상 있으나 입원 적응증 판단은 별도 프로세스.
- "수술을 고려한다" → 외과/해당 전문과 의뢰.
- "투석이 필요하다" → ER 또는 신장내과 의뢰.
- "내과/정형외과/외과 협진" → 타 기관 의뢰.
